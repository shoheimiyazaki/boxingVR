# ボクサーの見た目

## 素材の調査結果（2026-11）

フリーで、そのまま使えるボクサーの 3D モデルは見つかりませんでした。

- **CC0（パブリックドメイン）の人型**: [plewr の rigged character](https://plewr.itch.io/3d-rigged-character)、[100 Avatars](https://app.cinevva.com/de/guides/free-rigged-3d-character-models)、[3D Human Parts Pack](https://opengameart.org/content/3d-human-parts-pack) など。いずれもボクサーではありません。
- **ボクサーのモデル**: 有料（[CGTrader](https://cgtrader.com/3d-models/character/child/low-poly-boxing-kid) など）か、ライセンスがはっきりしないもの（[Boxer Girl](https://mrpr1993.itch.io/3d-low)）でした。
- **構造上の理由**: このゲームの体は 13 個の独立した剛体で、外部のスキンメッシュは骨ごとに切り分けて体格も合わせ直す必要があります。

以上から、**剛体ごとに滑らかなメッシュを手続き生成する**方式にしました。

## 方針

| 項目 | 内容 |
|---|---|
| 比率 | 成人男性（約 7.5 頭身、肩幅 ≒ 2 頭、上腕 1.5・前腕 1.25・腿 2・すね 1.9 頭）を下敷きにする |
| デフォルメ | 約 6 頭身。グローブを大きく、肩を広く、腰を細くする |
| 色 | 体は単色、グローブだけ色付き。2 人の見分けは色味の差（暖かいグレー／冷たいグレー）とグローブ（赤／青） |
| 傷み | 傷んだ部位は赤黒く寄せる（ゲームの情報なので残す） |
| 当たり判定 | 描画専用。当たり判定は物理の箱のまま。見た目が箱から 1.6cm 以上はみ出さないことをテストで確かめる（頭と首は重なり代の補いぶんを許容） |

## 作り方

| ファイル | 役割 |
|---|---|
| `games/MiniRing/Visual/ShapeMesh.cs` | ロフト（超楕円の断面を軸に沿って並べる）だけで形を作る。端は断面を 0 まで細らせて閉じる |
| `games/MiniRing/Visual/BoxerModel.cs` | 部位ごとの形。寸法は物理の HalfExtents と関節位置から割り出す。体格ごとにキャッシュする（GPU バッファがメッシュの参照ごとに作られるため） |
| `games/MiniRing/Visual/BoxerRenderer.cs` | 各剛体の姿勢に載せて描く |

## PDCA の記録（部位ごと）

撮影は `dotnet test tests/MiniRing.Tests --filter FullyQualifiedName~BoxerLookTests` で行い、`.visualcheck/boxer_*.png` に出力します。全身 5 方向、部位ごとの正面・斜め・横、当たり判定の箱を重ねた図を撮ります。

| 部位 | Check（見て気づいたこと） | Act（直したこと） |
|---|---|---|
| 頭 | 眉が頭に埋もれる／鼻がくちばし状／耳が大きい／顔が平坦 | 眉を顔の表面まで出し、鼻を小さな楔、耳を小さく薄く、頬骨と顎の線を整えた |
| 頭（2 回目） | 頭頂の閉じ方の式を誤って尖った／眉が浮いた棒に見えた | 頭頂を円弧で閉じ、眉を中間の強さに |
| 首 | 関節の重なり代（3cm 固定）で頭が胸に埋まり、肩に頭が乗って見える | 見た目の頭を持ち上げ、胴から首を出した |
| 胴 | 四角い箱。胸に固定した三角筋が、腕を前に出すと肩パッドのように浮く | 三角筋を上腕の肩側のふくらみに移した（腕と一緒に回る）。細い腰から広い胸の逆三角形、胸筋の張り出し、僧帽筋の斜面 |
| 胴（2 回目） | 胴と腰の間に隙間、上端の角 | 胴の下端を腰の中まで伸ばした。角の強さを上ほど弱くした |
| 脚 | 膝が人形の継ぎ目のように切れる／ブーツの筒が足の後ろに浮く | 膝の端を丸めて深く重ねた。筒は膝を曲げると足首からずれるので外し、ローカットにした |
| 全身 | 腿が丸太のようで下半身が重い | 逆三角形を強め、腿とすねを細く締めた |
| グローブ | カフ・拳のふくらみ・親指で、ひと目でグローブと分かる | 変更なし |
| レビュー | ロフトの奥行き軸が軸の向きで前後反転し、顎・胸筋・−X 側の力こぶが後ろ向きだった／腰の下端が開いていた／肘を曲げると外側がくびれる／胴の肩の張りが腕と一緒に回らない | 奥行きを +Z（軸が Z のときは +Y）に揃えてテストを追加した。腰の下端を閉じた。肘の端を関節の中心から半径ぶん先まで伸ばした。胴は肩関節より外へ張らない形にした |
