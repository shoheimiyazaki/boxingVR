## 0. このゲームで物理が何のためにあるか

| 目指すところ | そこから導く原則 |
|---|---|
| **見た目が脅威を伝える**。大きい・太い・硬そうな体は強く、削れた体は弱って見える | P1 強さは見えている物（寸法・材料・残った量）からだけ出る。見えない倍率を持たない |
| **壊れ方は材料から**。切れる・潰れる・折れる・弾かれるが説明できる | P2 壊れるか否かは、局所の応力・エネルギーと材料の値の比べだけで決まる |
| **自由な体でも納得できる**。ボクセルで編集した体・腕 4 本・四足・尾・欠損が、同じ物理で立ち・歩き・打ち・倒れる | P3 体の種類で分岐しない。体はグラフ（部位・関節・筋）として記述され、法則はグラフの上で一つ |
| **プレイヤーの入力は目標**。届かない・遅れる・押し負けるが手触り | P4 入力は目標を出すだけ。体は自分の筋（関節トルク）と床の反力だけで動く。外から体を押す・持ち上げる力は無い |
| **決定的で再現できる**。記録 = 入力、再生でビット単位に同じ | P5 試合の計算は固定ステップ・決まった順・種付きの乱数だけ |
| **一つの現象には一つのモデル**。拳と武器、人とボット、VR とパッドが同じ体を通る | P6 同じ量を二つの式で出さない。近道は台帳に載り、軸へ寄せる行き先を持つ |

P4 が今いちばん守れていない原則（骨盤のホバー・起こすねじり等）。P3 と P4 は「自由な体」の前提で、片方だけでは成り立たない。

## 1. 層

下ほど動かしにくく、上ほど頻繁に変えてよい。**依存は下向きだけ**。上の層は下の層の口（§2.2）だけを使う。

```
 外  観る側: 描画・音・中継・UI・動画 ……… 試合を読むだけ。書き戻さない
 L6  試合: 決まり・団体・ラウンド・審判・得点・キャンペーン
 L5  判断: ボット・教科書・読み・意図の解釈・VR の写像 → FighterCommand
 L4  個体: 体型・材料の配合・手足の数・顔・教育（データだけ）
 L3c 感覚: 体が知りうること（目・耳・自分の体の感覚）と、その遅れ・ぶれ
 L3b 運動制御: 目標 → 関節トルク、釣り合い・足運び・反射
 L3a 生理: 筋（断面 × てこ・速さ）・エネルギーの蓄え・循環・呼吸・臓器・意識
 L2  つながった物: 体のグラフ・剛体の鎖・関節・接触の伝わり・分かれる
 L1  材料と局所: ボクセルの物性・応力・壊れる条件・1 点の接触・1 つの関節
 L0  数値の土台: 時間・単位・解き手（Bepu の包み）・決定性・乱数
```

### 統合役の案から直した所（理由）

1. **L3 を 3 つに分け、感覚（L3c）を足した**。目の見え・相手の読みの「入り口」は、目のボクセルの残り（L1/L3a）で決まる体の量で、判断（L5）ではない。今はボットが相手の肩の位置を世界から直接読める（地図 V7）。「判断は感覚の出口しか見ない」を約束にすると、目を潰された体・視野の狭い異形の体が自然に弱くなる（P1）。相手の読み（`OpponentRead`）は感覚の出口を使う推論なので L5 に残す。
2. **接触と破壊を L1 と L2 に分けた**。1 点の接触で「どんな圧力が材料に掛かり、何が壊れるか」は L1（時間を持たない構成則）。「どの剛体とどの剛体がいつ当たり、力がどう伝わり、壊れた後に体がどう分かれるか」は L2（グラフの変更）。接触の検出と力積そのものは L0 の解き手の仕事。こうすると試験片のテスト（L1）が剛体の世界なしで書ける。
3. **エネルギー保存の責任を層ごとに分けた**。L0 は「解き手が勝手に増やさない」、L2 は「内力の和は 0（運動量・角運動量）」、L3a は「筋が出す仕事は蓄えから引く」、L3b は「外の力 = 0（P4）」。どの層もエネルギーの出どころを一つ上の層へ説明できる。
4. **決定性と性能は L0 が仕組みを持ち、全層が守る義務を負う**。各層は「1 フレームの予算の持ち分」と「順序を変えない」を約束する（§2.6）。
5. **描画・音・中継を層の外（観る側）に出した**。試合に響かないので、乱数・時計を使ってよい。ただし書き戻し禁止。団体の見せ方は外、団体の試合の決まり（休みの長さ・再生の速さ）は L6。
6. **L6 は体の状態を直接書き換えない**。休みの再生は L3a の法則（治る速さの式）を L6 が「時間を流す・環境の値を渡す」形で呼ぶ。今は L6 が直接ボクセルを治している（地図 V5）。
7. **L4 はコードを持たずデータだけ**（§1.8 の 1 ファイル）。L4 の値で変わってよいのは寸法・材料の配合・グラフの形・教育の値。式は L1〜L3 と L5 にだけある。

### 層ごとの定義

各層: **責任 / 持つ量と法則 / 持たないもの / 口 / テストの組と合格 / 変える手続き**。

#### L0 数値の土台
- 責任: 時間を進める、拘束と接触を解く、単位、乱数、決定性の仕組み。
- 持つ: 240 Hz の固定ステップ、SI 単位（m・kg・s・N）、Bepu の包み（型を外へ出さない）、種付きの乱数、接触の検出と力積の報告。
- 持たない: 人・部位・材料の名前。`Humanoid` の名を持つ物は L0 に置かない。
- 口（上へ）: 剛体を作る・力とトルクを掛ける（**関節の対の内力として**、または接触として）・接触の報告（点・法線・力積・相手）・拘束を作る/外す。
- テスト: 同じ入力で 2 回ビット一致、自由落下・弾む球・振り子でエネルギーが増えない（減衰の上限内）、拘束の位置誤差の上限、ステップを半分にして結果が収束する方向。
- 変える手続き: 計画書 → 物差し（上のテスト）を先に通す → 全テスト → `PhysicsVersion`（将来は `L0` の版）。

#### L1 材料と局所の物理
- 責任: 1 つのボクセル・1 つの試験片・1 点の接触・1 つの関節の「局所で何が起きるか」。
- 持つ: 材料の表（密度・ヤング率・降伏・引張・圧縮・粘り（破壊のエネルギー）・摩擦・減衰）、応力の求め方（圧力の集中・曲げ・せん断・引張）、壊れる条件（削れ・潰れ・断裂・曲げ折れ・靭帯の降伏）、1 関節の拘束の固さ・可動域の形。
- 持たない: 時間積分された剛体の世界、体の部位の名前、試合・団体・キャラの値、見えない倍率（相似の換算は近道として台帳）。
- 口: 下からは「接触の力・面積・速さ」、上へは「応力・壊れた量（セル）・残った断面」。純関数で書ける形にする。
- テスト（試験片）: 引張・圧縮・3 点曲げ・切断・圧子の押し込みで、(a) 実物の範囲に入る、(b) 寸法を k 倍したときの相似（強さ ∝ 断面、質量 ∝ 体積）、(c) 硬い方が壊れない・強さが近ければ両方の順序、(d) 材料の値以外の係数で結果が変わらない。
- 変える手続き: 材料の値を変える = 試験片の表を測り直して記録 → 全テスト → 版。

#### L2 つながった物の物理
- 責任: 剛体と関節のつながり（体のグラフ）、接触の力が鎖を伝わる、壊れた後の分かれ方。
- 持つ: ボクセルの部位の印から剛体・関節・質量・重心・慣性（全成分）を作る生成、関節の可動域と固さ、つながりが切れたら別の剛体にする規則。
- 持たない: 筋・意志・判断。体の種類の分岐（四足・人型）。
- 口: 下へは L1 の接触の問い、上へは「関節ごとに掛けられるトルクの口」と「体のグラフの問い合わせ（末端・支え・重心）」。
- テスト: 外力 0 の空中で運動量・角運動量の保存、静置で床の反力の縦 = 重さ、関節の位置誤差の上限、生成した重心・慣性 = ボクセルの数値積分、**人型・四足・6 肢・尾・欠損で同じテスト**（テストに体の種類の if を書かない）。
- 変える手続き: L0 と同じ重さ。物差しが先。

#### L3a 生理（体の働き）
- 責任: 関節のトルクの上限と、その代価。
- 持つ: 筋の力 ∝ 残った筋肉の断面 × てこ、力と速さの関係、エネルギー（酸素）の蓄えと戻り、循環・呼吸・臓器・出血、意識（頭のねじれ）・張り、治る速さの式。
- 持たない: 何をしたいか（目標）、試合の決まり。
- 口: 上へ「各関節のトルクの上限と、今の張り」、下へ「筋の塊が出す内力（関節の両側に等しく逆向き）」。
- テスト: 筋が出した仕事 ≤ 蓄えから引いた量、削れた断面に比例して上限が落ちる、意識の連続性（段を持たない）、体格 k 倍の相似。

#### L3b 運動制御
- 責任: 目標（`FighterCommand`）を、L3a の上限の中の関節トルクに変える。釣り合い・足運び・反射。
- 持つ: 末端の目標 → 関節トルク（ヤコビアン転置などの一つの方式）、支えの多角形・重心・捕捉点、末端の集合としての足運び、反射（手を着く・踏み出す・起き上がる試み）。
- 持たない: 外から体に掛ける力（P4）、姿勢の書き込み、技の名前。
- 口: 上から `FighterCommand`（末端の目標の並びへ一般化）、下へ関節トルク。
- テスト: 外の力の合計 = 0（M1）、トルクが上限を超えない、重心が支えの外へ出た辺から倒れる（M5）、足の数を問わず同じテストで立つ・歩く。

#### L3c 感覚
- 責任: 体が世界について知りうることを、体の状態から作る。
- 持つ: 目の残り → 見える範囲・遅れ・ぶれ（種付き）、自分の体の感覚（関節角・足裏の荷重）、聞こえ。
- 持たない: 推論（相手の次の拳の読みは L5）。
- 口: 上へ「感覚の出口」（`Sense` の形）。**L5 は世界・剛体を直接読まない**。
- テスト: 目を削ると情報の遅れ・ぶれが単調に増える、同じ種で決定的。

#### L4 個体
- 責任: 1 人を作るデータ（§1.8）。体型・材料の配合・グラフの形（手足の数）・顔・教科書・教育。
- 持たない: コード・キャラ名の分岐・強さの倍率（教育は技の側だけ）。
- テスト: 名簿の全員が生成でき、L2・L3 の不変量のテストを通る。教育が空 ≡ 教科書。

#### L5 判断
- 責任: 感覚の出口から `FighterCommand` を出す。ボット・教科書・読み・意図操作・VR の写像。
- 持たない: 剛体・力・ボクセルへの書き込み、感覚の外の真の値。
- テスト: 出力は `FighterCommand` だけ（型で強制）、同じ感覚で同じ出力、ドリル・リーグの成績（`BOT_PDCA`）。版は `LogicVersion`。

#### L6 試合とゲーム
- 責任: 決まり・団体・ラウンド・審判・得点・キャンペーン。
- 持たない: 体を直接書き換える口（治す・強くする）。環境の値（休みの長さ・再生の速さ）を渡して下の法則を走らせるだけ。
- テスト: 決まりの単体、試合の流れ、`ReplayTests`。

#### 外: 観る側
- 描画・音・中継・UI・動画。試合の状態を読むだけ。乱数・時計は自由（P5 の外）。テストは visual・目で見る。

## 2. 約束

### 2.1 依存の向き
- 上の層は下の層を使う。下の層は上の層の型・名前・値を知らない（`Aigis.Physics` が人体を知らない、L1 が団体の値を知らない）。
- `ArchitectureRulesTests` に、名前空間・アセンブリの参照の向きを足していく。

### 2.2 層をまたぐ口（これ以外を通らない）
| 境 | 口 |
|---|---|
| L5 → L3b | `FighterCommand`（末端の目標の並び・顔の向き・握り…） |
| L3c → L5 | 感覚の出口（`Sense`）。真の世界の値は渡さない |
| L3b → L3a | 関節トルクの要求 → 上限で切った実トルクとその代価 |
| L3 → L2 | 関節の対の内力（トルク）だけ |
| L2 → L1 | 接触の力・面積・速さ → 応力・壊れたセル・残った断面 |
| L2/L1 → L0 | 剛体・拘束・接触の報告 |
| L6 → 下 | 環境の値と時間（休み・再生の速さ）。直接の書き換えは無い |

### 2.3 外の力
- 試合の中で、接触と関節以外の力を体に掛けない（P4）。例外は生成の向き合わせ（`Fighter.Spawn`）だけ。
- 外の力の入口はすべて一つの記録（M1）を通る。M1 が 0 でない間は、その入口が台帳の項目になる。

### 2.4 近道の台帳
- 近道は「層」ではなく、**どの層のどの原則（P1〜P6）を破っているか**で台帳（`docs/DEBT.md` と地図の §3）に載せる。行き先（どの段で消えるか）を書く。
- **上の層で下の層の穴を塞ぐ近道は新しく入れない**（例: 立てない体をボットの判断や試合の決まりで救う）。下の穴は下で直す。

### 2.5 版
- 今の `PhysicsVersion` は L0〜L3 をまとめて数える。将来は `Material`（L1）・`Body`（L2〜L3）・`Logic`（L5）に分ける案（ユーザーの判断）。どれが上がっても記録の再生は失敗してよい（黙ってずれるよりよい）。

### 2.6 決定性と性能
- 全層: 種なしの乱数・時計・スレッドの順を試合の計算に入れない。辞書の列挙の順に結果を依存させない。
- 予算: 2 体・240 Hz で 1 フレーム 4.17 ms の中に収める。重くなる変更は層の持ち分を `docs/PERFORMANCE.md` に書く。結果を変えない最適化だけを版なしで入れてよい。

### 2.7 テストの層分け
- テストのクラスに層の印（`[TestCategory("L1")]` など）を付ける。L0〜L2 の物差しは**体の種類を問わない**・**金型（固定の値）を持たない**（同じビルドの比較・不変量・実物の範囲）。
- 下の層のテストが落ちている間、上の層の調整（教育・ボット）で合わせない。

### 2.8 変える重さ
| 層 | 手続き |
|---|---|
| L0〜L2 | 計画書 → 物差しを先に作る → スパイク → 段で入れる。全テスト・`rosterleague` で比べ、版を上げる |
| L3 | 物差し（M1・M5）を見ながら。全テスト・版 |
| L4・L5 | 使っていない種・相手で比べ直して採る（§1.8） |
| L6・外 | 通常の変更 |

### 2.9 新しい体・材料を足す手順
1. 材料: L1 の表に値（出典つき）を足し、試験片のテストで実物の範囲を確かめる。
2. 体: .vox に部位と関節の印を付ける（コードを足さない）。L2 の不変量のテスト（保存・反力・生成の質量）と L3b の立つ・倒れるに、その体を**データとして**加えて通す。
3. 通らないときはコードに分岐を足さず、どの層の法則が足りないかを地図に書く。
4. キャラは L4 のファイル 1 つ。教育は教科書から最適化（§1.8）。
