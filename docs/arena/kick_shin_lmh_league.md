# kick_shin_lmh: 前蹴りを人の動きにしたことでの試合の変化（短い総当たり）

`league --bots karate,taekwondo,champion --bouts 6 --seconds 60`（種 1、各組 6 試合）。前 = 変更前（0d01cef: 前蹴りは足首の経路、回し蹴りは下段の手本）、後 = 前蹴り・回し蹴りが人の動きの膝の制御（LogicVersion 42）。空手は前蹴りを重み 2 で使う。試合の数が少なく（各ボット 12 試合）勝敗は揺らぐ。`champion` は前蹴りを使わない。

| ボット | 前 勝-分-敗 | 前 与/被ダメージ | 後 勝-分-敗 | 後 与/被ダメージ |
|---|---|---|---|---|
| champion | 11-0-1 | 491 / 188 | 9-0-3 | 463 / 198 |
| taekwondo | 4-0-8 | 197 / 443 | 4-0-8 | 203 / 385 |
| karate | 3-0-9 | 342 / 399 | 5-0-7 | 299 / 381 |

見たこと: 空手は 3 → 5 勝（空手 vs テコンドーは 3-3 のまま、champion 戦が 0-6 → 2-4）。ダメージの比は空手 0.86 → 0.79 とわずかに下がり（与ダメージは 342 → 299）、勝敗の増えは champion が前蹴りで 2 勝した分で、前蹴りが拳の与ダメージを増やしたとは言えない。テコンドーは勝敗が同じで被ダメージが 443 → 385 に減り、奪ったダウンが 8 → 32 に増えた（回し蹴りが 3 つの高さに分かれ、人の動きの蹴りになったことの寄与は分けて測っていない）。揺らぎの範囲を超えるかは試合を増やして確かめていない。
