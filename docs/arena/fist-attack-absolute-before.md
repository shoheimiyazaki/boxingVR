# attacklab — PhysicsVersion 67

`attacklab --combos 1,2,3 --telegraphs 0.08 --ranges 1.05 --bouts 4 --seconds 12`、種1。

拳の速度は接触する歩の制御前の速度ノルム。相対速度は制御の力積適用後の衝突キャッシュ由来のHitEvent.Speedで、時点も異なる。

物理は変更前67のDLL。前後で同じ計測器を使うためArenaのDLLだけ拡張計測版に交換した（この計測器に埋め込まれた版定数では物理を判定しない）。
