# kicklab: Roundhouse（蹴る体 diego、すねの当てる点 ShinPoint 0.75、Overshoot -0.20、現在の Standoff 1.25、PhysicsVersion 39）

蹴る人が目標の間合いまで歩いて止まり、0.5 秒構えてから 1 本蹴る（目標 0.90, 1.00, 1.10, 1.20, 1.30, 1.40, 1.50, 1.60, 1.70。止まる位置は足の運びで決まるので、表は蹴り始めの実測の間合いを 0.10 刻みに束ねる）。相手は構えて立つだけ。種ごとに左右の脚を替える。
`当たったすねの点` = 当たった瞬間の、膝 → 足首の線へ落とした割合（0 = 膝、1 = 足首、1 超 = 足の甲・先）。`帯内` = その点が 0.50〜1.20（下すね〜足首のそば〜足の甲）に入った当たりが渡したエネルギーの割合（腿・膝の軽い当たりを数えないため、エネルギーで重みを付ける）。
`エネルギー` = `HitEvent.Energy`（組織へ渡った J）。`/蹴り` は 1 本の蹴りで渡した合計。

## 採否（手で書き足した判断。上の表から）

- 元の `Standoff` は 0.90（足首の目標の経路のときの値）。膝の制御の回し蹴りでは、実測の間合い 0.88 の束は帯内 0%（腿・つま先の当たり）、1.26 の束は帯内 85%（調整の種）・86%（使っていない種）・当たった蹴り 13/13・エネルギー/蹴り 3.98〜4.10 J と、すね〜足首〜足の甲へ当たる形が安定して出た。1.20 の束（帯内 49% → 64%）も近い。
- エネルギー/蹴りの最大は、帯の外（つま先が先に当たる 1.4 以上、または腿・膝が当たる 1.0 以下）に出る（5〜11 J）。足の先で強く当たるだけの間合いは、「すねの中ほどで当てる」狙いから外れるので採らない。
- 採った: `KickSpec.Roundhouse.Standoff` 0.90 → 1.25（実測 1.26 の束。`LogicVersion` 39）。
- 近道・残った問題: (1) 帯の上限 1.2 を超えるつま先の当たり（すねの点 1.3〜1.5）が間合い 1.4 以上で出る。足が先に当たるのは、すねが狙いを向いて突く形になるため（すねが相手の面と平行になる所まで脚が届かない）。(2) 相手の当たった所は `Leg`・`Knee`・`Elbow`・`Guard` が多く、胴（`Body`）は 1.01 の束の 2 本だけ。立って構える相手の腕と脚が先に当たる。(3) 実測の間合いは足の運びで半歩ごとにしか決まらず、同じ種は同じ間合いに止まる（種を替えても間合いが変わらない束がある。上の 2 つの表で 0.77・0.88・1.26 の束の標本が揃っている）。(4) 蹴る人の体は名簿の diego だけ。標準の体格は脚と腕の長さの比が違うので、別の `Standoff` になるはず（測っていない。`Standoff` は蹴る人の腕の長さの倍数）。
