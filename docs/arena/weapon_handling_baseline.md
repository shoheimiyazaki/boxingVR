# 武器の扱いの基準（2026-11-16、`handlelab`・`rosterleague`、LogicVersion 30 の教科書そのまま）

教科書（`Bots/weapons/*.json`）が今までの既定と同じ値のときの、刀（jin）・ロングソード（konrad）・こんぼう（sean）の扱いを数で見た表。
物差しは Arena の `handlelab`（`games/MiniRing.Arena/HandleLab.cs`。ゲームと同じ道で試合を回し、振りごとに当たりを数える）。
コマンド:

```
dotnet run --project games/MiniRing.Arena -c Release -- handlelab --bouts 6 --seconds 40 --seed 1 --parallel 2 --out <ファイル>
dotnet run --project games/MiniRing.Arena -c Release -- rosterleague --chars jin,konrad,sean,marcus,akira --bouts 4 --seconds 40 --seed 1 --parallel 2 --out docs/arena/weapon_handling_baseline_roster.md
```

（LogicVersion 31 で教科書を鍛えたあとは、鍛える前の値を JSON にして `--style-katana`・`--style-longsword`・`--style-club` で渡すと、この基準を再測定できる。再測定した表は最初の測定とすべての数が一致した。
下の表は再測定のもの（要約の表が付いている）。）

組: 刀・ロングソード・こんぼうの「同じ武器」（jin-jin など）・「別の武器」（jin-konrad・jin-sean・konrad-sean）・「拳」（それぞれ marcus と）、各 6 試合（コーナーを半分ずつ入れ替え）、40 秒、レフェリーあり。
表の見方は `HandleLab` の概要コメント（振り = 剣士の技 `SwordsmanBot.Current` / こんぼうの振り `ClubBot.Current` が出ている間 + 余韻 0.15 秒。刃筋のずれ = 当たる直前の刃の動く向きが、刃の面内（長さ × 幅）から外れた角度で 0° が刃で切る向き）。

## 弱い所（基準の表から。直す順）

1. **自分の武器で自分を削る**（ロングソード最大）。ロングソードは 1 試合に 44〜89 回・270〜470 セルを自分で失う（拳の相手でも失ったセル 470 はほぼ全部自傷）。
   技ごとの 1 振りあたり: unterhau 32 セル（224 振り・7178 セル）、stich 17、oberhau 13、zornhau 9。刀は nuki-do 12.3、kiriage 2.3、gyaku-kesa 2.4。こんぼうは Chop が自分の頭を 173 回打つ（383 セル）。
   `rosterleague`（5 人・各組 4 試合）でも konrad は勝率 19 %（最下位。受けた量 93、与えた量 60）、sean 69 %・jin 75 %。
2. **刃筋が立っていない**: 当たる直前の刃の向きが面内から平均 23〜35° 外れる（刀 23〜28°、ロングソード 32〜35°）。刀の当たりの 31〜59 % は峰が先（背で打っている）。
   経路（`SwordForms.FromKeys` の刃筋合わせ `FollowCut`）は動きの面に合わせているが、速い振りは体が付いてこられず（握りと剣の向きのずれ）、実際の刃が経路から外れる。
3. **こんぼうの Side（横振り）が弱い**: 当たった割合 65 %（Chop 76 %・Thrust 73 %）、1 振りで欠けるセルは Chop 36.6 に対して Side 21.9・Thrust 15.8。
   こんぼうの拳への当たりは 59 %（別の武器 60 %）で、同じ武器同士の 89 % より低い（動く相手を外す）。
4. 守り: 受けは 0（`SwordDefense.Adopted` は足と頭で外すだけ）、外しは刀同士で 9.2 回/試合。相手の振りのうち当たる割合は、ロングソード 75〜82 %・こんぼう 83〜89 %・刀 48〜70 %。

数字の読み方の注意: 40 秒の試合は K.O. が少なく、勝敗は引き分けが多い。勝ち負けの数は 12 試合で ±3 程度は揺らぐので、材料で見た差（自傷のセル・セルの差し引き）と合わせて見る。
