## パリー（手と腕の接触で拳の軌道を外へ曲げる）

基本動作のドリル（`basics` と同じ攻め手・受け手）。攻め手は 1 つの型（1 = ジャブ、2 = 右ストレート、3 = 左フック、4 = 右フック）だけを打ち続け、受け手は攻め手が打ち始めて合図の遅れだけ後に、決めた守りを必ず始める（反応の遅れを除き、守りの動きだけを比べる）。2 本 × 20 秒。
`最接近` = 打つたびに、拳が受け手の頭の中心へ最も近づいた距離の平均 [cm]（守らなければほぼ 0 = 当たる）。守りが拳の軌道を曲げた・頭を外した量。`手が触れた` = 受け手の手と攻め手の拳が 4 cm 以内に入った打つ回数（目標経路は手の置き場だけで、拳をそらすのは接触の力）。
