## すねで当てた方がダメージが大きいか（足の部位ごとの平均）

下の「足の部位ごと」の表（練習の前も後も混ぜた全部の蹴り）の通り、**すねで当たった蹴りの方がダメージは小さい**（すね 10.7、足の甲 14.4、つま先 16.5）。理由は、当たる瞬間の足の速さ（すね 2.7 m/s、足の甲 4.2、つま先 4.7 m/s）が違い、運動量（4.9 / 7.6 / 7.9）・エネルギー（7.5 / 17.3 / 20.6 J）がそのぶん小さいから。蹴りは膝・股を中心に振る回転で、当たる点が膝から遠いほど速い（すねの 0.55〜0.9 の点は足首の 55〜90 % の速さ）。ダメージはエネルギーに比例するほどは差が付かず（すね 1 J あたり 1.4、つま先 0.8）、これはすねの方が接触の面が広く骨が太いためと考えられる（接触の面積や材料の値ごとには分けて測っていない。物理の値は変えていない）。つまり「すねで当てるとダメージが大きい」は人形の物理では成り立たず、ここでは「すねの下の方で、狙った所に当てる」ことを先に満たし、その中でダメージを大きくしている（目的の順序はユーザーの指定どおり）。
