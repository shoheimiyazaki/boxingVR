# kicklab: Roundhouse（蹴る体 taeyun、すねの当てる点 ShinPoint 0.75、Overshoot -0.20、現在の Standoff 1.00、PhysicsVersion 42）

蹴る人が目標の間合いまで歩いて止まり、0.5 秒構えてから 1 本蹴る（目標 1.00, 1.05, 1.10, 1.15, 1.20, 1.25, 1.30, 1.40。止まる位置は足の運びで決まるので、表は蹴り始めの実測の間合いを 0.10 刻みに束ねる）。相手は構えて立つだけ。種ごとに左右の脚を替える。
`当たったすねの点` = 当たった瞬間の、膝 → 足首の線へ落とした割合（0 = 膝、1 = 足首、1 超 = 足の甲・先）。`帯内` = その点が 0.50〜1.20（下すね〜足首のそば〜足の甲）に入った当たりが渡したエネルギーの割合（腿・膝の軽い当たりを数えないため、エネルギーで重みを付ける）。
`エネルギー` = `HitEvent.Energy`（組織へ渡った J）。`/蹴り` は 1 本の蹴りで渡した合計。
