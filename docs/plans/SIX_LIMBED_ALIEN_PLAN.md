# 四足二腕のガルヴァ

- 体格データから前後二対の脚を生成し、既存の関節・脚 IK・支持多角形へつなぐ。前脚には既存の LegCommand を左右別々に通す。
- 両手に骨の鎌形ボクセルを付け、手首のサーボと既存の圧力・破壊モデルを使う。
- 選手データを名簿に追加し、前脚を使う入力経路を相手の位置から選ぶ。左右の動き、立位、代謝、接触、再現性をテストし、Arena で外観と動きを確認する。

## 操作

- デスクトップのキャラクター選択で「ガルヴァ」を選ぶ。標準操作では J と K（右・左クリック）が左右の鎌の突き。左 Ctrl を合わせると斬り払い。F は間合いと左右の位置から選んだ前脚の蹴りで、左 Ctrl＋F は横からの経路。
- 対人戦は 1P が F/G で両腕、T で前脚。2P は J/K で両腕、O で前脚。片方の Ctrl はそれぞれ左・右を使う。
- VR は `dotnet run --project games/MiniRing.Vr -c Release -- --player-char galva`。左右のコントローラで鎌の位置と向き、右トリガーで前脚の突き、左トリガーで前脚を横から出す経路。

## 設計

ガルヴァの体格、顔、教科書、前脚の技の頻度を `games/MiniRing/Characters/roster/galva.json` に置いた。身長は生成時の足裏から頭頂まで約 1.41 m。骨盤を前後に延ばし、既存の股・膝・足首・つま先を前後二対で使う。歩行時は一脚ずつ踏み替える。前脚を攻撃に使うときは、その脚を支持から外す。心臓・肺・血液の循環は既存のモデルを使い、後脚を脚の酸素容量の計算に含める。

鎌は骨の格子を前腕につなぎ、手首のサーボと装着部品のボクセル接触を共用する。突きと斬り払いは目標経路が異なり、当たり方は接触に使われた面と速さで決まる。前脚は左右の股からの目標距離を脚の長さで割って選ぶ。脚の可用性も考慮し、技が終わるまで選んだ側を保持する。

## 検証

- 高速テスト 675 件が通過。ガルヴァの四脚での立位と移動、両腕と左右前脚の追従、鎌と脚の接触、デスクトップ・VR の指令、記録の再生、装備指定のある団体への出場判定を確認した。
- 対象の 57 テストでカバレッジを計測し、計測対象の変更行 367 行のうち 328 行を実行した。計測器との互換性のため、今回変更していないエンジンと Bepu は計測対象から外した。
- Vulkan で VFC の試合を撮影し、四脚の歩行、両鎌の外観、相手に鎌が当たる場面を確認した。VR 実機での動作確認は未実施。

## 参照画像に合わせる改修

- 長い腕と大型の鎌、装甲の頭と胴、前傾した四足の構えを作り、物理で形と歩行を確認する。
- 刃元と切っ先を結ぶ線分を目標にする。助走、平面内の開始・終了、引き戻しを同じ入力経路で定義し、既存の腕と手首のサーボに渡す。
- 装備や姿勢の異なる相手でドリルを行い、目標と実際の刃先、接触で削れたボクセル、脚の安定性を比較する。

### 実装と練習結果

前腕と上腕の長さ方向の寸法を約34%伸ばし、刃元から切っ先までの直線距離を約51 cmにした。頭部の殻、顎、眼、胴と脚の装甲をボクセルで作った。首の骨と頸髄は既存の組織を使い、前傾した胴と外に張る肘・膝は各関節の目標として与える。

`ClawSegment` は刃元と切っ先の位置、および刃面のロールを指定する法線を受け取る。 `ClawStroke` は構えからの引き、加速する助走、切断面の中での開始と終了、振り戻しを定義する。入力は既存の腕と手首のサーボへ変換し、リプレイには変換後の位置と向きを記録する。手首が回転に遅れた分は、刃の中点が目標面に近づく方向へ腕の目標を補正する。鎌を採点する速度は接触位置の速度とし、長い刃が関節を通る場合は既存の関節接触も使う。

`dotnet run --project games/MiniRing.Arena -c Release -- clawlab` で再計測できる。ジンとマーカスに対し計72本を試し、直接削ったセルが最も多かった振り抜き0.24秒・助走係数0.75を採用した。練習に使わなかったラモンとアルバートは、振っている間に横へ動かした。各設定で左右の鎌と3種類の狙いを合わせて6本ずつ試した。

| 検証の指標 | 調整前 | 採用設定 |
|---|---:|---:|
| 鎌が直接削ったセル | 363 | 461 |
| 腕 / 首 / 胴のセル | 231 / 0 / 40 | 263 / 1 / 197 |
| 刃先の最大速度の平均 | 11.92 m/s | 10.36 m/s |
| 接触前の刃先と目標面の平均距離 | 12.2 cm | 16.7 cm |
| 試行後も立っていた本数 | 6 / 6 | 6 / 6 |

採用設定はこの検証で直接削れたセルを約27%増やし、刃先と面との平均距離は4.5 cm増えた。首のサンプルは1セルなので、首の命中精度には改善の余地がある。照準の運動と着弾後の破損は物理の結果として別々に計測した。

採用設定でナロンとの試合を撮影し、構えから両腕をそれぞれ振る動き、鎌による前腕の骨折、斬り払いの字幕を確認した。高速テスト679件が通過し、斬り払い・突きによるボクセルの削れと、刃の入力を含むリプレイの再現性を確認した。
## 昆虫型の体への改修

- 先に、前脚の真上にある一体胴、4 本の基節、尖った接地端を生成時のテストで確かめる。
- 胴の 2 つの損傷グリッドを溶接拘束でつなぎ、関節として曲がる腰をなくす。循環と呼吸は既存の胸部組織を使う。
- 各脚に横へ張る基節を設け、足の末端を下向きの跗節にする。既存の足首 IK は可動する基節側の股関節を参照する。
- 歩行、前脚指令、鎌、記録の再現性を回帰テストし、試合映像でも接地と輪郭を確かめる。

体格表の寸法は 140 cm・85 kg。各脚は基節・腿節・脛節・基部の跗節・先端の跗節の 5 節。外殻の先端を絞り、接地端には既存の損傷で縮む細いコライダーを使う。腿節の屈曲方向を左右外側へ広げて、前脚と後脚で前後の向きを変えた。

接写で基節の位置拘束が立位で最大約 11 cm 伸びることが分かり、付け根と腿節側の位置ばねを 45 Hz にした。静止姿勢で前後 4 本を測ったときの最大の開きは約 6 mm。リングのコーナーでは、後脚の接地端が縁に掛からないよう、胴の後方への張り出しの分だけ立ち位置を内側へ寄せる。
