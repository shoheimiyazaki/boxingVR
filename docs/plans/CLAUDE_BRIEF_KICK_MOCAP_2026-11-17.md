## データ（Claude が探して確かめた）

- **Szczęsna, Błaszczyszyn, Pawlyta: "Optical motion capture dataset of selected techniques in beginner and advanced Kyokushin karate athletes", Scientific Data 8:13 (2021)**, doi:10.1038/s41597-021-00801-5。
  データは figshare（collection 4981073）、**ライセンス CC0**（figshare の API で確認）。1 人分 `B0367.zip`（140 MB、https://ndownloader.figshare.com/files/24601574）、全 37 人 `Karate.zip`（9.9 GB）。
- 技の番号: S03 = 廻し蹴り下段（膝〜腰）、S04 = 廻し蹴り上段（肩〜頭）。E01 = 空、**E02 = コーチが持つミットを蹴る**、E04 = 相手。T01/T02 = 試し（各 3 本ほど）。
- 形式: C3D（Vicon Plug-In Gait）、**200 Hz**、長さは mm、Z が上。ラベルの例: 関節の中心 `LHJC RHJC LKJC RKJC LAJC RAJC`（股・膝・足首）、`LTOE RTOE LHEE RHEE`、骨盤の軸 `PELO PELA PELL PELP`（原点・前・左・上の点）、腿の軸 `RFEO RFEA RFEL RFEP`、すねの軸 `RTIO RTIA RTIL RTIP`、胸 `TRXO ...`、肩の中心 `LSJC RSJC`、頭 `HEDO ...`、ミット `Tarcza:Tarcza1..6`、重心 `CentreOfMass`。
- 読み方: `tools/mocap/c3dread.py`（Claude が書いた最小の C3D 読み。浮動小数・整数の両方）。`tools/mocap/kicks.py` で足首の速さの山を出すと、B0367 の E02 は **右脚の回し蹴りが 12 本**（下段 6・上段 6）。足首の最高の速さ 8〜12 m/s、その瞬間の股-膝-足首の角 72〜105°（膝はまだ曲がっていて、伸びきる前に速さの山）。

## やること

1. **データをリポジトリへ**: 蹴りの区間（各蹴りの前後、構えから戻りまで）だけ、必要なラベル（上の関節の中心・骨盤・腿・すね・胸・肩・頭・つま先・かかと・ミットの点）を、小さな文字の形式（CSV か JSON）にして `data/mocap/kyokushin/` へ。README に出典・CC0・引用・切り出し方を書く。変換は `tools/mocap/` の Python（`py -3 -I`）でよい。
2. **ゲームで読む**: `games/MiniRing/Motion/` に読み込み（例 `KickCapture`）。各フレームで、蹴る脚について体フレーム（骨盤の向き。蹴りでは腰が回るので、構えの向き・相手（ミット）への向きとの差も出す）での **膝の位置（脚の長さで割る）・腿の軸まわりのねじり・膝の曲げ**、それと **骨盤の回り（体の向き）・胸のひねり・軸足の位置**、ミットの位置。当たる瞬間（足/すねがミットにいちばん近い・ミットが動き出す）で時刻をそろえる。
3. **膝の制御へ当てはめる**: 人の蹴りの膝の経路・ねじり・曲げ・体の向き・胴のひねりを、人形の脚の長さの比で縮め、時間は体の大きさの比の 1/√（刀と同じ考え方）で、回し蹴りの技の値にする（下段・上段の 2 つ。人の 6 本ずつを平均するか代表を選ぶ。どれを採ったか書く）。今の段 2 の手作りの経路（`KneePath`）は比べもの用に残してよいが、既定は人の動きから作った方にする。ねじりの 0 の定義が人のデータ（Plug-In Gait の膝の角）とゲームで違うので、どちらでも同じ幾何（すねの向き）になることを数値で確かめる。
4. **確かめる**:
   - 人の動きを棒人間で描いた動画と、人形が膝の制御でなぞった動画（真横・前、0.25 倍スロー、構えて立つ相手へ）。コマを PNG に抜いて自分の目で見て、膝の上がり方・回り方・伸びる拍子が人のものと似ているか比べる。
   - 当たったすねの点・相手の当たった所・ダメージ・運動量を、今の回し蹴り（手作り・段 2）と並べて表に（`docs/arena/kick_mocap_*.md`）。
   - テスト: 読み込み（ラベル・フレーム数・200 Hz）、膝の曲げ・ねじりの取り出しが既知の形（立った形でほぼ 0）で正しい、人の動きから作った回し蹴りが相手に当たる。
5. 版: 判断（技の経路）を変えたら `LogicVersion`。体の物理は変えない。`docs/TAEKWONDO.md`（と `docs/SWORD_MOTION.md` の流儀で出典）に書く。全テスト（Probe 除く）を最後に 1 回。
