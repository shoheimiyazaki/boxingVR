問いへの答えは「貫手で目の組織を削り視界を落とす例はあるが、全手形で急所を十分に壊せるとは言えない」。90本合計で眼組織の欠損は3セル、脳・心臓・肺・肝臓は0、腸は1セル。臓器の打撲と機能低下、頭のねじれによる意識低下は、組織の欠損がなくても発生する。

## 期待と結果、その原因

- **柔らかい所へ貫手が入り得る**: 目狙い・種2で眼組織2セルと左視界40%の低下を確認した。正拳の目狙いは3本とも眼組織欠損0。総欠損だけでは分からなかった限定的な成功である。
- **腹に必ず深く入り臓器を削るとは言えない**: 腹部臓器欠損は腸1セルだけ、肝狙いでも肝欠損0。一方で打撲が起きており、力が臓器へ全く伝わらない接続切れではない。みぞおち狙いの貫手の心肺供給終値は0.1963、正拳0.5470。肝狙いの一本拳では心肺供給0.0775となり、狙った臓器以外にも効く。打撲モデルは打点から各臓器までの距離で配分するためである。
- **骨上で指が負ける現象は確認できない**: 貫手・一本拳等の指骨欠損は0。頭狙いの局所欠損0が多く、頭蓋への強い集中接触を確認できていない。骨標本へ同エネルギーで打つ比較なしに指骨モデルの妥当性を断定しない。
- **狙い点と実眼セル・実打点のずれ**: 撮影した貫手→目・種1の最寄り採点命中は、狙い点から7.569mm、最寄りの実眼セル中心から13.583mm離れ、接触面は皮膚だった。眼欠損も視界低下も0。TargetMap.Eye は頭寸法比による推定点で、顔ごとの実眼セル中心を参照しない。Targeting.Clamp も目標を可動範囲へ収め、手は物理追従で遅れる。目を指定するだけでは眼球に当たらない。
- **近くても圧力・深さが足りない例**: 上記貫手の命中歩は接触圧力3.188kPa、法線接近速度0.811m/s、削れ/潰れ0。一本拳→みぞおち・種1の最寄り命中は39.940kPa、1.673m/s、削れ/潰れ0。正拳の最寄り採点命中は接触圧力・法線接近速度とも0。歩の前の拳速度による採点と、接触の法線方向の圧力は別の物差しである。この3歩だけで全接触の優劣は導けない。
- **手形が接触で無視されるバグは再現せず**: Drive→SetHandShape→BareHandState.Build→VoxelContact.Resolve の接続を確認した。形は共通式へ渡る。ただし元の拳セルの幾何変換で、指関節や実際の一本の指先の形ではない。貫手の拡大コマもセルが間隔を空けて伸びた形に見える。この既知の近似は「細い面になるはず」を保証しない。
- **臓器の削れと打撲の違い**: VoxelContact は接触面積・材料のたわみ・応力・残エネルギーで破壊する。面の下では圧力を深さとともに広げ、材料強度より大きく、強度×セル体積の仕事を賄える場合だけ潰す。打撲は ApplyHit→BruiseOrgans の距離減衰を別途通る。打撲が強いことと臓器組織の削除は同じ現象ではない。

直し方の候補は、実眼セルから狙い点を求めること、クランプ前後の目標と実打点を追跡すること、指・節の姿勢と連続する組織で手形を組み立てること、軟組織/骨標本への同エネルギー実験。今回は物理・材料値の調整や倍率で数字を合わせていない。

## 直したこと

1. 発動数と命中数を分離し、急所内部の損傷と機能、局所/外側、各本の生値を追加した。
2. 旧ドリルは急所重み1でも中心狙いの重み1が混ざっていた。ドリル専用 forcedAim を追加し、混入を防ぐ回帰テストを追加。未指定時の通常の判断・乱数消費は維持。判断版30→31。
3. ケース名で攻め手の顔形状まで変わる交絡を除くため、攻め手名を共通化した。
4. 試作測定器の「へこみ移動を欠損と数える」誤集計を修正。Shiftだけでは欠損が増えない回帰テストと、目/脳/各臓器/遠隔損傷を分けるテストを追加した。
5. 採点されない接触の意識低下も記録し、ラウンド終了で停止して新品の体を混ぜないようにした。
6. 測定と同じ台本での撮影を追加し、再撮影の古い末尾コマを混ぜないようffmpegへフレーム数を明示した。

## 検証と残る限界

- Releaseビルド成功（警告0・エラー0）。
- `dotnet test tests/MiniRing.Tests -c Release --no-restore --filter "FullyQualifiedName!~Probe" --logger "trx;LogFileName=karate-vitals-final.trx"`: 647件成功・失敗0・スキップ0、3分23秒。新規4件を含む。ログ `.karate-vitals-tests-final.log`、TRX `tests/MiniRing.Tests/TestResults/karate-vitals-final.trx`。
- NuGet復元では、このプロセスのAPPDATA/LOCALAPPDATAを作業ディレクトリ内へ置き、既存の `C:\Users\smiya\.nuget\packages` とリポジトリのNuGet.Configを明示した。外部設定ファイルは変更していない。
- 終値は時間・回復・KO打ち切りの影響を含む。蓄え・供給の/命中も試合全体の低下累計で、打撃単独の因果量ではない。
- 意識最大落ちは240Hz歩の差分。同じ歩の複数接触は合計となり回復が差し引かれる。LastHeadTwist は歩内の最後の呼び出し値で、真の全接触ピークは保証しない。
- 局所は初期の目/こめかみ側に固定。途中で狙い側が変われば外側になる。接触記録の破壊位置で数え、移動した各セルの個体追跡ではない。
- VisionState は元位置の眼組織HPから算出される。組織の移動でも低下し得るため、材質の欠損と区別して解釈する。
- 指骨の台帳は梁の曲げ破断を検出するものではなく、手形は解剖学的な指関節の運動ではない。
- 種1～3の結果で、相手・体格・速度を広げた一般化、同エネルギー比較、全急所の破壊成功率は未検証。
- 撮影の再実行は命中数・総欠損数が測定と一致することを確認。全状態チェックサムの一致確認ではない。
