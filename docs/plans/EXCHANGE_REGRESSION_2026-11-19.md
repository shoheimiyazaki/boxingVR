# 打ち合いが弱くなった・触れていないのに倒れる: 原因の調べ（2026-11-19。直した結果は §9）

## 結論

原因は別々の枝から入った 2 つ（と、その一方が悪化させる 1 つ）。

1. **打撃が約 1/3 の強さになった** = 枝 `rush-physics` の **77be881**（「体の質量は体自身の動きの分だけ」、PhysicsVersion 45）。master の履歴へは第一親の **ca1244b**（master を枝 spacing-control-features へ取り込んだ merge。ca1244b の第一親 b2181b8 は間の層・戦略の層の枝で、第二親側に rush-physics と merge-grappling が入っている）で入った。拳に乗る質量が 2.7 kg → 0.6 kg、1 発のダメージが 8.7 → 2.9。当たりの数は変わらない。
2. **触れていないのに倒れる** = 枝 `merge-grappling` の **2ce39a8**（支えのモデル、PhysicsVersion 47）。捕捉点が足の凸包から出ると立たせる力が連続に抜ける（`Fighter.Balance`）。足の運びが間に合わず、打たれていなくても倒れる。
3. **軽い一撃（ダメージが小さい当たり）でも意識が飛ぶ**（1 を悪化させる）= 77be881 の `ConcussionGain` ×100。平均で合わせた校正で、頭のねじれ ω² に効くので、体が乗った当たりの意識の引きが以前より大きくなる（1 発の最大 3.9 → 10〜20）。ダメージ（得点）は 1/3 なのに意識（KO）は 2〜3 倍効く。

## 3. 仕組み 1: 打撃が弱い（77be881）

変更は `PunchMechanics.LimbDrive / BodyClosingSpeed / BodyCarry` と `BoxingGame.BodyFactor`。

- 以前: `ImpactMass = 腕の質量 + 連結度 × 体の有効質量`（体の質量 × 拳の速さで運動量が湧いていた）。拳 1 発の質量 2.7 kg、体の割合 0.82〜0.84。
- 後: 体の分は `押し出し × 体自身が当たりへ近づく速さ ÷ 当たる速さ` だけ。拳の質量は **0.6 kg、体の割合 0.34**（体を止めて腕だけ伸ばす拳は 0）。運動量 p = 質量 × 速さは 2.75 × 1.6 ≒ 4.4 → 0.6 × 1.9 ≒ 1.1。
- `PunchMechanics.Damage = (√p − √0.25) × 11 × Sharpness`。`MomentumThreshold = 0.25` と `DamageScale = 11` は据え置き（77be881 のコメント: 「境目は変えない。0.05 にすると押し付けの当たりが 108 → 204 回に増える」）。p 4.4 → 1.1 でダメージは 17 → 6.3。実測の 1 発 8.7 → 2.9（Sharpness などを含む）。
- 当たりの数は 171 → 172 のままで、1 発の強さだけが 1/3、合計ダメージが 562 → 192（CS）・686 → 188（CSl）。
- 同じ質量は削れ（`HitEvent.Energy = ½ m v²`）と押し込み（`CarryBody` の `carried`）にも使われるので、見た目の削れ・体が持っていかれる量も約 1/4 に下がる。
- 77be881 の記録（docs/arena/rush_physics.md）が校正したのは「ダウンの回数」（`ConcussionGain` ×100）だけ。**得点のダメージの尺度（`DamageScale`・`MomentumThreshold`）は校正されていない**。

## 4. 仕組み 2: 軽い一撃で意識が飛ぶ（77be881 の `ConcussionGain` ×100）

`TwistHead` は `Concussion += gain × ω²`（ω = 頭の慣性で割った回転速さ [rad/s]）。77be881 で gain を 0.000035 → 0.0035（×100）にした理由は「運動量が約 1/7〜1/25 になった分を埋める」（`FighterTuning.ConcussionGain` のコメント）。

- 運動量が 1/r なら ω² は 1/r²。×100 は r ≒ 10 の平均で合わせた校正。当たりごとの r は違う（腕だけの手打ち r ≒ 25、体が乗った一撃 r ≒ 4〜7）ので、体が乗った一撃は以前の 100/r² ≒ 2〜6 倍の脳しんとうを出す。実測: 1 発の増分の最大 3.9 → 10〜20、p90 1.41 → 2.1〜2.8。
- 種 4・champion:swarmer の 02c8c68（`Fighter.TwistHead` と `CarryBody` に記録を足した検証用の worktree で実測）:
  - t=18.72 s: 速さ 2.62 m/s、質量 0.67 kg（体の割合 0.51）、ダメージ 9.1 の頭への当たり。頭の回転は打撃の分 13.1 rad/s + 接触の分 1.7 rad/s で 14.7 rad/s、`0.0035 × 14.7²` = +0.76、意識 0.19・張り 0.12 でダウン。
  - t=37.73 s: 速さ 3.41 m/s、運ぶ運動量 0.67 kg·m/s、こめかみで 35.5 rad/s → +4.40。
  - 同じ試合の、体の乗らない当たり（2.74 m/s・質量 0.33 kg・体の割合 0）は 3.5 rad/s で +0.045。
  - つまり意識を飛ばすのは「速さ」でなく **体が乗って運動量が運ばれた当たり**（連絡のあった 1.47 m/s・質量 0.98 kg・体の割合 0.66・ダメージ 7.7 で +1.23 も同じ型）。接触の力積から来る回転（`alsoTwist`）は 0〜3.5 rad/s と小さく、原因ではない。
- 以前の版で同じ当たりが +1.6 ほど（ω が 4〜6 倍、gain が 1/100）というのは比からの見積もりで、以前の版で同じ瞬間は再現していない。
- 反事実（02c8c68、同じ 8 試合、基準 = ダウン 3.4・ダメージ 184・当たり 70 / 試合）: `ConcussionGain` 0.0035 → 0.001 でダウン 1.5、ダメージ 275、当たり 101 / 試合（打ち合いが続く）。0.00035 でもダウンはさらに減る。**原因の切り分けであり採る値ではない**（使っていない種で比べ直していない）。

## 5. 仕組み 3: 触れていないのに倒れる（2ce39a8、支えのモデル）

2ce39a8 が入れたもの: `Fighter.Support.cs`（支持多角形、`Balance`）、`SupportPolygon`、足の運びの着地点。立たせる力すべてに `Balance` を掛ける（`SupportModel.Soft`）。

- `Balance = (1 − 外れ / L)²`。外れ = 捕捉点（重心 + 水平の速さ / ω、ω = √(g / 重心の高さ)）が、足の凸包 + 踏み出し足の着地点の外へ出た距離。`L = SupportRecovery (0.5) × 脚の長さ`。
- 02c8c68 の種 4、赤（champion）が 12.08 s・20.75 s・29.92 s（検証用 worktree の記録）に打たれず倒れる: 脳しんとう 0、張り 1.00、意識 1.00、スタミナ 0.95〜1.0、直前の当たりから 1.0〜2.1 秒（12.08 s は当たりの 1.3 秒後）。
  - 倒れる前 0.5〜0.7 秒: 重心の水平の速さ 0.25〜0.55 m/s と普通、相手との距離（重心どうし）は 0.2 付近で組み合いの距離。重心の支えの余裕 `SupportMargin` が負（凸包の中）から +0.01 → +0.08 m へ出て、`Balance` が 1.0 → 0.00（0.4〜0.5 秒）、`VerticalBalance` が 0.08〜0.2 になって立たせる力が抜け、足が浮く・傾く → `Enter(Down)` で崩れる。
- 反事実（02c8c68、同じ 8 試合）: `SupportRecovery` 0.5 → 1.0 で「打たれず倒れた」が 11 → 1、2.0 で 0。1 試合のダメージは 184 → 212（1.0）。
- 2ce39a8 単独でも、77be881 を含まない b2181b8 → 2ce39a8 で「打たれず倒れた」は 2 → 17（CS・CSl の 4 試合ずつの合計）、77be881 だけ（支えなし）では 0。**この症状は 2ce39a8 のもの**。
- 同時に当たりの数が減る（CS 130-67 → 75-45）。倒れ・起き上がりの時間が打ち合いを食う。

## 6. 提案する直し（§1: 物理で、閾値や場合分けではなく）

1. **ダメージの尺度を、新しい運動量に合わせる（1 つの係数）**。77be881 は運動量を約 1/4 にしたのに、運動量 → 得点の換算（`DamageScale`）を据え置いた。`MomentumThreshold`（「触れただけ」の得点の決まり。0.05 にすると押し付けの当たりが増える）は変えず、**`DamageScale` を √(運動量比) 倍（約 2.2〜2.5 倍、11 → 約 25）**にして、典型の拳 1 発が以前の 7〜9 に戻るかを測る。`MaxDamage = 40` も同じ比で見直す（本当は最大の削れ = 材料の強さから決めたい）。押し付けの当たり（`ClosingSpeed` と `Sharpness` で 0 に近い）は増えない。`PhysicsVersion` を上げる。
2. **脳しんとうの尺度を 1 つにする**。今は拳が `ConcussionGain` 0.0035、床の衝撃が `CanvasConcussionGain` 0.000035（100 倍の差、docs/DEBT.md の近道）。体が乗った一撃で ω が 14〜35 rad/s になって、軽い当たりで意識が飛ぶ。
   - 直し方は、拳の係数を ×100 に置かず、**頭と首が受けるエネルギー（½ I ω²、I = 頭の慣性）が首・脳に運ぶ量として、床の衝撃と同じ係数で出す**こと。ω² は同じだが、頭を打つ当たり 1 発で 1.0 を超える（意識が全部飛ぶ）ことが無いか、`Metric_concussion` の p90・最大と「意識を飛ばした一撃のダメージ平均」が以前（約 28）に近いかを測って決める。
   - まず `ConcussionGain` を 0.001 前後に下げた値を、使っていない種・別の組（boxer:champion ほか）で比べ直す（`PairedEvaluation.Confirm` の決まり）。
3. **支えのモデルは足の運びを先に見る**。組み合う距離（0.2）では足を踏み替える余地が無く、`Footwork.Landing` が間に合わないまま捕捉点が出て `Balance` が抜ける。`SupportRecovery` を 1.0 にするのは効く（11 → 1）が、足を払われて倒れる崩しの物理（`throwlab`）まで弱める。**踏み出し足の着地点を捕捉点の予測（水平の速さ ÷ ω）に合わせる足の運び（`KeepCaptureOverFeet`・着地点の選び方）を、打つ・退く速さに追いつかせる** 側を `Trace_falls` で調べてから、効かなければ `SupportRecovery` を最後に採る。
4. 直す前後は `Metric_bouts` と `Metric_concussion` で比べる。使っていない種（8〜11）・別の組でも確かめる。版（`PhysicsVersion`・`docs/VERSIONS.md`）、`docs/BOXING.md`・`docs/DEBT.md`・`CLAUDE.md` §8 の「意識」「拳に乗る体の質量」を合わせる。

### 9.3 足の運び（採らなかった直し）

倒れる前の記録（`Trace_falls` に足の運びの着地点・捕捉点を足したもの）: 捕捉点が前足の横（後ろ足の側）へ流れると、足の運びは前足を選び、構えの制約（左足は右足より左・前）で前足が捕捉点の側へ出られず、同じ所で 0.1 秒ごとに踏み直し続けて、支えの残りが 1 → 0 へ抜けた。

試した形と、打たれずに倒れた数（champion:swarmer + counter:slugger、種 4〜7 の 8 試合。前は 11）:

| 今の捕捉点へ | 6 | 前へ歩くと倒れる（`GrapplingTests.WalkingInEveryDirection`） |

連打する側の腕の酸素（左右の小さい方、5 秒ごと、6 試合の平均）: 直した後の連打 vs 溜めで 0.99 → 0.62 → 0.43 → 0.15 → 0.11 → 0.03 → 0.01 → 0.00 → 0.00（35 秒で尽きる）、連打 vs CPU で 0.99 → 0.81 → … → 0.22。溜める側は 0.95 以上のまま。

- **連打はまだ最強**。呼吸と循環のモデル（PhysicsVersion 52）は連打する腕の酸素を 35 秒で使い切らせるが、尽きた腕でも当たりは数えられ、勝敗は変わらない。脳しんとうの 100 倍を外した後のほうが、連打は 1 発で倒されにくくなって強くなった（6-0）。
- 新しい倍率は足していない。物理の直す方向の提案: (1) 腕の酸素が尽きたら、腕の筋肉が出せる力（関節のトルクの上限）を届く酸素の分まで落とし、拳の速さ（とその 2 乗の削れ）が落ちるようにする（今は `HandSlowness` の遅れが小さく、尽きた腕の当たりも 2.7 点のまま）。(2) 押し付け・腕だけの軽い当たりを打撃に数える境目（`MomentumThreshold`・`Sharpness`）を、力（運動量 ÷ 接触時間）で決める。(3) 得点を √運動量 でなく運動エネルギー（½ m v²）か壊れた組織で数えれば、数で稼ぐ軽い当たりより体の乗った 1 発が勝つ（得点のルールなのでユーザーの判断）。
- 台本の「溜め」は間合いの読みが下手で、手数が少ない（CPU 相手に 0-6）。ボットの拳（champion）も連打に負けている。

### 9.5 打撃 → ダメージ → 脳しんとうの道の係数（ほかの何かを埋め合わせるだけの値）

| 係数 | 何を埋めているか | 物理の量に置き換えられるか |
|---|---|---|
| `ConcussionGain` ×100・`CanvasConcussionGain` | 77be881 で拳の運動量が減った分を、拳の側だけで埋めた | **置き換えた**: `ConcussionSpin` 40 rad/s（意識を飛ばす頭の回転の速さ、1 つ） |
| `LimbDrive`（押し出し） | 関節の固さ・突っ張れるかを動きの割合で読む近道。`BodyCarry` と二重に数える | 二重の数えは外せる（9.1）が、押し付けの点・崩しの効き方まで変わるので外していない。本当は肘の曲がりと関節のトルク × 接触時間 |
| `DamageScale` 11・`MomentumThreshold` 0.25・`MaxDamage` 40 | 得点のルール（√運動量）。2.7 kg のころの運動量で決めた値のまま | 得点はルールで物理の量ではない。尺度を決め直す（1 発 2.7 → 8 点）か、運動エネルギー・削れた組織で数えるかはユーザーの判断 |
| `Sharpness`（0.35〜0.8 m/s の滑らかな段） | ゆっくり押し当てた接触を打撃に数えない | 力 = 運動量 ÷ 接触時間で数えれば物理になる（接触時間は Bepu の接触から測る）。今回は入れていない |
| `KnockbackTransfer` 0.6・`MaxKnockbackSpeed` 0.6 m/s | 跳ね返り（反発）をまとめた割合と、押し込みの上限 | 反発係数（材料）に置き換えられる。上限は測り違いの守り |
| `StrikeShare` 0.55・`FullStrikeSpeed` 2.5 m/s・`MaxStrikeSpeed` 6 m/s | 当たった部位に残す運動量と全身へ配る運動量の分け方（首の固さ・接触時間の代わり） | 運動量を全部頭に掛け、首の関節がつないだ体へ運ばせれば物理になる |
| `CarvePerJoule` 12・`MaxCarve` 120 | 素手の拳の削れ（グローブはボクセルの接触で削る） | 拳もボクセルの接触で削れば消せる |
| `BodyToFistEfficiency` 0.5・`BodyToFistTime` 0.04 s | 体の運動エネルギーを拳へ移す運動連鎖。胴の運動量は外からの力積で消し、腕にはサーボの目標の先走りとして渡す（運動量が保存しない） | 関節の力で胴から腕へ運動量を渡せば物理になる |
| `LeverTransfer` 0.55 | 肩・肘を固めて腕の線に直交する力を伝える割合 | 関節のトルクの上限から出せる |
| `ZoneDamage.Multiplier` | 部位ごとの得点の倍率 | 得点のルール |
