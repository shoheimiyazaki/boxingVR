# やりたいこと（2026-11-19、ユーザーから）

片付け（剣・CT の体・グローブ v2 の取り込みと、残る既知の失敗の直し）が終わってから始める。始めるときは 1 項目ずつ作業セッション（docs/WORKFLOW.md）に分ける。

## すぐに始めたいこと

1. **ボクサーを増やす**: IVF が階級別になったので、各階級にボクサーが欲しい。ボクサーごとの個性も（§1.8: 体と教育の 1 ファイル）。
2. **眼球で意識の状態を知らせる**: 意識を失っている・死んでいる・朦朧としているなどを、キャラの目で見せる（§1.7 の「見える手がかり」）。
3. **VR で動きを記録してお手本を作る**: 各武器に加えて柔術も（docs/VR_MOTION.md の `.vrmotion` と `imitate`）。
4. **関節を極められるラグドール物理**: 柔術に向けたアップデート（docs/GRAPPLING.md）。
5. **VR の UI を充実させる**: インタラクティブな UI。
6. **VR の三人称の視点の操作**: 自分の向きとキャラの向きが違うと操作しにくい。リングを回転させて、常に自分とキャラの向きがそろうようにする。コントローラのスティックでも回せる。
7. **モードの切り替えを直感的に**: 一人称でキャラに入る、三人称でキャラを操作する、部屋の中を歩き回る、の切り替え方。案: VR 空間の中でさらに FPV のヘルメットを被る、操作パネルの上に立つ。
8. **歩き回りモードでキャラに触れる**: ラグドールを人形のように掴める。
