# 報告: 棒術（木の六尺棒）と棒術家 1 人（2026-11-16）

**完了**（指示書の項目は一通り入れた。弱い所と確かめていない所は末尾）。ワークツリー `.claude/worktrees/bojutsu`（ブランチ `claude/bojutsu`）の中だけ。コミットは 1 つ（ワークツリー内、プッシュなし）。

## 棒の形と握り

- `WeaponKind.Staff`（`Weapon.cs`、enum の末尾に追加。既存の値は変えていない）。長さ 62 cm（基準体格の身長 0.355 × 1.75 m）、半径 6 mm の丸い断面が全長で一定、両端は半球、材質は木だけ（棍棒と同じ。材質の値は変えていない）、2.5 mm のセル、質量 52 g（木の密度 × 5184 セル）。打つ所は**両端**（`Weapon.StrikeEndsX`）。`IsBlunt`・`CanTwoHand`・`.vox` の直せる種類に足した。
- 握り: 真ん中をはさんで 11 cm 離した両手（人形の肩幅 10.7 cm を測った）。右手が +X 側、左手が −X 側（`TwoHandGripsOf`）。棒の向きは両手の位置の差で決まる（`Fighter.Support`: 右手の指令から決まる握りの上の位置へ左手が握りに行く。刀・ロングソードと同じ道）。握りの持ち替えは入れていない。
- `BothHands_HoldTheStaff_AShoulderWidthApart`（2 つの拳の間隔 = 握りの間隔 ± 2 cm、肩幅 ± 1 cm）で確かめた。

## 技（目標の経路）

`Motion/StaffForms.cs`（`SwordForms.FromKeys` と同じ作り。キーは右手の位置・棒の向き・歩き・前傾・胴のひねり。姿勢は書かない）。5 つ: **tsuki**（突き）・**uchi-oroshi**（打ち下ろし、真上から）・**yoko-uchi**（横打ち）・**ashi-barai**（足払い）・**gaeshi**（返し: 前の端で打ち下ろし、棒を縦に回し続けて後ろの端が頭の上から打ち下ろす）。どちらの端で打つかは判断に書かず、棒の向きの経路で決まる。間合いは「いちばん前へ届く端」の届く距離（`StrikeDrill.ReachOf` を端ごとに求めて大きい方。端が 1 つの武器は同じ式・同じ答え）。受けの経路は技ではなく、既存の `WeaponDefense.Parry`（来る線に棒の中ほどを横たえる）を使う。

棒の後ろの端は右手より 1.9 腕の長さ後ろにあり、棒の線が体を通ると自分に当たる。素案（1 技 27〜371 セルの自傷）を、体の箱（`SelfClearance.Nearest`）と肩からの届きを数える探索で直して、構え・キーを体の右側へ置いた（`docs/BOJUTSU.md`）。打ち下ろしは打ちを 0.28 → 0.5 秒にして、先のずれが平均 0.36 → 0.09 腕の長さ・試合の自傷 4.5 → 0.5 セル/振りになった。返しの打ちを同様に延ばすと悪化したので元のまま。

## ボットと教科書

試合の棒術家は刀・ロングソードと同じ `SwordsmanBot`（`FormSwordsman` が型・構え・両手の間隔 0.585 腕の長さ・握りから先までの長さを渡す）。棒専用の判断のコードは無い。判断の値は教科書 `Bots/weapons/staff.json`（`WeaponStyle`、`education.weaponBot` で上書き可。`WeaponCatalog`・`WeaponEducation`・`HasBot` に足した）:

| 値 | 内容 |
|---|---|
| `Defense` | `SwordDefense.Adopted`（足と頭で外す。刀と同じ） |
| `HitAndAway` | 既定値（Margin 0.06・Lunge 0.35・OpeningTime 0.4・Patience 1.2・Circle 0.35・Debana true） |
| `Pacing` | 刀と同じ（0.25・0.6・0.15） |
| `Rest` / `MinReach` / `KeepReach` | 0.6 / 0.33 / 0.35 |
| `TechniqueWeights` | なし |

`HitAndAway` なし（A）と既定値（B）を各 20 試合で比べ、B を採った（6-9-5・セル差 +12・得点 36/79 対 4-8-8・−102・34/122。自傷は B が 144、A が 106 セル/試合）。

「武器の種類で判断を分けず」: 種類での分け方が残る所は、`FormSwordsman` の型・構え・間隔の表（刀・ロングソードと同じ）、`IsBlunt`/`CanTwoHand` の一覧、`MatchSelection.TwoHanded`（`FormSwordsman.Handles` に置き換えたので種類の一覧は 1 か所）。判断の式（選び方・守り・間合いの取り合い）は武器で分かれていない。受けの体からの距離（`Clearance`）を後ろの端まで見る `WeaponDefense.Parry` の `rearLength`・`SwordsmanBot.RearLength`・`FormSwordsman.RearLength` を足した（端が 1 つの武器は null で今までと同じ）。

### 弱い所

- 勝ち越せていない（刀・ロングソード・こんぼうに対してほとんど勝てず、受けた得点が与えた得点の 2〜3 倍）。引き分けが多い。
- 自傷が 1 試合 111〜114 セル（刀 7〜79、こんぼう 13〜30、ロングソード 137〜235）。内訳は上腕・胸・腰・頭。技の外（構え・歩き・倒れる）の頭への自傷（rear 端）も残る。
- 足払いが振りの 3〜4 割を占める（間合いがいちばん短い）。足払いは腰・腿の高さまでしか下がらない。
- 返しの 2 打目（後ろの端）は勢いが少なく、試合で後ろの端が当たる割合が低い。返しは経路への追従も悪い（先のずれ平均 0.48・最大 2.0 腕の長さ）。
- `Parry`（受け流しの構え）は試合の既定では使われない（教科書の守りは足と頭で外す `Adopted`）。刀に対し `Parrying`（受けながら外す）にしても、棒術家の失うセルは守りなしより減らなかった（2103 対 2063 セル）。棒を横たえた受けの構えを固定で置くと、刀が体から削るセルは棒を下げた構えの 9/42 に減る（`BojutsuTests`）ので、棒は受けられるが、ボットが受けを選んでうまくいく形にはなっていない。

## §8 に足した近道（`CLAUDE.md`）

(1) 型は手作りのキーで、体の箱・肩の届きを数える探索で直した設計の近道（体は目標から遅れるので自傷が残る）。(2) 両手の握りは棒の真ん中をはさんだ固定の 2 点（持ち替えなし）。(3) 打つ端が 2 つあることを `StrikeEndsX` と種類の一覧に足した。間合い・相手の棒の切っ先の読みは端を選ぶが、自分の武器の折れ・欠け（`FarEdge`・`WeaponSense.Lost`）は +X の端だけを数える。(4) 受けは刀と同じ `Parry`（真ん中を使う形ではない）。(5) 足払いは腰・腿の高さ。(6) 返しの 2 打目は勢いが少ない。
