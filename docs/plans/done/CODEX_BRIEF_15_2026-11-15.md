# 作業指示 15（2026-11-15）: P0b — 雑音を測り、対にした評価で差を言う道具を作る

**作業指示 14（P0a）の後に始める**。最初に `CLAUDE.md`（§1.6・§4・§10）、`docs/LEARNING_PLAN.md` §9、`docs/WEAPON_DEFENSE.md` の guardspar の不採用の記録、`games/MiniRing.Arena/MatchTrainer.cs`・`DefenseTuner.cs`、`games/MiniRing/Bots/BotArena.cs`・`DefenseDrill.cs` を読む。日本語。コミット・プッシュはしない。

## 背景（Claude が決めたこと）
- 今の調整器は (1+λ) で一番の候補を拾うので、運の良い候補が残る（勝者の呪い）。guardspar・awaylab は使わなかった種で比べ直すと負けて不採用になった。次の段（CMA-ES）の前に、**評価がどれだけ揺れるか**と、**揺れの中で差を言う方法**を作る。
- 試合は種と値で完全に決定的（§1.6）。だから同じ値を同じ種で 2 回測ると差は必ず 0 で、それでは雑音を測れない。雑音は「種を変えたときの揺れ」と「ごく小さく値を変えたときの揺れ（体の動きはカオス的で、わずかな違いで軌道が分かれる）」の 2 つで測る。

## やること

### 1. 点の式を共通にする
- `MatchScore.Of(wins, losses, dealt, taken)` = 勝ち − 負け + 0.9 tanh((与えた − 受けた) / 400)（今の `MatchTrainer.Evaluate` の式）を 1 か所に置き、`MatchTrainer` もそれを使う（`MatchTrainer` の結果は変えない）。
- **試合の 1 標本** = 1 つの種 × 決めた相手の全員 × 両コーナー（`BotArena.Pair` の 2 試合）。その合計に `MatchScore.Of` をかけたものを 1 標本の点にする。全体の合計にかける今の `MatchTrainer` とは尺度が違うことを、`evo_noise.md` に書く。
- 自分の名前が相手と同じだと集計が混ざる。`MatchTrainer.Evaluate` のように名前に印を付ける。
- **ドリルの 1 標本** = 1 つの種のドリル。点は**比でなく差**にする。例えば守りなら、種ごとの（守らない受け手の被ダメージ − 被ダメージ）と打ち返しのダメージ。比は、基準のダメージが 0 に近い組で膨らみ、裾が重くなって検定の前提が崩れる。比は今どおり合計から出す。
  - そのために `DefenseTuner.Evaluate`・`Aggregate` を、種ごとの結果の配列を返す `internal` にする。`DefenseTuner` の今の点（合計からの比）は変えない。

### 2. 対にした評価 `PairedEvaluation`（`games/MiniRing.Arena/PairedEvaluation.cs`）
- 2 つの値 A・B を同じ種の組で測り、種ごとの差 d_i = 点(A) − 点(B) を集める（共通の乱数）。
- 返すもの: 標本の数、平均の差、標準誤差、95 % 信頼区間（**t 分布**の臨界値。n = 8 なら約 2.36）、符号検定の p 値（**両側**、d_i = 0 の種は除く、二項分布で正確に計算）、点(A)・点(B) の相関 ρ。
- **逐次に足す（racing）は予算の配分にだけ使う**: n_min 標本を測ったあと、k 標本ずつ足して n_max まで。覗く回数を L 回に決め、各回の有意水準を α / L（Bonferroni）にする。止めた時点の値は「目安」と表示する。**採否の主張は、使わなかった種の固定の n で行う**（この道具に `Confirm(n)` のような固定 n の評価を別に用意する）。
- k は 12 コアが遊ばない大きさ（1 標本の試合の数 × k ≥ コアの数）にする。
- 決定的であること: 同じ引数なら同じ結果。`BotArena.RunAll` は結果を添字の位置に書くので、並列の数（`maxParallel`）を 1 にしても既定にしても同じになる。

### 3. 雑音を測る `noiselab`（Arena のコマンド）
試合（相手 = boxer・outboxer・swarmer・counter・slugger・jabber）とドリル（`DefenseDrill.Punch` でストレート "2" を champion の受け手へ、守り `Slip` に固定、合図 0.04 s、打ち返しあり）の両方で、次の表を作る。
- **(a) 種による揺れ**: 同じ値（champion）を、重ならない 2 つの種の組で測り、標本ごとの点の標準偏差。
- **(b) 小さな変更での揺れ**: champion と、`Cross` の `Duration` を +0.001 s だけ変えた champion′（守りのドリルでは `Slip` の `HeadX` を +0.001）を同じ種で対にし、d_i の標準偏差と ρ。ρ が 0 に近ければ、同じ種で対にしても分散は減らない（そう書く）。
- **(c) 本当の差を言うのに要る数**: champion と champion-v1 を対にして、効果の大きさ ÷ 標準誤差が 2.5 を超えるのに要る標本の数。
- **(d) 1 標本の長さ**: ドリルは 10・20・40 秒、試合は 30・45・60 秒で、(c) の効果の大きさ ÷ 標準誤差を**同じ壁時計あたり**で比べる（点の尺度が秒数で変わるので、信頼区間の幅でなく検出力で比べる。短い秒数は近づくまでの前置きの割合が大きいことも書く）。
- 記録: `docs/arena/evo_noise.md`（表・壁時計・結論: CMA-ES に使う標本の数・秒数・λ の推奨）。
