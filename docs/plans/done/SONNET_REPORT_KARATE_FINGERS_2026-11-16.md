# 指の関節で組む手形と、本物の急所のセルを狙う（2026-11-16）

実装・テスト・測定・動画は完了。ただし期待した結果（柔らかい所で細い面が拳より深く入り、貫手が目を壊す）は **測定で確かめられなかった**。理由は下の「期待と違った点」。コミットはワークツリー内のみ、プッシュなし。

## 狙いの道（`BodyLandmarks` / `TargetMap`）
頭の寸法の比の見積もりを消し、急所の点を実際のセルから 1 つの道で求める。目 = 残っている目・黒目のセルの重心（左右別、潰れた目は狙えない、同じ見えなら打つ側に近い方）。こめかみ = 目の高さの頭蓋の骨の横の端の外の皮膚、あご = 顔の前側で最も低い骨の前の皮膚、みぞおち = 胸骨の下の端の 1 セル下の皮膚。心臓・肝臓 = 作ったときの臓器のセルの重心から打つ側へ辿った最も外の皮膚のセル。**内臓の扱い**: 見える物ではないので、「体の中のこの辺り」という作ったときの置き場の知識（削れても動かさない）で、皮膚の上の点として狙う。目だけは外から見えるので、いまの残りのセルに追従する。`LogicVersion` 31→32。

## 手の組み立て
`HandSkeleton`（親セルの表: 掌 + 4 本 × 3 節、指は骨 1 セル + 十字の皮膚、節の長さは中指が最長）、`BareHandState`（親セルごとの損傷の台帳と置き直し）、`HandMotion`（関節ごとのバネ・ダンパ）。手形 = 関節の曲げ角（正拳 = 全部曲げる、貫手 = 全部伸ばす、一本拳 = 人さし指だけ付け根 45° で第 2 関節が前、手刀 = 手首を偏らせ縁を前、掌底 = 手首を反らす、裏拳 = 握って手首を曲げる）。セルは節の向きに沿って置き直し、重なれば骨 → 肉 → 皮膚の順に場所を取り、残りは近い空きセルへ。動きは落ち着く時間 0.055 s（指）・0.08 s（手首）と関節より先の慣性から固さを出す。骨の強さ = 節の骨のセルのうち最も傷んだものの残り（直列）。骨が欠けた節は力が入らず力を抜いた形へ落ち、折れた指は貫手を作れない。`PhysicsVersion` 34→35。詳細は `docs/KARATE.md` 末尾の節。

## 期待と違った点（原因）
- 貫手 → 目の目の欠損は 前 0.67（2 セル）→ 後 0。狙いの点は実際の目のセルの上（`LandmarkTests` で 1 セル以内）だが、撮った一撃は狙いから 13.1 mm（前 13.6 mm）外れて顔の横・頬に当たった。原因は狙いではなく**届け方**（拳の経路の終わりで手の先 = 握りの点より 19 mm 先の指が、顔の横に先に当たる）。数字合わせの調整はしていない。
- 打つ面は物理として小さくなった（貫手・一本拳は正拳より打つ面のセル数が少ない、`HandSkeletonTests`）が、全欠損が貫手で大きく減った（みぞおち 22.67→0.67）のは、旧い手が太い球の指 4 本で質量が大きく（旧 15.3 g、新は 590 セルで質量は未測定だが軽い）、胴・腕を広く削っていたため。この比較は手の質量が変わった後の別の手との比較で、細い面の効き目の比較としては弱い。
- 裏拳・掌底は経路・手首の回転で打つ面が握りの点（手首）から近くなり、命中が裏拳で大きく減った（64→5）。手首を中心に回すため（§8 参照）。ボット側の経路は直していない。
- 骨の上（こめかみ・あご）で指の骨が負けたか: 指骨の欠け（表の「指骨」列）は 0（細い指が欠ける打撃が来なかった）。確かめられていない。

## 1. 掌底が壊れていた原因と直し
- 原因（確かめた）: (a) 90° 回す中心（握りの点）の y が 1 mm で、回したセルの座標が格子の位相（奇数 mm のセル中心）から半セルずれ、丸めで重なって押しのけられ、隙間だらけになった。(b) 斜めの回転は forward の丸めで重なり・穴ができる（全手形で起きるが 90° の倍数のときは位相だけの問題）。
- 直し: 手首・指の関節を人の可動域の値で持つ（`HandSkeleton.Range`: 掌屈 80°・背屈 70°・橈屈 20°・尺屈 30°、付け根 −45〜90°、第 2 関節 0〜110°、先 0〜80°）。手形の角度も `HandMotion` の目標もその範囲に収める。90° 回す近道は外した。掌底 = 背屈 70° + 指の付け根 −20°（指は前腕に対し真上 = 格子に合う向き）。押しのけ先は連続な位置に最も近い空き（`BareHandState.Vacant`）。
- 結果: `media_tmp/hands/handsheet.png`（6 形 × 横・上・斜め）で、掌底は指 4 本が長さ違いで真上に立つ掌に見える。手刀は橈屈 20° の斜めで格子の段が目立ち、穴・赤いセルが 1 つ見える（原因 4 参照）。
- 手刀は、前腕の回内・回外（縁を前へ向ける本来の動き）を持たないので、まっすぐ突くと貫手とほぼ同じ形。これは手の関節ではなく手の向きの指令の仕事（ボットはまだ出さない）で、§8 に書いた。

## 4. 赤・白のセルの原因
材質の取り違え・色付けの間違いではない。重なって押しのけられた皮膚が体の中に埋もれ、代わりに筋肉（赤）・骨（白）が外に出ていた。外に出た筋肉・骨を、近い（筋肉 3 セル・骨 1 セルほどまで）埋もれた皮膚と置き場を入れ替えて直した（`BareHandState.Reskin`、傷に依らず、組織の数は同じ）。外に出る筋肉・骨のセル数: 正拳 6→0、貫手 0、一本拳 6→1、裏拳 1→0。斜めの手刀・掌底は 14・6 セル残る（テストは各形の総セル数の 4 % 以下）。
