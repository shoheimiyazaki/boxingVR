## 決めたこと

2. **レフェリーなしの決まり**（ゲームのルール。物理は同じ）:
   - ダウンの数え・10 カウントの K.O.・動かないままの K.O. は今のまま数える。HUD のカウントも出す。
   - 倒れている相手への打撃（拳・はめる物・武器・蹴り・踏みつけ）も、立っている相手と同じ `ApplyHit`・接触の物理で数える。止めているのは `victim.State == Standing` の条件だけのはず。`Referee == false` のときだけその条件を外す（場合分けは「審判がいるか」というルールの 1 つだけ。技の種類で分けない）。
   - 立ち直った後の一呼吸（`Holding`・`ResumePause`）は無い（止める人がいない）。
   - 記録の再生: `Referee` を記録の見出し（`ReplayMatchSettings`）に入れ、古い記録は既定の true で読む。`ReplayTests` にレフェリーなしの試合の往復を 1 本足す。
3. **入力元に渡す情報**: `FighterSense` に「相手が倒れているが攻めてよい」ことが分かる値を足す（例: `OpponentDowned`（相手の体が倒れている）と `MayStrikeDowned`（= レフェリーなし））。`OpponentAlive` の意味（立っていて打ってよい）は変えない。レフェリーありのときのボットの振る舞いは変えない。
4. **倒れた相手への攻め（技 = 目標の経路。§1.2）**: 体が倒れた相手の上へ届くように、歩いて相手の横（頭か胴の脇）へ立ち、腰を折り・膝を沈めて（`HeadOffset` の下げ・前傾、`LegCommand`）、目標を下の相手の頭・胴へ向けて打ち下ろす。姿勢を書き込まない。威力は物理（打ち下ろす拳・武器の速さと乗る質量、体のバネ）から出る。倍率・急所の分岐を書かない。
   - ボクシングの拳（グローブ・素手・メリケンサック・カタール・籠手。`BoxerBot`）: 上からの打ち下ろし（鉄槌のような縦の振り下ろしと、体ごと沈んで落とす突き下ろし）。カタールは突き下ろす向きの経路（刃の向きは手の目標の向きで）。
   - 空手（`karate`）: 踏み下ろし（踏みつけ。足の目標を相手の胴・頭の上から下へ。`KickSpec` の仕組みを使う）と、沈んで突き下ろす下段突き。
   - 日本刀: 上からの突き下ろし（とどめ）と、上段からの斬り下ろし。ロングソード: 突き下ろしと、上からの斬り下ろし。どちらも型（`SwordForms`・`FormSwordsman`）の形で足す（他の型と同じく目標の経路で）。
   - こんぼう（`ClubBot`）: 振りかぶっての打ち下ろし。
   - どの技を選ぶか（相手の頭・胴のどちらが届くか、距離、自分の体勢）はボットの判断。スタイルごとの好み（打ち下ろしの手数・溜めの大きさ・踏みつけを使うか）は `BotStyle` の値（JSON で変えられる）として持つ。数字はコードに埋めず、値の横に意味と根拠を書く。
   - 相手が立ち上がりかけたら（`OpponentAlive` に戻ったら）いつもの技へ戻る。
5. **プレイヤー（デスクトップの意図操作）**: 相手が倒れていて攻めてよいとき、弱・強の攻撃は上の打ち下ろしの技になる（ボットと同じ実行部 `TechniqueExecution`／型を使う。§2）。移動は今のまま（相手の横へ回るのはプレイヤーの操作）。VR は手の位置がそのまま目標なので何もしなくてよい（打撃が数えられることだけ確かめる）。
