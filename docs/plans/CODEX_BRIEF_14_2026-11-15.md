## 背景（Claude が決めたこと）
- ボットの技を進化（CMA-ES）で磨く計画の最初の段。拳の技（`PunchSpec`）の値は `Technique.cs` の `PunchSpec.Of` にハードコードされていて、守り（`DefenseBook`）のようにスタイルの値として変えられない。まずデータにする。**学習・アルゴリズムはこの作業では入れない**。
- 既定の値では試合が 1 ビットも変わらないこと。だから `LogicVersion`・`PhysicsVersion` は上げない。

## やること

### 1. `PunchBook`（`games/MiniRing/Bots/PunchBook.cs`）
- `DefenseBook` と同じ形: `Technique` ごとの値、`Of(Technique)` → `PunchSpec`、`With(Technique, …)`、`Default`、`Validated()`。
- **既定の値の出どころを 1 つにする**（§1.5）: 今の `PunchSpec.Of` の値を `PunchBook.Default` へ移し、`PunchSpec.Of(t)` は `PunchBook.Default.Of(t)` を返すだけにする。
- **JSON**: `BotStyle.JsonOptions`（`BotStyle.cs:350`）はフィールドを出さないので、`Vector3` の `HeadShift` はそのままでは `{}` になり、読むと 0 に戻る。リプレイの見出しは CPU のスタイルを `ToJson`/`FromJson` で保存して再生する（`ReplayTests` の `ReplayStoresTheCpuStyleItself…`）ので、これは再生のずれになる。次のように作る。
  - JSON 用の値は `DefenseMove` と同じく init プロパティを持つ class（例: `PunchMove`。`HeadShiftX/Y/Z` は float）にし、`PunchSpec` へ変換する。positional な `PunchSpec` を直接シリアライズしない（引数の既定値 `Extend = 1f` が JSON に無いとき 0 になる）。
  - 部分的な JSON（技 1 つだけ・値 1 つだけ）を読んでも、書いていない値は既定になる（`JsonObjectCreationHandling.Populate` か、技ごとの既定への重ね合わせ）。
- **変えてよい値と変えない値**（`Validated()` で強制する）:
  - 技の正体は変えない: `Lead`・`ToBody` は既定へ戻す。
  - `Extend` は `Feint` 以外 1 に固定する。`TechniqueExecution.Spring`（`TechniqueExecution.cs:37`）は `Extend >= 1` のときだけ体のバネを拳へ移すので、1 未満は「フェイント化」と「移送の切れ目」を混ぜてしまう。`Feint` だけ 0.2〜0.6。
  - 変えてよい: `Lateral`・`Low`・`Overshoot`・`Duration`・`HeadShift`・`StepIn`・`Sweep`。範囲は物理として意味のある幅で、値の横に根拠を書く（例: `Duration` 0.18〜0.8 s。短い目標は体が追えず、長いと的になる。`Lateral` 0〜1.2、`Low` −1〜1.2、`Overshoot` 0〜0.6、`StepIn` 0〜1、`Sweep` 0〜0.6、`HeadShift` 各成分 ±0.4）。
  - 範囲は `PunchMove` 側の `public static` の表（名前・最小・最大）に 1 回だけ書き、`Validated()` が参照する（次の作業の遺伝子への写しも同じ表を使う）。同じことを `DefenseMove` にもする: `DefenseMove.Validated()`（`DefenseBook.cs:117-148`）と `Mutation.Move`（`Mutation.cs:43-58`）に重なっている範囲を表へまとめ、両方が参照する（値は今のまま。`Mutation` が今より狭い範囲を使っている所はその範囲を表に別に持つ）。
- `BotStyle` に `public PunchBook Punches { get; init; } = PunchBook.Default;`。`Validated()` で検証する。既存の `champion.json` などは書き換えない。

### 2. 使う所を `Style.Punches` へ替える
- `BoxerBot.cs` の 1005・1020・1023・1108 行付近の `PunchSpec.Of` → `Style.Punches.Of`。
- **`BoxerBot.KindOf`（544 行付近）は替えない**: 技 → 拳の種類（ストレート・フック…）は `Lateral`・`Low` の閾値で決めていて、守りの選び方・合図・ドリルが使う。技の種類は技の番号で決まるもので、磨いた値で変わってはいけない。`PunchBook.Default` の値で決めることをコメントに書く。
- `IntentControl.cs`: 296（`HandOf`）・331（`Lead` を見る所）・381（経路の `spec`）を `_style.Punches` へ替える。
- `DefenseDrill.cs` 303 付近（`DrillCue.For` の攻め手の手）を `attacker.Punches` へ替える。
- `Combo.HasBodyShot` は今どこからも呼ばれていない。`PunchSpec.Of`（＝既定）のままでよい。

### 3. 結果が変わらないことの確かめ
