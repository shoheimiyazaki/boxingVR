## 式
- 首の骨折: 頭の部位全体が首の上の梁（`BeamAxis`=Y、`BeamSlices`=首の 2 段）。曲げは腕・脚と同じ `VoxelBending.FindBreak`（`candidates` 引数を追加）。骨の削り抜けは `FindBoneBreak`（`searchLow/High` を追加）。折れると `BoxerBody.BreakAt` が頭を首の段で分け、下の首の側が破片になる。`Fighter.BreakNeck`: 首の側の破片を胴に溶接（玉継手 + 向きのサーボ）、首のサーボと関節を外す。肉が残れば腕・脚と同じ `Fighter.Link` で頭がぶら下がる（向きのバネは残った断面に比例）。
- 首の切断: 肉まで断たれた（`Bridge` が 0 / Link が作れない / 後から肉が千切れた・削られた）なら、頭は「体から外れた部位」になり `Die("neck")`（「K.O. — NECK DESTROYED」）。
- 脊髄: 高さ（頸・胸・腰）ごとに「いちばん細くなった段の残りのセルの割合」（`BoxerBody.CordFunction`）。部位の筋を動かす神経 = 上の高さまでの積（腕 = 頸、胸 = 頸×胸、腰・脚 = 頸×胸×腰）。`Fighter.Strength` = 15% + 85% × 肉の残り × 神経。絶たれた筋は `DeadGripRelaxSeconds`（0.5 s）の指数でほどける。首のサーボは頸に比例、息（`Breath`）は心臓・肺 × 頸。
- 折れる力（`NeckBreakProbe`、無傷）: あごの高さの真横 467 N・前後 1527 N、頭の真ん中 938 / 3244 N、頭の上 614 / 1924 N。試合でグローブが頭へ渡す力は p99 107 N・最大 200 N、刀・ロングソードは p99 約 20 N・最大 65 N。無傷の首は試合では折れない。骨を 4 セル中 3 つ削ると、あごの高さの真横 250 N で折れる。
- 垂れ方: 頭を前へ倒す回転（0.1 N·m·s）を与えると、無傷の首は元に戻り（平均 0.01 rad）、折れた首は頭が胸へ垂れたまま（1.45 rad）。
