# 指示書 D: WVC だけの番組の部品（リングアナウンサーのコール・ラウンドの採点・王座のベルト）

先に読む: 根の `CLAUDE.md`、`docs/TV_BROADCAST.md`（§1.1・§3）、`docs/LLM_CONTENT.md`、`games/MiniRing.Arena/TvShowGraphics.cs`・`WvcEmblem.cs`・`TvProgram.cs`、`games/MiniRing.Arena/Orgs/wvc.json`。

## ユーザーの指定（2026-11-18）

> 中継中の UI や選手紹介や対戦カード表示、その他の構成自体を各団体で全く違うものにして、完全に別系統の大会・テレビ番組であることを強調してください。

WVC は「格式の高いボクシング団体の、地上波の格式ある中継」。別の作業 C が番組の型の骨組みと VFC の番組（深夜の有料配信のケージファイト）を作っている。この作業は、**WVC にしか無い場面の部品**を、単独のファイルとして作る（番組の流れへの組み込みは、C と合わせた後に指示する側がする）。

## 触ってよいファイル

新しいフォルダ `games/MiniRing.Arena/Shows/Wvc/` の新しいファイルと、`tests/MiniRing.Tests/` の新しいテストファイルだけ。`TvShowGraphics.cs`・`VideoMaker.cs`・`Organization.cs`・`Orgs/*.json`・`tools/` は触らない（C が触る）。既存の描画の部品（`WvcEmblem`・`TvShowGraphics` の公開の補助: `Logo`・`RuleGems`・`VoxelWord`・色）を**呼ぶ**のはよい。

## 作る部品（それぞれ「入力のデータ → 2D の重ね絵（`ScreenTextDraw`・`UiShapeDraw` の並び）」の純粋な関数。時刻 t で動く）

色・字・飾りは今の WVC の画面にそろえる（金・白・濃紺、金の細い罫と菱形の飾り、中央揃え、角丸の板）。

1. **リングアナウンサーのコール**（1 人 約 6 秒、赤 → 青の順に 2 回使う）: 生の絵（そのコーナーの選手を映すカメラ）の上に重ねる、画面の下 1/3 の格式ある板。上から「赤コーナー」、肩書き（流派・所属ジム。資料にあれば）、戦績（「17勝 12K.O. 2敗 1分」の WVC の言い方）、体重、そして大きく本名と呼び名。文字は 0.3〜0.5 秒ずつ順に出る。入力は `TvCorner`（と `CharacterProfile`）。
2. **ラウンドの採点の札**（休みの最初の 6〜8 秒、画面の右下）: そのラウンドまでの、ラウンドごとの「与えたダメージ」（今の判定と同じ量 `Condition.TotalDamage` の差分。数字はそのまま出してよい: WVC の判定の基準そのものなので見える量）と、ラウンドで当てた打撃の数。3 人のジャッジの採点表の形を真似るのはよいが、ジャッジ 3 人で違う点を作り出さない（量は 1 つ）。入力: ラウンドごとの赤・青の数の並び。
3. **王座のベルト**（決着の画面に重ねる、勝者の名前の上）: ボクセルで積んだ金のチャンピオンベルト（中央の大きな板に WVC の紋章を小さく）。入力: 出すかどうか（呼ぶ側が決める: 札の `next` が「優勝」など。部品は判断しない）と時刻。

## 確かめる
- 各部品の PNG を `.visualcheck/` に出し（既存の visual テストの仕組み。黒か生の絵の代わりの灰の背景でよい）、**自分で開いて見る**。今の WVC の冒頭・勝敗の画面と並べて、同じ番組の部品に見えるかを報告に書く。
- 単体テスト（入力の検査: 空の並び・長い名前でも板からはみ出さない・時刻 0 と終わりで壊れない）。
- 全テスト `dotnet test tests/MiniRing.Tests --filter "FullyQualifiedName!~Probe"` が通る（件数を報告）。
