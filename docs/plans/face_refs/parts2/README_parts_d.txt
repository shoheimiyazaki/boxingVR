PART LIBRARY D

The five requested PNGs are AI-generated concept comparison sheets made with
the built-in image generation tool. They contain realistic sketches and voxel
interpretations. Their printed legends, pixel dimensions, and grid depictions
can contain generation artifacts; they are not exact exports of parts_d.txt.

For exact implementation use parts_d.txt and the five *_grids.png supplements.
These supplements are rendered directly from the canonical cell layouts at
20 pixels per cell with flat fills and one-pixel grid lines. They have no
realistic sketches. All 51 layouts include full top-first rows and anchors.
grid_data.json and render_grids.ps1 provide reproducible grid rendering.

Canonical legend and sRGB hex colors are in palette.txt. Empty cells are shown
as warm off-white on reference atlases. In a game, treat '.' as no voxel.
Coordinates are zero-based. SIDE faces right. TOP anterior points downward.
The shapes and colors are independent modular traits for fictional people.

generation_prompts.txt records the prompt set used for the generated sheets.
