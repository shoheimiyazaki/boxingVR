## ユーザーの指定（2026-11-18、原文の要旨）

> 傷はちょっとずつ治るようにしてください。両者ダウンしたまま何もしない時間が長く、番組として失敗しています。
> 傷は生きているボクセルと接する破壊されたボクセルが確率で再生するように。欠損部位も含め。武器は手が武器を保持できる程度まで回復していたら、新しいものを支給。
> 再生の抽選の間隔と確率はいい感じに: 軽い傷はインターバル中におおよそ再生、大きな欠損は回復しきらない程度。
> 回復が起きるのはインターバル中と、両者ダウンして意識だけでは回復しない場合。武器支給はインターバルのみ。
> 両者ダウンで絵的につまらない状態が続く場合は、片方が立ち上がれる状態になるまで再生速度を上げる。

## 設計（指示する側が決めた。変えたいときは理由を書いて報告）

### 1. 再生のモデル（成長の前線）: `BoxerBody.Regrow(...)`（新しい関数）
- 一回の抽選（pass）: 体に付いている部位（`_parts`。破片 `_fragments` は対象外）の格子の各セルについて、**作ったときに材質があった（`Original.Materials[i] != 0`）のに今の材質が違う（空・押し込まれた別の材質）セルのうち、6 近傍に今「生きている」（材質が 0 でない）セルがあるもの**を候補に集め、それぞれ確率 `p` で元の材質・表面・満タンの HP に戻す（今の `grid.Reset`）。候補を全部集めてから抽選する（同じ pass の中で連鎖させない = 順序に依らない）。
  - 材質は残っているが HP が減ったセル（目など。`VisionState` が HP を見る）も、同じ確率で HP を満タンに戻す。
  - 切り株（骨が断たれて先が落ちた部位）も対象: `SplitAt` で先のセルが空になった切り株の格子は、元の形まで切れ目の先へ伸びる（今の `Regenerate` は切れた部位を飛ばしていた。新しいモデルでは飛ばさない）。
- 乱数は**試合の種から作った専用の `Random`**（例 `new Random(seed ^ 0x2e9e0)`）。他の乱数の流れ（`_fx` など）を動かさない。部位の順・セルの番号の順で回す（決定的: CLAUDE.md §1.6）。
- 戻した部位は `UpdateMass()`。切り株の切れ目のスライスが骨で埋まり直したら `_cutAt` から外す（筋肉の断面 `Muscle` が全長で測られる）。
- 速さは物理の量で持つ: **前線の進む速さ `v` [m/s]** と抽選の間隔 `Δt` [s] から `p = v·Δt / セルの大きさ`（平らな前線は 1 回の抽選で平均 p 層進む）。値（まず これで測る）:
  - `Δt = 0.25 s`、`v = 1.2 mm/s`（ボクセル 5 mm なら p ≈ 0.06）→ 休み 25 秒で約 3 cm。拳の打撃の削れ（数 mm〜2 cm）はほぼ戻り、刃の深い切り込み（5 cm 超）は半分ほど、失った前腕（約 25 cm）は戻りきらない。
  - 測った結果（軽い傷が休み 1 回で何割戻るか、前腕の切り株が何 cm 伸びるか）で値を直し、`MatchRules` のコメントに根拠を書く。
- **加速**: 倍率 `m`（1 以上）のとき、1 回の抽選を `k = ceil(m·p)` 回の pass に分け、各 pass の確率を `m·p/k` にする（`m·p` が 1 を超えても 1 回の抽選で k 層進める）。

### 2. 欠損した先の部位の生え直し（芽を出し直す）
- 切り株の格子が元の遠い端（骨の端 `_boneSpan` の遠い側。関節を受ける所）まで骨で埋まり直したら、その先の部位（肘から先・膝から先・足首から先: `Fighter._detached` に入った、元の Fighter の部位の剛体）を生え直させる:
  1. 落ちている古い先の部位の中身は、**同じ位置・向き・中身の破片（体の外のボクセルの剛体）として床に残す**（新しい剛体に格子を写す。落ちた腕が床から消えない）。破片どうしをつないでいた玉継手があれば、写した破片へ付け替える。
  2. Fighter の部位の剛体（同じ id）は、格子を**関節の面に接する 1 層（芽）だけ**残して空にし、親（切り株）の関節の所へ、作ったときの関節の向き（休みの姿勢）で置き直し、生成時と同じ関節の拘束・角度の制限・筋肉（サーボ）を作り直す。`_detached` から外し、`arm.Severed`・`arm.HandGone`・`_legSevered`・`_legSupport` を戻す。グローブ・はめる物は戻さない（武器は下の 3）。
  3. その後は 1 と同じ前線の再生で、芽から先へ伸びる（芽に接するセルから）。
- 剛体の位置を書き換えるのは軸（§1.1: 位置を書くのは生成直後だけ）の例外。中身がほぼ空の部位を「新しく生成する」のと同じ扱いとして、`docs/DEBT.md` に項目を足す（直す方向: 部位の剛体を新しく作る口を Fighter に持たせる、など）。
- 骨が折れて肉でぶら下がっている所（`_fleshLinks`）も同じ: 切り株が遠い端まで埋まったら、肉のつなぎを外し、ぶら下がっていた破片は床の破片として残り、先の部位は芽から生え直す。
- 首（頭が離れた）は死なので対象外（死んだ体は再生しない）。
- 芽の質量が小さすぎて関節が暴れるなら、`UpdateMass` の最小の質量（芽の数層ぶん）を `FighterTuning` に足してよい（根拠を書く）。

### 3. いつ再生するか（`BoxingGame.UpdateMatch`）
- **休みの間**: 両者とも、`Δt` ごとに 1 の抽選（倍率 1）。
- **ラウンド中**: 両者がダウン（`State == Down`）していて、どちらも「意識だけでは立てない」とき: 両者とも抽選（倍率 `m`）。
  - 「意識だけでは立てない」= 脳しんとう（`Concussion`）が全部引いたとしても立てない: `!CanStand`、または 脳の残り（`BrainFunction`）で決まる意識（脳しんとう 0 のとき）で `StandReach` が立つのに足りない（ダウンからの起き上がりの試みが成り立つ値。今の起き上がりの式から読む。分岐ではなく同じ式に脳しんとう 0 を入れて評価する関数を `Fighter` に足す: 例 `BodyLetsStand`）。
  - 倍率: その状態が続いた時間 `t` から `m = 2^(t / T)`（`T` = 倍になる時間。まず 3 s）。上限は無くてよいが、1 回の抽選の pass の数は `k` で抑えられるので、実害が無いかを測る。どちらかが「意識だけでは立てない」でなくなったら `t = 0`・再生を止める。
  - 片方だけダウンなら再生しない（相手が攻める場面を消さない）。死んだ体は再生しない。
- WVC（`RegenVoxelsPerSecond` > 0 の団体）は今の `Regenerate`（予算で内側から戻す）のまま。同じ現象に 2 つのモデルになるので `docs/DEBT.md` に書く（直す方向: WVC も前線の再生へ寄せる）。WVC の試合・中継の出力は変えない。

### 4. 休みの武器の支給
- 休みの間（ラウンド中はしない）、試合の始めに武器を持っていた選手（`BoxingCorners` の武器）が、今その武器を握っていない（落とした・折れた・手を失った）とき、その手が**武器を保持できる**なら、同じ種類の新しい武器を手に支給する（今の `Arm` と同じ、試合の始めに持たせるのと同じ手順）。
  - 「保持できる」は物理の量で: 今ある「力の抜けていく手が、支えきれなくなった所で武器が抜ける」式と同じ量（握りの力・腕の筋肉の断面 × 武器の重さのモーメント）で判断する。一つの現象に一つのモデル（§1.5）。腕が `Severed`・手が無いなら保持できない。両手持ちの武器は、主の手が保持できれば支給（添える手は今の仕組みのまま）。
  - 床の古い武器・折れた武器はそのまま残す（片付けない）。
  - 休みの間に手が戻って保持できるようになったら、その時点で支給してよい（休みの間なら何度でも調べる。支給は 1 回の休みに 1 本まで）。
  - 中継の記録（events.json）に出来事を足す（例 `weapon_supplied`: 誰に・何を）。実況の `run.js` は種類の名前を決め打ちしていないか確かめ、壊れないこと。
- 新しい武器を手に置くのも §1.1 の例外（生成と同じ）: `docs/DEBT.md` に書く。

### 5. 団体のファイル・決まり
- `MatchRules` に再生の値を足す（例 `RegrowthSpeed` [m/s]・`RegrowthTickSeconds`・`StuckDoublingSeconds`。0 なら前線の再生をしない）。`MatchRules.Vfc` に値を入れる。
- 団体のファイル `vfc.json` の `match` に再生の値（例 `"regrowth": { "speed": 0.0012, "tickSeconds": 0.25, "stuckDoublingSeconds": 3 }`）と、武器の支給（`"resupplyWeapons": true`）を足し、`TvShowRules.Rules` が通す（団体名の分岐を書かない）。WVC は書かない（既定 0 / false）。`OrganizationMatchTests.VfcRulesCountNoDownsJudgeNothingAndDoNotHeal` の名前と中身を新しい決まりに合わせる（`MatchRules.Vfc` と同じになること）。
- VFC の皮膚のあざ（`BruiseHalfLifeSeconds`）も休みに引くようにする（WVC と同じ 20 s）。
- VFC の言葉を直す: `vfc.json` のコメントと `rulesSheet` などの文、`VfcShow` の休みの看板「傷は治らない」（例「傷は少しずつ戻る」。言葉は団体のファイルへ出すのが良い）、`docs/commentary/personas/takamiya.md` の「休みでも治らない」の段落（ケージドクターの経歴の範囲で、事実だけを直す。口ぐせ・言い回しの例を書かない: `docs/LLM_CONTENT.md`）、`docs/VFC.md` の表、`tools/tvshow/cards/vfc-test.json` の `_comment`。
