## やること

### 1. `games/MiniRing.Arena/Evolution/CmaEs.cs`
- 依存を増やさず自分で書く（次元は 9〜15）。手本は Hansen の "The CMA Evolution Strategy: A Tutorial"（2016）と pycma の `purecma.py` の既定値: λ = 4 + ⌊3 ln n⌋（引数で上書きできる）、μ = ⌊λ/2⌋、w′_i = ln((λ+1)/2) − ln i を正規化、μ_eff、c_σ・d_σ・c_c・c_1・c_μ の式、h_σ の扱い。
- 計算は `double`。固有分解は対称行列のヤコビ法（n ≤ 30）で、固有値の並び・固有ベクトルの符号を決まった規則でそろえる。
- **決定的**: 正規乱数は世代ごとに `new Random(Hash(seed, generation))` から作る Box-Muller（`double`）。`System.Random` の内部状態は JSON に書けないので、再開を一致させるためにこうする。並列で評価しても、候補の番号順に点を並べてから更新する。
- **探索の空間は正規化した [0, 1]**（値ごとの範囲の表で写す）。範囲の外は**評価と出力にだけ**鏡映する（三角波で折り返す。σ が大きいと何度も折れる）。平均・共分散の更新は、折り返す前の標本で行う（標準のやり方）。最後に出す値は、平均 m を折り返して `Validated()` を通したもの。
- 初めの σ = 0.15（正規化の空間で）。
- 止める条件は **σ が初めの 1/50 未満**、**世代の上限**、**条件数が 1e14 を超えた**の 3 つだけ。点の改善では止めない（世代ごとに種が変わるので、世代の間の点は比べられない。最良の点は運で上振れする）。
- 状態（世代・平均・σ・C・p_σ・p_c・種）を JSON に書き、読み込んで続けると、続けて回した場合と同じ軌跡になる。
- 1 世代の API は ask / tell（`Ask()` → 候補の配列、`Tell(points)`）にする（作業 17 で並列の評価から呼ぶ）。最小化か最大化かを引数で決める。

### 2. `games/MiniRing.Arena/Evolution/Genomes.cs`
- 拳 1 技: `Lateral`・`Low`・`Overshoot`・`Duration`・`HeadShift.X/Y/Z`・`StepIn`・`Sweep`（9 次元）。
  - **探索の範囲は既定の値を中心にした技ごとの幅**（例: 各値 ±0.3、`Duration` ±0.12 s、`HeadShift` ±0.12。その上で `PunchMove` の範囲の表で切る）。広い範囲で探すと、ストレートが実質フックに育つことがある。技の種類（`KindOf`）は既定の値で決まるので、それでは「ストレートとして選ばれるフック」になる。幅は 1 か所の表に書き、根拠をコメントに書く。
- 守り 1 技: `Mutation.Move` が揺らす 15 値。範囲は作業 14 で作った `DefenseMove` の範囲の表を使う。`Block` の `HandsUp` は 1 に固定し、`Sweep` でない技の `EndX` は外す（次元が 14 になる）。
- 写しは往復できる（値 → 遺伝子 → 値で同じ。範囲の端も）。
