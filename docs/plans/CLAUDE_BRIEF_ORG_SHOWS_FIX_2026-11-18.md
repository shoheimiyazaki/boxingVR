## 直すこと（優先順）

1. **試合の前の生の絵で、選手が T ポーズ**（腕を真横に広げた生成直後の姿勢）のまま映る（VFC の入場・フェイスオフ・コールドオープン、`docs/video/vfc-test/chk/f_24.png`）。
   - 本番の試合の状態には手を付けない（試合の前に本番を進めると試合が変わる。チェックサム・記録の再生を壊さない）。
   - 直し方: リプレイと同じ「影の試合」の考え方で、試合の前の場面のためだけに、同じ種・同じ両コーナー・同じ決まり・同じ雰囲気の `BoxingGame` をもう 1 つ作る。構えて立つ指令（`FighterCommand`。体はバネで追う。姿勢を書き込まない: CLAUDE.md §1.2）で 1〜2 秒進めてから映し始め、試合の前の場面の間も同じ指令で進め続ける（軽く揺れて立っている）。入場の場面ではその選手が自分のコーナーの近くにいる、などは指令の目標で作ってよい。
   - WVC・VFC のどちらの団体でも、生の絵を使う試合の前の場面は全部これで描く。

2. **VFC の暗い会場に、部屋の窓が昼の光で白く光る**（`f_24.png`・`f_74.png`）。照明（`ArenaMood`）は効いているが、窓の見た目（発光・空の明るさ）が団体の雰囲気を受けていない。`ArenaMood` の値（例 `window` を窓の見た目の明るさにも掛ける、または夜の窓の値を足す）で、VFC では窓が夜（暗い）に見えるようにする。WVC の部屋は今のまま（描画が同じ）。描画だけで試合に響かないこと。

3. **ファイトポスターの肖像が背中から写したように見える**（`f_14.png`: ジンは顔が見えない）。`CharacterPortraits` の向き（+Z が正面か）と、ポスターでの使い方を確かめ、2 人とも顔が正面に見えるようにする。

4. **VFC の決着の画面で、死んだ選手の体の図が無傷に見える**（`.visualcheck/show_vfc_result_death.png`: 首を断たれたコンラートの頭が描かれ、灰色にも沈んでいない）。
   - 体の図は見えている欠損から描く: 離れた頭は輪郭だけ。敗者（死んだ側）の図は全体を灰色に沈める。原因（頭の離断が体の図のデータに入っていない・敗者の判定が逆、など）を調べて直し、テストを足す（首を断たれた体の図で頭が「失った」になる）。

5. **VFC の休みの看板の傷の言葉が、左下の顔の窓に隠れる**（作業 C は動画の後に直したと報告。撮り直しで確かめる）。

## WVC の部品の組み込み（WVC の番組をより「格式ある地上波のボクシング中継」に）

`WvcShowParts`（作業 D、純粋な関数）を `WvcShow` の流れへ組み込む。WVC の番組の出力は変わってよい（今回の意図した変化）。WVC の試合そのものは変えない。

- **リングアナウンサーのコール**: 試合の前の場面の並びで「選手の比較の表」の後に、赤 → 青の順に `WvcShowParts.CallSeconds`（6 秒）ずつ。下は生の絵（そのコーナーの選手を映すカメラ。上の 1 の影の試合で構えて立っている）。中継の記録に試合の前の場面（`prefight`）として出来事を書く（画面の説明: 「リングアナウンサーが赤コーナーの〇〇をコール」）。
- **ラウンドの採点の札**: WVC の休みの最初の `RoundCardSeconds`（7 秒）、画面の右下。値は、ラウンドごとの与えたダメージ（`Condition.TotalDamage` のラウンド内の差分。`VideoMaker` の `redRoundStart`・`blueRoundStart` にある）と、ラウンドで当てた打撃の数（中継の記録の hit・weapon_hit を数える、など今ある量から）。休みの顔の窓・字幕と重ならない置き場。中継の記録に出来事（画面の説明）を書く。
- **王座のベルト**: 札の試合に `"belt": true`（新しい欄。既定 false）があるとき、勝敗の画面で勝者の名前の上に。「K.O.」の大きな字と重ならないよう、勝敗の画面の配置を直す（作業 D の注: 隙間は約 54 px しか無い）。引き分けでは出さない。

## 撮影（最後に。どちらも `tvshow.ps1` で最後まで: 下見 → 撮影 → プロスペクティブ実況（Haiku）→ 声入れ → 点検 → 結合）

- **VFC**: `tools/tvshow/cards/vfc-test.json`（jin 対 konrad）。下見の種は 8。下見の結果の表（種ごとの決着・死か）を報告に貼る。どの種も死なない（全部引き分け）なら、そのことを報告し、引き分けの回をそのまま撮る（決着の画面は引き分けの「両者生還」を見せる）。
- **WVC**: 新しい札 `tools/tvshow/cards/wvc-title.json`（1 試合、例 marcus 対 ramon、`"belt": true`、`"next": "王座獲得"`、`rounds` 3・`break` 20 か今の WVC の札の既定）。
- それぞれの動画のコマ（試合の前の各場面・試合中・休み・リプレイ・決着）を切り出して**自分で見る**。台本（transcript）を読む。
- **試合の終わりの音の大きさを測る**: 両方の動画で、0.5 秒ごとの音の大きさ（RMS の dB）を出し、決着の前後 6 秒と、動画全体の中央値・上位の大きさを比べて報告する（今日、ゴング 0.7 → 0.45、決着の歓声のピーク 0.75 → 0.4 にした。直す前の WVC の測定: 決着の後 4 秒が中央値より約 20 dB 大きかった）。
- 送れる大きさに縮めた版（音を残す: `ffmpeg -i in.mp4 -vcodec libx264 -crf 30 -preset slow -vf scale=960:-2 -c:a aac -b:a 96k out_small.mp4`）も作る（30 MiB 未満）。
