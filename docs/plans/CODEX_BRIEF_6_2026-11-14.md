# Codex への作業指示 6（2026-11-14）: キーボード操作の手触り

最初に `CLAUDE.md` と `docs/INTENT_CONTROL.md` を読む。日本語。コミット・プッシュはしない。作業指示 4・5 が終わってから着手する。
ユーザーが `run-keyboard.cmd`（意図操作のデスクトップ版）で試した評価（これが正）を直す。§1 の軸（入力は目標・体はバネで追う・アニメーションを書かない）を守り、速さ・重さは目標の経路と体の力学で出す。

1. **カメラ**: キーボード操作中、カメラはふんわりとプレイヤーを追う（位置・向きを減衰付きのバネで追従。急に揺れない）。描画だけで試合の計算に入れない。
2. **移動はカメラ基準**: 今の「相手基準（ラジコン）」をやめ、押した方向 = 画面（カメラ）に対しての方向へ動く。向き（顔の向き）は相手を向いたまま。カメラの向きは入力の記録に入れて再生が一致するように（カメラの状態を入力として記録する、または入力の段階で方向をワールドへ直してから記録する）。
3. **スリップ・ダッキングを速く**: 首をぐっと下げ、重力も使って一気に下へ落とす。目標の経路を速く深く（頭・胴の目標を素早く下げ、脚の支え（ホバー）を一瞬抜いて重力で沈む、膝を折る）。ボットと共有の守りの経路（`DefenseBook`）を変える場合は、ボットの守りのドリルで悪くならないことを確かめる（`docs/BOT_PDCA.md`）。
4. **ジャブ**: 戻しが遅い → 連打できるように（引き戻しの経路を速く、次のジャブを戻りの途中から受け付ける）。**押す長さで性質を変える**: 短いタップ = 軽く速い連打のジャブ、少し長め = 体重を乗せて押し込むジャブ（溜めと同じ仕組みで、威力は体のバネから。ボタンで倍率を掛けない）。
5. **コンビネーション**: ジャブ・ジャブ・ストレートのような連続入力が、つながった技として出る（先行入力の受付を広げる、`Combo` の接続）。押した順がそのまま出ること。
6. **回避からのコンビネーション**: ダッキングの沈んだ姿勢から攻撃キーでボディブロー、スリップの傾きから逆の手のフック、など。回避の姿勢（沈み・ひねり）を体のバネとして使って打ち出す（`TransferBodyMotion`）。
7. **サイドステップ**: 横＋回避（または横の二度押し）で素早く横へ出る。足の運びの目標で書く。

確かめ: 各項目に数値のテスト（例: ダッキングで頭が 0.2 秒で何 cm 沈む、タップのジャブの連打間隔、ジャブ・ジャブ・ストレートが押した順に出る、カメラ基準の移動、記録→再生の一致）。キー入力の台本で動画（`docs/video/gen13_keyboard_*.mp4`、縮めた版は音を残す）を撮り、コマを自分で見る。全テスト、`docs/INTENT_CONTROL.md` と `run-keyboard.cmd` のキー説明を更新。最終報告に、変えた所・測った数字・動画・確かめていない所。
