# ボクセルの体 — 削れる・弱る・落ちる・死ぬ

人形の体は、部位ごとの直方体（ラグドールの箱）の中の、**元のローポリの体の形の内側**をボクセル（約 5mm 角）で埋めています。ボクセルは皮膚・肉・骨・臓器のどれかで、パンチで削れていきます。

ボクセルは部位ごとの **3D テクスチャ**として GPU へ渡し、**表面の形は GPU が作ります**（空のボクセルと中身のあるボクセルの境目に面を張る）。CPU は削れたセルのテクセルを書き換えるだけです。

- **肉が削られる**と、その部位の力が落ちます（腕・脚・胴）。
- **骨が断たれる**と、そこから先が別の物体になって落ちます（腕・脚）。
- **臓器を壊す**と死にます。
- 削れたボクセルは、その材質の色の破片になって飛び散ります。肉と臓器からは血の粒も飛び、傷の周りの皮膚は血の色に染まります。

仕組みはエンジン（Aigis）の部品として作り、ゲーム（MiniRing）は体の中身と遊びへの響き方だけを決めます。

## 1. エンジンの部品

| 層 | 部品 | 役目 |
|---|---|---|
| 基盤 `Aigis.Foundation/Voxels` | `VoxelGrid` | 箱を埋めるボクセルの格子（物理を知らない純粋なデータ）。材質ごとの残り数、削る（`Carve`）、傷の染み（`Stain`）、骨が途切れた断面を探す（`FindBoneBreak`）、そこで割る（`Split`）、残りの外形（`OccupiedBounds`） |
| | `VoxelPalette` / `VoxelMaterial` | 材質の表。組織の種類（肉・骨・臓器）、硬さ（1 ボクセルを削るのに要るダメージ）、致命的か、色（体の中・外側の皮膚） |
| 物理 `Aigis.Physics/Voxels` | `VoxelBody` | 格子と剛体を結ぶ。打撃を刻み（`Impact`、削れたボクセルを飛ぶ破片として返す）、骨が断たれたら遠い側を新しい剛体にして切り離す（`Sever`）。質量はボクセルの数に比例して減る |
| 物理 `PhysicsWorld.Reshape.cs` | `ReshapeDynamicBox` | 生きている剛体の当たり判定と質量を作り直す。剛体の原点は動かさない（関節の取り付け位置が保たれる）ので、中心からずれた箱は子 1 つの複合形状にし、慣性は原点まわりで取る |
| | `CopyCollisionFilter` | 切り離した破片に、元の部位と同じ衝突の除外を持たせる（隣の部位とぶつからない） |
| | `GetJointAnchors` / `GetConstraintBodies` | 関節の取り付け位置・つないでいる剛体を読む（切れた先を破片へ付け替えるため） |
| 描画 `Aigis.Render/Voxels` | `VoxelVolume` | 格子の 3D テクスチャ（RGBA8、1 テクセル = 1 ボクセル）。中身があれば不透明でその色（皮膚・肉・骨・臓器、血の染み）、空なら透明。格子が変わったときだけ書き直し、版を上げる |
| | `VoxelVolumePipeline` | 3D テクスチャから GPU 上で表面を作って描く（下）。ヘッドレス・ウィンドウ・VR の描画器が共有する |
| | `VoxelDebris` | 削れたボクセルの破片: 回りながら飛び、床で跳ねて転がり、縮んで消える（見た目だけ、CPU で計算、上限 4000 個） |
| 受け渡し | `IGame.BuildVoxelVolumes`、各描画器の `voxels` 引数 | ゲームが描くボクセルの体積を、ホスト（デスクトップ・VR・動画）が描画器へ渡す |

剛体は消さず（Bepu はハンドルを使い回すため、エンジンの方針で削除の動詞を持たない）、**削れた剛体は形を変え、切れた先は新しい剛体として足す**、で一貫させています。

### GPU で表面を作る（`VoxelVolumePipeline`）

いちばん簡単な「境界面」の作り方です（なめらかにしない、ブロック状の面）。

- 頂点バッファは使いません。体積 1 つにつき「セル数 × 6 面 × 6 頂点」を 1 回の描画で出します。
- 頂点シェーダが頂点の番号から「どのセルの、どの面の、どの角か」を割り出し、`texelFetch` でそのセルと面の向こうの隣を読みます。
- **中身のあるセルで、隣が空か体積の外**のときだけ面を出します。それ以外の面は画面の外の 1 点に潰し、描かれません。
- 面の法線で、エンジン既定の太陽と空・地面の環境光の簡単な陰影を付けます。不透明で深度を書き、不透明な物と一緒に描きます。
- テクスチャのアップロードは版が変わった体積だけで、削れた瞬間に 1 回です。

### 体の形（ローポリの形の内側）

- 各ボクセルの中心がローポリのメッシュ（部位のローカルで閉じた形）の内側かを、光線が面を横切る回数の偶奇で判定し、内側だけを埋めます。判定はモデル × 格子の大きさごとに 1 度だけで、モデルは同じ体格の試合で共有します。
- 骨・臓器の配置は、箱ではなくメッシュ自身の外形を −1..1 とした座標で決めます（箱のままだと細い腕がほとんど骨になる）。
- 皮膚（元の外側）は、最初から空と接していたボクセルです。

### 削り方（`VoxelGrid.Carve`）

- 1 発は「当たった点・拳の進む向き・削る量」で表します。削る量 1 で肉のボクセル 1 個です。
- 当たった点から拳の向きへ短い「掘る線」を引き、線に近く浅いボクセルから順に、削る量を使い切るまで削ります。強い 1 発ほど線が長く（削る量の立方根に比例）、深く掘れます。
- ボクセルは残りの硬さを覚えています。骨（硬さ 8）は弱い 1 発では止め、何発も受けると割れます。
- 削った穴の周り（掘る線の 2 倍の範囲）は、近いほど濃く血の色に染まります。

### 骨の断裂と切り離し（`FindBoneBreak` / `Split` / `VoxelBody.Sever`）

- 部位の長さの軸に沿って断面ごとに骨を数え、両側にはまだ骨があるのに骨が 0 になった断面を「断たれた所」とします。
- そこから遠い側のボクセルを新しい格子に移し、その外形の箱で新しい剛体を作ります。速度は切れた所の速度、質量はボクセルの割合、衝突の除外は元の部位と同じです。
- 残った側は、残りのボクセルの外形に当たり判定を縮め、質量も減らします。

## 2. ゲームの体（`games/MiniRing/Voxels`）

### 中身（`BoxerAnatomy`）

部位の箱のローカル（体の前が +Z、本人の左が +X）に置きます。どの臓器も、半分以上壊れると死にます。

| 部位 | 中身 |
|---|---|
| 頭 | 頭蓋（殻）の中に脳。あごの骨。顔の前に目 |
| 胸 | 背骨（背中側の柱）、肋骨（帯状、間は肉）、胸骨。籠の中に心臓（左寄り）、左右の肺、肝臓（右下） |
| 腰 | 骨盤の環、背骨、腸 |
| 上腕・前腕・腿・すね | 長さに沿った骨の芯、周りは肉 |
| 足 | 骨の板 |

| 材質 | 組織 | 硬さ | 致命的 | 色 |
|---|---|---|---|---|
| 皮膚（外側の 1 層） | 肉 | 0.7 | — | 肌色 |
| 筋肉 | 肉 | 1 | — | 赤 |
| 骨 | 骨 | 8 | — | 象牙色 |
| 脳 | 臓器 | 1.4 | ○ | 桃色 |
| 心臓・肝臓 | 臓器 | 1.4 | ○ | 暗い赤・赤茶 |
| 肺・腸 | 臓器 | 1.2 | ○ | 薄紅・黄土 |
| 目 | 臓器 | 0.8 | — | 表は黒目、中は白い眼球 |

外側の 1 層は皮膚です（作った直後に、元の表面にあるボクセルを皮膚に塗り替える。目だけは顔に出たまま）。削れると、その下の材質がその色で見えます。

1 人あたり約 1.76 万ボクセル（5mm）です。

### 遊びへの響き方

| 起きること | 効き方 |
|---|---|
| 腕の肉が削られる | 拳を目標へ引く力と、肩・肘のサーボの強さが、上腕・前腕の肉の残りに比例して落ちる（肉が無くても 15% は残る） |
| 脚の肉が削られる | 体を持ち上げる力・歩く力・股と膝のサーボが落ちる。弱い方の脚の力が 35% を下回ると、倒れて起き上がれない |
| 胴の肉が削られる | 体の軸を保つ力が落ちる |
| 腕の骨が断たれる | その腕はもう動かない。前腕が切れたら、グローブは破片と一緒に落ちる。掴んでいれば離す。落ちていく腕の打撃は数えない |
| 脚の骨が断たれる | 立てずに倒れ、起き上がれない（10 カウントで負け） |
| 臓器が半分以上壊れる | 死んで崩れ落ち、その場で K.O.（「K.O. — BRAIN DESTROYED」など） |

- 切れた所から先の関節（肘から先・膝から先）は、破片へ玉継手で付け替えます。その関節の筋肉（サーボ）は外すので、ぶらぶらになります。
- 破片とそれにぶら下がる部位は「体から外れた部位」になり、打撃・掴み・重心・押す力の対象から外れます。体とはぶつかるようになります（互いの間と切り口だけはぶつからない）。
- 前腕を 2 度切っても、グローブは最初に落ちた先の破片に付いたままです。
- 削る量は「打撃そのものの強さ」です（得点用の部位の倍率を外したダメージ × `CarvePerDamage`）。得点ではガードの上を 0.25 倍に割り引きますが、受けた腕にかかる衝撃は同じなので、ブロックし続けた腕は削れていきます。

### ボット同士での確かめ（champion 対 jabber、120 秒 × 4 試合、5mm のボクセル）

- 最初に腕が落ちるのは 28〜40 秒（ブロックで受け続けた前腕）。1 試合に 1〜3 回。
- 脳の破壊による K.O. は 68〜106 秒。
- 骨の硬さ 6 では早いと 17 秒で腕が落ちたので 8 にしています。ボクセルを 7mm から 5mm にしたとき、1 発で削る体積が変わらないよう `CarvePerDamage` を 1.6 → 4.3 にしました。
- 描画: ヘッドレスで 1280×720 の試合動画が約 0.6 倍速で書き出せます（CPU で立方体を並べていたときの約 1.7 倍の速さ）。VR の自己テストは、ボクセル込みで外部画像への描画が通常の描画と 1 バイトも違いません。VR の実機での重さはまだ確かめていません。

### 分かっている限界

- 切れた後の切り株は、当たり判定を残りのボクセルの外形に縮めますが、剛体の原点（重心）は元の場所のままです（関節の取り付け位置を保つため）。小さな切り株では重心が当たり判定から外れます。
- 骨の断裂は「骨が 1 つも無い断面」で判定するので、斜めに削って骨のつながりだけを断った場合は切れません。

### 砕け散る見た目

1 個のボクセルが砕けるたびに、次のものを飛ばします（`BoxingGame.SpawnDebris`、上限 9000 個）。

- その材質の色の欠片（速く、強く回る）と、細かい破片 2 つ。
- 骨: 白い粉 3 つと、光る火花（機械の部品が壊れるように）。
- 肉: 血しぶき 3 滴。
- 臓器: 血しぶき 3 滴と、光る赤い飛沫 2 つ。
- 当たった所: 一瞬の閃光（光る火花の放射）。致命傷では大きな赤い閃光。

光る破片はエンジンの `MaterialKind.Emissive`（太陽や影を無視して自分の色で光る）で描きます。

### 砕ける音（`Audio/VoxelBreakSound.cs`）

機械の部品が壊れる雰囲気で、ボクセル 1 個に 1 粒の音を鳴らします（素材ファイルなし・合成）。

| 材質 | 粒の音 | 長さ |
|---|---|---|
| 皮膚 | 金属の小さな「チッ」（高い不協和な倍音と、短いクリック） | 約 30ms |
| 肉 | 歯車がかみ合う「ガリッ」と、低い「ガコッ」 | 約 70ms |
| 骨 | 金属板が割れる鋭い音（量子化した破裂）と、わずかにずれた倍音でうなる金属の響き | 約 160ms |
| 臓器 | 重い「ドスッ」、粗く量子化した砕ける音、ひずんだ金属のうなり | 約 260ms |
| 脳 | 臓器の音に、電気の唸りと、下がっていく放電音 | 約 320ms |
| 目 | ガラスのレンズが割れる高い「キン」と小さな破裂 | 約 120ms |

- 1 発で砕けたボクセルは、砕けた順（当たった所に近い順）に約 3.5ms ずつずらし、粒ごとに音程を ±15% 揺らして重ねます。皮膚の「チッチッ」から骨の「バキン」、臓器の「ドスッ」へと、掘り進む様子が粒だって聞こえます。粒が 48 を超えたら間引き、残りを少し大きくします。
- 臓器と脳の粒は大きく重く鳴らします（ダメージが大きそうに）。
- **致命傷**（約 1.8 秒）: 心地よさ = 深い重低音の「ドン」と、上がっていく鐘の三和音（E6・G6・C7）。ヤバさ = 機械の電源が落ちていくような下降音（だんだん粗く量子化され、途中でつまずくように繰り返す）と、三全音（55Hz と 77.8Hz）の不協和なうなり。
- 試合は 1 発ごとに `ShatterEvent`（砕けた粒の列と致命傷か）を出し、デスクトップ・VR・再生・動画の書き出しが鳴らします。打撃音（`HitSound`）とは別に重なります。

## 3. 調整の入口（`FighterTuning`）

| 目的 | 値 |
|---|---|
| ボクセルの細かさ | `VoxelSize`（既定 5mm。細かいほど形が元の体に近く、GPU の頂点が増える） |
| 削れる速さ | `CarvePerDamage`（ダメージ 1 あたりの削る量） |
| 飛び散り方 | `ChipSpeed` |
| 死にやすさ | `OrganDeathFraction`（臓器がこの割合より少なくなったら死ぬ） |
| 弱り方 | `MinMuscleStrength`（肉が無くても残る力）、`StandStrength`（立っていられる脚の力） |
| 材質の硬さ・色・中身の配置 | `Voxels/BoxerAnatomy.cs` |
| 砕け散り方 | `BoxingGame.SpawnDebris`・`Burst` |
| 砕ける音・致命傷の音 | `Audio/VoxelBreakSound.cs`（粒ごとの合成、`Mix` の粒の間隔と音量、`Fatal`） |
