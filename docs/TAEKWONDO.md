## 膝の制御（2026-11-17、PhysicsVersion 39・LogicVersion 39・記録の版 11）

ユーザーの指定: キックは**膝の位置にバネの制御点**を置き、膝の制御点は**位置**と**ねじり方向の回転**を目標にする。その先のすねは**膝の曲げ伸ばしの 1 次元**だけを入力できる。蹴りは **膝の位置・ねじり角・膝の曲げ伸ばし** の 3 つで動かす。

- **契約**（`LegCommand`）: `KneeLocal`（膝の位置、体フレーム）・`KneeTwist`（腿の軸まわりのねじり [rad]。0 = すねを曲げると足が体の後ろ側へ行く向き = 体の後ろを軸に垂直な面へ落とした向きが曲げの法線。null = フリー）・`KneeBend`（膝の曲げ [rad]、0 = 伸びきり。null = フリー）。`KneeLocal` が null なら今までの足首の目標（踏み下ろし `GroundStrike`・空手の蹴り 5 種など、まだ移していない物）。幾何は `LegKnee`（入力元と体が同じ定義）、脚の寸法は `FighterSense.SelfLeg`（股・立った形の膝・腿とすねの長さ。体フレーム）。
- **体の側**（`Fighter.ApplyKneeControl`）: 膝の点（腿の先）を PD 力で目標へ引く（反作用は骨盤。拳・足首と同じ `FighterMath.HandAccel`、力の上限は歩く足の上限の `KickKneeForceGain` 倍）。股のサーボの目標 = 「立った腿の向き → 股から膝への向き」へ振る回転 × 腿の軸まわりの `KneeTwist`。膝のサーボの目標 = `KneeBend`。**フリーのときは今の値を目標にする**ので、バネは効かずダンパだけ（ねじりは今の腿の向きから測る）。蹴りの間、足首は引かない（すねの先は膝の曲げと慣性で振られる）。足首の曲げの目標だけは入力の足の向き（`Orientation` の X 軸まわり、すねに対する角）。
- **脚のサーボの強さ**: 膝の制御で蹴っている脚の股・膝のサーボのトルクは `KickLegTorqueGain`（3 倍。測ると 3 倍と 8 倍で結果が同じなので、トルクは上限になっていない）、最大の速さは `KickLegServoSpeed`（30 rad/s、歩く足は 10）。**速さの上限が効いていた**: 10 rad/s のままだと、すねを 1.7 → 0 rad へ 0.17 秒で伸ばす指令（9.6 rad/s）に実際の曲げが 0.1 秒遅れ、すねが伸びきる前に当たっていた（測った）。`PhysicsWorld.SetTwistServoSettings`/`SetAngularServoSettings` に `maxSpeed` の引数を足した（エンジンへの変更、`docs/REUSE.md`）。
- **回し蹴りの経路**（`KickSpec.EvaluateKnee`。技の分岐は無く、目標の時間変化）: 段 1（抱え）膝を蹴る脚の側の横・やや上（前から 69° 外・水平から 20° 上）へ。ねじり・曲げはフリー。段 2（回し）膝を前（当てる点の方）へ回しながら、ねじりを「すねが狙いを向く角」へ、曲げを伸ばす方へ（曲げの変化は回しの後半に寄せる）。段 3 畳み直す。段 4 戻す（フリー）。体の向き・胴のひねり（`FaceYaw`・`TorsoTwist`）は今までの回し蹴りのもの。
- **距離でフォームが変わる**: 当たる瞬間は、すねの「膝から `ShinPoint`（0.75。足首とすねの中間）の点」が狙い（脇腹: 胸と腰の中間。`Overshoot` −0.2 で表面）へ来るように、股から狙いまでの距離 D を腿の長さ r とすね×0.75 の届く範囲へ丸め（遠すぎれば届く所まで。伸びきらないよう `KneeContactMinBend` 0.45 rad を残す）、膝を「股を中心とする腿の長さの球」と「狙いを中心とするすね×0.75 の球」の交わりの円の上（体の外・上寄り）に置く。曲げは余弦定理（D² = r² + (0.75 L)² + 2 r (0.75 L) cos 曲げ）から、ねじりはすねが狙いを向く幾何から連続に出る。
- **間合いを覚える**（`kicklab`、§1.8）: 回し蹴りの `Standoff` を 0.90 → **1.25** に（測定と採否は `docs/arena/kicklab_roundhouse.md`）。表は実測の間合い 0.1 刻み。1.26 の束は帯内（すねの点 0.5〜1.2）85%・使っていない種でも 86%・13/13 当たり・3.98〜4.10 J。エネルギー/蹴りの最大は帯の外（つま先が先に当たる 1.4 以上）に出るので、最大だけでは採らなかった。
- **動画**: `kickvideo`（3 つの間合い。0.25 倍スロー、真横、金の線 = 膝の制御点）。見たこと: 膝が体の前・横へ上がり、すねがぶら下がった形から水平へ伸びて足が相手へ届く。間合い 0.89 は腿が相手の腕・脚に当たって（0.23 J）すねが伸びきれない。間合い 1.23 は足の甲（すねの点 1.09、3.2 m/s、8.7 J）が相手の腿の高さに当たる。間合い 1.47 はつま先（1.32、3.5 m/s、10.4 J）が相手の膝・腿に当たる。
- **移したのは回し蹴りだけ**。横蹴り・後ろ蹴り・かかと落とし・前蹴り・ロー・ミドル・ハイ・膝・空手の 5 種・踏み下ろしは、足首の経路のまま動く（`KickSpec.UsesKnee` が回し蹴りだけ true）。移すときは `EvaluateKnee` と同じ契約で、段ごとの膝の向き・ねじり・曲げを書く。

## 回し蹴りのロー・ミドル・ハイと、すねの下の方で当てる練習・前蹴りの手本（2026-11-17、LogicVersion 42・PhysicsVersion 43）

## 蹴りの経路（`KickSpec`、`KickTechnique` の末尾に 4 つ）

どれも目標の時間変化だけ（アニメーション・種類ごとの倍率・当たり判定は無い）。足首の目標（体フレーム）に加え、回す蹴りは `FighterCommand.FaceDirection`（体の向き）と `TwistBias`（胴のひねり）を経路で出し、体が物理で追う（`KickSpec.FaceYaw`・`TorsoTwist`・`TurnProfile`: 当たる前に回りきり、畳み直すころに戻す）。体が回ると狙いの体フレームでの位置が動くので、ボットは毎歩狙いを求め直す。

| 蹴り | 経路 | 足首の曲げ | 体の向き / ひねり |
|---|---|---|---|
| 回し蹴り `Roundhouse` | **膝の制御**（上の節）: 膝を横へ上げ、前へ回しながらすねを伸ばす。狙いは脇腹 | すねに対して背屈 −0.5 | 1.0 rad / 0.6 rad（脚の側の腰が前へ） |
| 横蹴り `Side` | 膝を胸へ畳み、体を横へ向けて真っすぐ押し出す | 0 | 1.45 rad / 0.5 rad |
| 後ろ蹴り `Back` | 背を向ける回転（150°）の中で畳み、後ろへ伸ばす | つま先を上げる | −2.6 rad / 0.5 rad |
| かかと落とし `Axe` | 狙い（頭のてっぺん）の上・手前まで脚を上げ、振り下ろす | つま先を上げる（かかとが先） | 回さない |

`Standoff`（その蹴りが届く胸と胸の距離、腕の長さ倍）は見える体の寸法から。テコンドーの選び方は `BotStyle.KickRangeFit`（0 なら今までどおり重みだけ。正なら今の間合いと `Standoff` の合い具合で重みを連続に変える）。「テコンドーなら」の分岐は判断の式に無く、違いは JSON の値（`KickRate` 0.75、回し蹴り 3・横蹴り 2・ほか 1、拳の重みは小さい）。

## 弱いところ・近道

- 回し蹴り以外の足の速さは足首 1 点の力の上限（`KickFootForceGain`）で決まり、0.6〜3.5 m/s。回し蹴りは膝の制御で、足の速さは関節の速さの上限（`KickLegServoSpeed`）と慣性で決まる（kicklab で 1.4〜2.4 m/s、つま先が先に当たる束は 3 m/s 台）。
- かかと落としは脚がまっすぐ斜めに倒れるのですねが先に当たり、かかとは後から（かかと先頭にはなりきっていない）。位置を少し変えると軸足が崩れて倒れた（Standoff 0.8）。
- 後ろ蹴りは体が回って脚を畳むが、後ろへ伸びる脚が映像では見分けにくい。
- 回す蹴りの回転は体の向きの目標（FaceDirection）の変化で作る近道を含む（胴のひねりは上限 35°）。
- **膝の制御の回し蹴りの近道・残った問題**（2026-11-17）: (1) 膝の点を引く力の上限（`KickKneeForceGain` 4）・脚のサーボのトルク（`KickLegTorqueGain` 3）・速さの上限（`KickLegServoSpeed` 30 rad/s）は、足首 1 点の近道の代わりに置いた調整値で、脚の関節トルクの全力を測って決めたものではない（トルクは 3 と 8 で結果が同じ）。(2) 当たるのは足の甲・つま先が多く、すねの中ほど（0.5〜0.75）には当たらない（kicklab の「当たったすねの点」平均 0.4〜1.1、本命の当たりは足の甲 1.1 前後）: 脚の長さが胸と胸の距離に対して短く、すねが相手の面と平行になる所まで届かない。(3) 相手に当たる所は腕（`Elbow`・`Guard`）と脚（`Leg`・`Knee`）が多く、胴は少ない。(4) 腿の軸まわりのねじりは、膝を前へ回す間に最大 180° 近く回す指令が出る（人の股関節の可動域は持たない）。(5) 右脚（後ろ足）は左脚より当たりが弱く出る（右脚は腿・すねが低いエネルギーで当たる束が多い。止まる間合いが右と左で違うことを含め、原因は未確認）。(6) 蹴りの選び方に使う手がかりは間合いだけ（相手の拳の読み・頭の高さは使っていない。狙いの点は相手の頭・胸の位置に追従する）。
