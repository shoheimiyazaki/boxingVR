# ボクシングの力学と部位ダメージ

## 1. パンチの力学（`games/MiniRing/PunchMechanics.cs`）

ジャブ・ストレート・フック・アッパーを**種類で場合分けしません**。決まるのは「拳と体の軸の位置関係」と「力の向き」だけで、そこから体重がどれだけ乗るかが連続的に決まります。プレイヤーの腕の動かし方、CPU の拳の経路、キーボードの修飾キーが変えるのは**経路だけ**です。

### 1-1. 体の有効質量 — 力の作用線と体の軸の関係

自由な剛体の重心から r の点に、向き n の撃力が加わったとき、相手が感じる質量は次の式で決まります。

```
m_body = 1 / ( 1/M + (r×n)ᵀ I⁻¹ (r×n) )
```

- M は体重です。I は重心まわりの慣性で、体を円柱で近似し、胴の向きを主軸にしています。
- **作用線が体の軸を通る（r×n = 0）**: 体重 M がそのまま乗ります。重心へ向かって押す・引く一撃（体の真ん中から出すストレート）です。
- **作用線が軸から外れる**: 体が回って逃げるので、乗る質量が減ります。腕だけ横から払う手打ちです。
- **体の軸まわりに回す（接線方向）**: ひねりの回転慣性 I_yaw / r² が乗ります（フック）。軸に近い（コンパクトな）ほど大きくなります。
- **体の軸に沿って突き上げる**: 前後に倒す慣性が大きいので、重く乗ります（アッパー）。

| 例（体重 6.8kg・テストの値） | 乗る質量 |
|---|---|
| 作用線が重心を通る | 6.8kg（体重そのもの） |
| 軸から 8cm 外れた押し | 体重の 3 割未満 |
| 半径 5cm のフック | 半径 10cm のフックより重い |

### 1-2. 腕の連結度 — 体の質量を拳まで通せるか

体の質量は腕を通ってしか拳に届きません。拳の向きと肩→拳の線の揃い具合を a として、連結度を次のように決めます。

```
coupling = ( a² + 0.55 · (1 − a²) ) × 関節の健全度
```

- **肩→拳の線に沿って押す・引く**（骨で突っ張る）: 体の質量が丸ごと伝わります。押しても引いても同じです（a²）。
- **線に直交する力**: 肩と肘を固めて体の回転に乗せた分（てこ、55%）だけ伝わります。
- **関節の健全度**: 肩 × 肘 × 脚（地面を押す）で決まります。痛めているほど同じ動きでも手打ちになります。

### 1-3. 拳に乗る質量・力・ダメージ

| 量 | 式 |
|---|---|
| 拳に乗る質量 | `腕の質量 + coupling × m_body` |
| 腕が出せる力の上限 | `腕の筋力 × (1 + 1.5 × coupling × m_body / M)`（体を借りられるほど脚と腰の力が乗る） |
| ダメージ | `11 × (√運動量 − √0.25) × 鋭さ(速さ) × 部位の倍率`（運動量 = 質量 × 踏み込み速度） |

- 体から借りた力の 3 割は胴を拳の方向へ押し出し、体重移動として見えます。
- ダメージの √ は、手打ちと体重の乗った一撃の差を数倍に収めるためです。
- 「鋭さ」は速さに応じた滑らかな係数で、ゆっくり押し当てた接触（押し合い）を打撃に数えないためのものです。
- 体から来た分の運動量は、物理の接触では伝わらないため、相手の**全身へ一様な速度変化**として足します（上限 0.6m/s）。同じ運動量の反作用を打った側の全身へ返すので、運動量は湧きません。
- 倒れている相手（起き上がり中を含む）への打撃は数えません。CPU も倒れた相手には手を出しません。

### 1-4. 体の軸の向き — 両手と頭の位置から

- **ひねり** = 35° × tanh(0.9 ×（右手と左手の前後差）+ 0.6 ×（両手の横位置の和））。
  - 前に出た手、または体の中心を横切る手の側の肩が前に出ます。
  - 腰は胸のひねりの 45% だけ回ります。
- **前傾・横傾き** = 頭のずれ（構えの位置からの差）÷ 胴の長さ、の角度です（最大 30°）。
- **沈み込み**: 頭を下げるとダッキングになり、立つ高さが最大 30% 下がります。
- VR では、肩を「ゆっくり追従する構えの頭位置」から推定し、それより速い頭の動きを人形の体の傾きとして渡します。頭だけ振っても腕の写像は動きません。

## 2. 部位ダメージ（`HitZones.cs` / `BodyCondition.cs`）

当たった点を部位ローカル（+Z 前・+Y 上・+X 本人の左）に直し、箱の中のどこかで判定します。

| 部位 | 場所 | 倍率 | 効き目 |
|---|---|---|---|
| 顎 | 頭の前・下 | 1.3 | 意識 ×1.6（反応遅れ・脱力）、首・脚も少し。顎・こめかみは軽めでもダウン |
| こめかみ | 頭の横 | 1.15 | 意識 ×1.3、脚 |
| 頭 | それ以外 | 1.0 | 意識 ×0.7 |
| 首 | 頭の底・胸の上端中央 | 1.1 | 首（頭が据わらない・反応遅れ）、意識 |
| 心臓 | 胸の前面・左 | 1.0 | **一瞬固まる**（反応遅れ＋起き上がれない）、スタミナと上限、心臓（スタミナが戻りにくい） |
| 肝臓 | 胸の右下・骨盤の右上 | 1.1 | **0.8 秒遅れて**脚とスタミナ。打たれた直後は平気そうで、少し後に崩れる |
| みぞおち | 胸の中央下 | 0.9 | スタミナ ×1.2 |
| ボディ | 胴のそれ以外 | 0.7 | スタミナ、脚 |
| 肩 | 上腕の体側半分 | 0.6 | その腕の肩（**腕が上がらない**・力が伝わらない） |
| 肘 | 上腕の外側半分・前腕の付け根 | 0.5 | その腕の肘（肘サーボが弱い・筋力） |
| ガード | 前腕（グローブ） | 0.25 | ガードの上からでも肘とスタミナを削る |
| 膝 | 腿の下端・すねの上端 | 0.8 | 脚 ×1.5（**立てない**） |
| 脚 | 脚のそれ以外 | 0.4 | 脚 |

### 性能の低下（すべて連続関数）

| 性能 | 決まり方 |
|---|---|
| 反応遅れ | 20ms + 300ms ×（1 − 意識）+ 120ms ×（1 − 首）+ 心臓の固まり。体は遅れた指令に従う。遅れが急に増えた間は体が固まり（過去の指令へ巻き戻さない）、追いつくときも実時間の 1.5 倍まで |
| 全身の駆動 | 意識が 0 に近いほど 45% まで抜ける |
| 脚 | ホバー・歩行速度・脚サーボ・立つ高さ（膝が折れて低くなる） |
| 立てるか | 脚 > 18% かつ 意識 > 12%。起き上がりには脚・意識 > 35% と、心臓で固まっていないことが必要 |
| 腕を上げられる高さ | 肩と（0.4 + 0.6 × スタミナ）の小さい方で、肩より上 0.6 腕長 〜 下 0.8 腕長 |
| 腕の筋力 | スタミナ・肩 × 肘・意識 |

- **回復**: 意識は頭を打たれずに 1.5 秒たつと戻り始め、脚・首・スタミナは徐々に戻ります。それぞれのダメージの 25% は上限を削り、その試合中は戻りません。
- **スタミナの消費**: 拳に掛けた仕事と、力を出し続けること自体で減ります。
- **勝敗**: 意識が 0 で KO です。倒れて 10 秒立てなければ 10 カウント KO で、脚を壊されて立てない場合もこれに当たります。リングから落ちても負けです。

## 3. ローポリの体と打撃のへこみ（`LowPoly/`）

- **形**: 部位ごとに、輪を重ねたローポリ（`BoxerShapes`）。頭は額・眉弓・鼻筋と窪んだ眼窩・鼻先・頬骨・耳・口・顎先とエラ（112 枚）、胸は僧帽筋・肩・胸筋・みぞおち・腹筋（96 枚）、上腕は力こぶと三頭筋、前腕は平たい形。脚・足は六角柱です。
- **細分化**: 辺の中点で 1 回割ります（`FighterTuning.ModelSubdivisions`、三角形 4 倍）。頂点を動かさないので形はローポリのままで、変形できるノードだけが細かくなります。
- **へこみ**: 当たった部位の、拳の表面から `DentSpread` 以内のノードを、拳の速度の向きへ動かします。深さはダメージ × `DentDepthPerDamage`（1 発 `MaxDentDepthPerHit` まで）、近いほど大きく（(1 − x²)² の山）。累積は部位の最小半径 × `MaxDentRatio` で止まります。
- **色**: ノードの変位 ÷ 上限で、白 → 赤。三角形は 3 ノードの平均の色です。体は白なので、どちらのファイターかはグローブの色（赤＝プレイヤー、青＝CPU）で見分けます。
- **描き方**: エンジンのメッシュは書き換え不可・1 インスタンス 1 色・行列はせん断不可なので、へこんだ部位は三角形を直角三角形 2 枚に割り、単位直角三角形 1 つを回転と非一様拡大で並べます（`RightTriangles`）。へこんでいない部位は静的メッシュ 1 個です。全部位がへこんでも 1 万インスタンス程度で、詰める処理はリリースビルドで約 0.4ms/フレームでした。
- へこみは見た目だけです。当たり判定・急所の判定は今までどおり箱で行い、ラウンドごとに新品に戻ります。

## 4. 調整の入口

| 目的 | 場所 |
|---|---|
| 体重の乗り方 | `PunchMechanics.LeverTransfer`、`FighterTuning.BodyDrive`、`WeightShiftShare` |
| ダメージ量 | `PunchMechanics.DamageScale`、`MomentumThreshold`、`Sharpness`、`ZoneDamage.Multiplier` |
| 体の軸 | `FighterTuning.MaxTorsoTwistRadians`、`HipTwistShare`、`MaxLeanRadians` |
| 効き目・回復 | `BodyCondition` の各係数 |
| へこみ・色 | `FighterTuning.DentDepthPerDamage`、`MaxDentDepthPerHit`、`DentSpread`、`MaxDentRatio`、`ModelSubdivisions` |

`MatchStatsProbe` を detailed ログで実行すると、CPU 同士 30 秒のヒット分布が出ます。部位ごとの件数・平均ダメージ・乗った質量・速さ・体の割合で、調整の目安になります。
