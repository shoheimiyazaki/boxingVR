# ボクシングの力学・部位ダメージ・打撃音

## 1. パンチの力学（`games/MiniRing/PunchMechanics.cs`）

ジャブ・ストレート・フック・アッパーを**種類で場合分けしません**。決まるのは「拳と体の軸の位置関係」と「力の向き」だけで、そこから体重がどれだけ乗るかが連続的に決まります。プレイヤーの腕の動かし方、CPU の拳の経路、キーボードの修飾キーが変えるのは**経路だけ**です。

### 1-1. 体の有効質量 — 力の作用線と体の軸の関係

自由な剛体の重心から r の点に、向き n の撃力が加わったとき、相手が感じる質量は次の式で決まります。

```
m_body = 1 / ( 1/M + (r×n)ᵀ I⁻¹ (r×n) )
```

- M は体重です。I は重心まわりの慣性で、体を円柱で近似し、胴の向きを主軸にしています。
- **作用線が体の軸を通る（r×n = 0）**: 体重 M がそのまま乗ります。重心へ向かって押す・引く一撃（体の真ん中から出すストレート）です。
- **作用線が軸から外れる**: 体が回って逃げるので、乗る質量が減ります。腕だけ横から払う手打ちです。
- **体の軸まわりに回す（接線方向）**: ひねりの回転慣性 I_yaw / r² が乗ります（フック）。軸に近い（コンパクトな）ほど大きくなります。
- **体の軸に沿って突き上げる**: 前後に倒す慣性が大きいので、重く乗ります（アッパー）。

| 例（体重 6.8kg・テストの値） | 乗る質量 |
|---|---|
| 作用線が重心を通る | 6.8kg（体重そのもの） |
| 軸から 8cm 外れた押し | 体重の 3 割未満 |
| 半径 5cm のフック | 半径 10cm のフックより重い |

### 1-2. 腕の連結度 — 体の質量を拳まで通せるか

体の質量は腕を通ってしか拳に届きません。拳の向きと肩→拳の線の揃い具合を a として、連結度を次のように決めます。

```
coupling = ( a² + 0.55 · (1 − a²) ) × 関節の健全度
```

- **肩→拳の線に沿って押す・引く**（骨で突っ張る）: 体の質量が丸ごと伝わります。押しても引いても同じです（a²）。
- **線に直交する力**: 肩と肘を固めて体の回転に乗せた分（てこ、55%）だけ伝わります。
- **関節の健全度**: 肩 × 肘 × 脚（地面を押す）で決まります。痛めているほど同じ動きでも手打ちになります。

### 1-3. 拳に乗る質量・力・ダメージ

| 量 | 式 |
|---|---|
| 拳に乗る質量 | `腕の質量 + coupling × m_body` |
| 腕が出せる力の上限 | `腕の筋力 × (1 + 1.5 × coupling × m_body / M)`（体を借りられるほど脚と腰の力が乗る） |
| ダメージ | `11 × (√運動量 − √0.25) × 鋭さ(速さ) × 部位の倍率`（運動量 = 質量 × 踏み込み速度） |

- 体から借りた力の 3 割は胴を拳の方向へ押し出し、体重移動として見えます。
- ダメージの √ は、手打ちと体重の乗った一撃の差を数倍に収めるためです。
- 「鋭さ」は速さに応じた滑らかな係数で、ゆっくり押し当てた接触（押し合い）を打撃に数えないためのものです。
- 体から来た分の運動量は、物理の接触では伝わらないため、相手の**全身へ一様な速度変化**として足します（上限 0.6m/s）。同じ運動量の反作用を打った側の全身へ返すので、運動量は湧きません。
- 倒れている相手（起き上がり中を含む）への打撃は数えません。CPU も倒れた相手には手を出しません。

### 1-4. 体の軸の向き — 両手と頭の位置から

- **ひねり** = 35° × tanh(0.9 ×（右手と左手の前後差）+ 0.6 ×（両手の横位置の和））。
  - 前に出た手、または体の中心を横切る手の側の肩が前に出ます。
  - 腰は胸のひねりの 45% だけ回ります。
- **前傾・横傾き** = 頭のずれ（構えの位置からの差）÷ 胴の長さ、の角度です（最大 30°）。
- **沈み込み**: 頭を下げるとダッキングになり、立つ高さが最大 30% 下がります。
- VR では、肩を「ゆっくり追従する構えの頭位置」から推定し、それより速い頭の動きを人形の体の傾きとして渡します。頭だけ振っても腕の写像は動きません。

### 1-5. 足の運び（`Footwork.cs` / `LegIk.cs`）

足はかかと側とつま先の 2 つの部位で、母指球の蝶番でつながっています。構えは左足が前（オーソドックス）で、かかとを少し浮かせて母指球に乗ります。

- **足の置き場所（`Footwork`）**: 倒立振子のモデルで決めます。
  - **捕捉点** = 骨盤の位置 + 速度 / ω（ω = √(g / 骨盤の高さ)）。ここに足を置けば体を止められる点です。
  - 構えの中心は、止まっていれば今の両足の真ん中です。捕捉点が真ん中から離れたら（押された・動いている）その分だけ寄せ、移動の意図（指令の速度 × 0.3 秒）を先に見越します。
  - 中心の周りの構えの位置（左前・右後ろ）から外れた足、届かなくなった足は 1 歩ずつ踏み直します。捕捉点が両足を結ぶ線から外れたら、倒れる向きへ踏み出して体を受け止めます。
  - **どちらの足から出るか**: 行く向きの側の足からです（前へは前足、後ろへは後ろ足、左へは左足、右へは右足）。踏んだばかりなら、もう一方の足が付いていきます（ステップ・ドラッグ）。
  - 足は交差させず、両足の開きにも上限があります。踏み出す先は、股の高さから脚が水平に届く範囲に収めます。
  - **打つとき**: 胴のひねりに合わせて軸足を母指球で回し（かかとを外へ返す）、かかとをさらに浮かせ、体重を前足へ移します。右の拳は後ろ足、左のフックは前足が軸です。
- **体は足に付いていく**: 骨盤は移動の指令に 0.08 秒遅れて付いていき（その間に足が先に踏み出す）、両足の間の支えの点（体重のかけ方で前後へ寄る）へ弱く寄せられます。支えの点から離れすぎると、離れる向きの速さを抑えます（体が足を置いて先へ行かない）。
- **脚（`LegIk`）**: 足首の目標へ 2 ボーン IK で股・膝を解き、足首はかかとの浮きに合わせて曲げ、つま先は反らせて床に付けたままにします。
  - IK は今の骨盤の位置と、**目標の姿勢**から解きます。今の姿勢から解くと、傾いた骨盤を脚が支え直さず、骨盤が 45° 傾きました。
  - 足首は手の拳と同じく PD の力で目標へ引きます（反作用は骨盤へ）。サーボだけでは、すり足の足が床の摩擦に負けて置き場所まで運べませんでした。着いている足は床から引き上げません。
- **関節の位置**: 関節の重なり代（子の部位の箱が関節から親の側へはみ出す長さ）と足首から足の中心までのずれは、体の縮尺に合わせます（Aigis の既定 3cm・5cm は 1.7m の体用）。前腕は肘から 1.1cm、かかとは足首から 1.8cm だけ出ます。
  - 骨盤の高さは、着いた足に膝を 30° 曲げて届く高さが上限です（足を開くほど腰が落ちる）。脚が床と体の間で受け持つ重さは姿勢で変わるので、高さのずれは積分して打ち消します。頭を下げれば（ダッキング）骨盤が沈み、膝が曲がります。
  - 足の運びの間は脚の重さを床が支えるので、浮かせるのは上体だけです。

## 2. 部位ダメージと打撃音（`HitZones.cs` / `BodyCondition.cs` / `Audio/`）

**この節のダメージ（点数）は、動きに影響しません。** 反応が遅れる・スタミナが尽きる・よろめく、といった点数による性能低下はありません。

動きに響くのは**体そのものの壊れ方**です。体はボクセルでできていて、打撃で削れます。肉が削れた部位は力が落ち、骨が断たれた腕・脚は落ち、臓器が壊れると死にます（[VOXEL_DAMAGE.md](VOXEL_DAMAGE.md)）。

ダメージの使い道は次の 3 つです。

| 使い道 | 内容 |
|---|---|
| 打撃音 | 強さと芯の食い方で音色が変わる（下記） |
| 見た目 | 拳が当たった所がへこみ、へこんだ量に応じて白から赤になる（§3） |
| 得点 | 画面の左右に、相手に与えたダメージの合計とクリーンヒット（ガード以外）の数を出す |

当たった点を部位ローカル（+Z 前・+Y 上・+X 本人の左）に直し、箱の中のどこかで部位を判定します。倍率はダメージ量に掛かります。

| 部位 | 場所 | 倍率 |
|---|---|---|
| 顎 | 頭の前・下 | 1.3 |
| こめかみ | 頭の横 | 1.15 |
| 頭 | それ以外 | 1.0 |
| 首 | 頭の底・胸の上端中央 | 1.1 |
| 心臓 | 胸の前面・左 | 1.0 |
| 肝臓 | 胸の右下・骨盤の右上 | 1.1 |
| みぞおち | 胸の中央下 | 0.9 |
| ボディ | 胴のそれ以外 | 0.7 |
| 肩 | 上腕の体側半分 | 0.6 |
| 肘 | 上腕の外側半分・前腕の付け根 | 0.5 |
| ガード | 前腕（グローブ） | 0.25 |
| 膝 | 腿の下端・すねの上端 | 0.8 |
| 脚 | 脚のそれ以外 | 0.4 |

### 打撃音（`Audio/HitSound.cs`）

音の素材ファイルは使わず、一撃ごとに 2 つの値から合成します。

| 値 | 決まり方 | 音への効き方 |
|---|---|---|
| 強さ 0..1 | ダメージ ÷ 28 | 低く太く、長く、大きくなる。強打では低い「ズン」が加わる |
| 芯 0..1 | 体重の乗り具合（BodyShare）。急所（顎・こめかみ・肝臓・みぞおち）は上乗せ。ガード・肩・肘は低い | 破裂音「パンッ」が明るく鋭くなる。芯を食うと短い「パキッ」が加わる |

音は 4 つの層を重ねています。最後に小さな部屋の響きを付け、柔らかくクリップして角を丸めます。

| 層 | 音 | 鳴るとき |
|---|---|---|
| ドスッ | ピッチが落ちる低い正弦 | 常に |
| パンッ | 帯域を絞ったノイズの破裂 | 常に |
| パキッ | ごく短い高域のクラック | 芯を食ったとき |
| ズン | 50Hz の低い余韻 | 強打のとき |

当たった場所でも芯の高さが変わり、頭は少し高く、ボディは低く、ガードはこもった音になります。
音色は強さ 8 段 × 芯 4 段 × 場所 3 種で、初めて鳴らすときに合成してキャッシュします。鳴らすたびにピッチを ±4% 揺らすので、同じ音の繰り返しには聞こえません。
音は試合の外側（`HitSoundGame` と VR ホスト）で鳴らすので、物理・記録・再生の決定性には影響しません。再生（`run.cmd replay`）でも鳴ります。
出力先は Windows の既定の音声デバイスです（Quest Link 中は Link の音声出力）。デバイスがなければ黙って鳴らしません。

## 3. ローポリの体と打撃のへこみ（`LowPoly/`）

> 体の見た目はボクセル（[VOXEL_DAMAGE.md](VOXEL_DAMAGE.md)）に替わりました。ローポリの体は、ボクセルの体を持たないファイターを描くときだけ使います（へこみの記録は今も続けています）。

- **形**: 部位ごとに、輪を重ねたローポリ（`BoxerShapes`）。頭は額・眉弓・鼻筋と窪んだ眼窩・鼻先・頬骨・耳・口・顎先とエラ（112 枚）、胸は僧帽筋・肩・胸筋・みぞおち・腹筋（96 枚）、上腕は力こぶと三頭筋、前腕は平たい形。脚・足は六角柱です。
- **細分化**: 辺の中点で 1 回割ります（`FighterTuning.ModelSubdivisions`、三角形 4 倍）。頂点を動かさないので形はローポリのままで、変形できるノードだけが細かくなります。
- **へこみ**: 当たった部位の、拳の表面から `DentSpread` 以内のノードを、拳の速度の向きへ動かします。深さはダメージ × `DentDepthPerDamage`（1 発 `MaxDentDepthPerHit` まで）、近いほど大きく（(1 − x²)² の山）。累積は部位の最小半径 × `MaxDentRatio` で止まります。
- **色**: ノードの変位 ÷ 上限で、白 → 赤。三角形は 3 ノードの平均の色です。体は白なので、どちらのファイターかはグローブの色（赤＝プレイヤー、青＝CPU）で見分けます。
- **描き方**: エンジンのメッシュは書き換え不可・1 インスタンス 1 色・行列はせん断不可なので、へこんだ部位は三角形を直角三角形 2 枚に割り、単位直角三角形 1 つを回転と非一様拡大で並べます（`RightTriangles`）。へこんでいない部位は静的メッシュ 1 個です。全部位がへこんでも 1 万インスタンス程度で、詰める処理はリリースビルドで約 0.4ms/フレームでした。
- へこみは見た目だけです。当たり判定・急所の判定は今までどおり箱で行い、ラウンドごとに新品に戻ります。
