# 団体（WVC・VFC・IVF）の決まり・王座・ランキング

2026-11-19、IVF（Interesting Voxing Federation）を足したときに 3 団体の違いを整理した（ユーザーの指定: 「階級別にして WVC と差別化」「王座・ランキング・勝ち負けのルールは他の団体も含め、整理して差別化」）。
体・物理・材料・ボットの判断は団体によらず同じ（CLAUDE.md §1.5）。違うのは**試合の決まり・出場の条件・王座とランキング・中継の見せ方**で、すべて団体のファイル `games/MiniRing.Arena/Orgs/<id>.json` の値（コードに団体名の分岐を書かない）。

## 3 団体の比べ

| | WVC（Wonderful Voxing Council） | VFC（Voxel Fighting Championship） | IVF（Interesting Voxing Federation） |
|---|---|---|---|
| 競技 | Voxing | Voxel Fighting | Voxing |
| 性格 | 格式の高い無差別級。ボクサー同士がメインで、まれに異種格闘技戦 | 何でもあり。決着は死だけ | 階級制の純粋なボクシング |
| 体重 | 無差別級（1 階級） | 無差別（1 階級） | **計量して 5 階級**: ライト 〜64 kg・ミドル 〜73・ライトヘビー 〜80・クルーザー 〜91・ヘビー 91〜。**同じ階級どうししか組めない** |
| 出場 | 誰でも（素手・はめる物・武器の選手も招く） | 誰でも | **グローブを着けさせる**・武器なし・ボクシングの教科書（champion・jabber・slugger・boxer・outboxer・swarmer・counter）だけ |
| 場 | 四角いリング・レフェリーあり | 六角形の金網の檻・レフェリーなし | 四角いリング・レフェリーあり |
| 勝ち方 | 10 カウント・失神（動かない）・リングアウト・死・判定（与えたダメージ） | 死だけ（ダウンを数えない）。5R 両者生還は引き分け | WVC の勝ち方 ＋ **3 ノックダウン制**（1 ラウンドに 3 度のダウンで TKO） |
| 休み（`match.regenVoxelsPerSecond`・`match.regrowth`。治る量 = 休みの長さ × 速さ） | **ほぼ治らない**（1.79 個/秒、休み 17 秒で 30 個ほど。削れた顔は次のラウンドも残る） | **速く治る**（前線の再生 1.26 mm/s。2026-11-24 に 0.84 から 1.5 倍） | 浅い傷が治る（標準の 89.37 個/秒、休み 17 秒で 1500 個ほど） |
| 王座 | **WVC 世界王座** 1 本（無差別） | **VFC 王者** 1 つ | **階級ごとの王座**（IVF ミドル級王座…） |
| ランキング | 所属（キャラの `org` = wvc）だけ | 所属（vfc）だけ | 出場の条件を満たす名簿の全員（所属を問わない） |
| 順位の点 | 勝ち 3・引き分け 1 | 勝ち 3・引き分け **0**（両者生還は評価しない） | 勝ち 3・引き分け 1・**倒して勝てば +1** |
| 中継 | 金・黒・赤、ゴング | クリーム・赤・黒、ホーン、暗い会場に檻のスポット | エメラルド・紺・銀、ゴング、明るく澄んだ会場。紋章は階級の王座のベルト（5 つの星 = 5 階級） |

軸との関係:
- 計量の体重は**見えている体**から出る（`CharacterProfile.WeightOf` = 物理の体の質量、試合の体の `Fighter.TotalMass` を kg に丸めた値。プロフィールの体重と同じ値。§1.7。2026-11-24 にそれまでの紙の式 72 kg × 身長の比² × 太さから物理へそろえ、ramon（63 kg）はライト級、yoandry（72 kg）はミドル級へ移った。席は試合をせずに移った階級のランキングの末尾）。階級は体重の値で引くだけで、強さの倍率は持たない。
- 出場の条件は見える物（はめる物・武器・教科書）だけで決める。
- 3 ノックダウン制・判定・ダウンを数えないは試合の決まり（`MatchRules`）で、体の物理ではない。`MatchRules.KnockdownLimit` の既定は 0（今の試合のまま 1 ビットも変わらない）なので `PhysicsVersion` は上げていない（VFC の決まりを足したときと同じ）。

## ファイルの欄（`Orgs/<id>.json` に足したもの）

| 欄 | 意味 |
|---|---|
| `match.limbBendStrengthScale` | 腕・脚の骨の曲げ強さの倍率。仕組みは残すが、どの団体も 1（2026-11-25、ユーザーの指定「大会ごとに材料の強さを変えない」。WVC は物理の版 83 から 0.60 だった。`OrganizationMatchTests` が全団体 1 を見る）。WVC の決まりでグローブどうしの 1 ラウンドに骨が折れる割合（`MaterialStrengthProbe.Wvc_GlovedFractureRatePerRound`、15 人の全組 × 種 2 = 210 ラウンド）: 0.60 で 61.9 %（0.91 本）→ 1 で 33.8 %（0.41 本）。目安の 3〜50 % の中 |
| `match.concussionSpinScale` | 意識の飛ぶ首のねじれの倍率（WVC 2.01）。見えない倍率の近道（docs/DEBT.md「団体の見えない倍率」） |
| `match.knockdownLimit` | 1 ラウンドにこの数のダウンで TKO（`"TKO — 3 KNOCKDOWNS"`）。0 なら無し |
| `entry.gear` | 団体が着けさせるはめる物（`glove` など。`null` なら選手のまま） |
| `entry.weapons` | 武器の選手が出られるか |
| `entry.textbooks` | 出られる教科書（書かなければ何でも） |
| `divisions` | 階級（軽い順。`limitKg` はその体重ちょうどまで。最後の 1 つだけ `null` = 上限なし） |
| `titles.belt` / `titleBout` / `bout` | 王座・王者が出る試合・出ない試合の呼び方（`{org}`・`{division}` を差し込む） |
| `ranking.membersOnly` / `win` / `draw` / `finishBonus` | 順位に入る選手と点 |

## 王座とランキングの記録（`Orgs/standings/<id>.json`）

- 階級ごとに `champion`（空位は `null`）と `ranking`（王者を除く強い順）。組み込みの資源（変えたらビルドし直す）。試合の中では読むだけで、変わるのは試合と試合の間（§1.6・§1.8 と同じ）。
- **王座は試合でしか動かない**: 王者が負ければ勝った選手へ移り、前の王者はランキングの 1 位へ。挑戦者どうしは、上の相手に勝てばそのすぐ上へ（`OrgStandings.AfterBout`）。
- ランキングの総当たり（`rankings`）は順位だけを決め直し、王者は王者のまま。空位の階級は `--crown on`（既定）で 1 位が王者になる（王座決定）。
- IVF のヘビー級の王者は名簿の経歴（マーカス「2018年: ヘビー級王座を獲得」）に合わせて初期値で置いた。ほかは総当たりで決めた（結果は `docs/arena/*_rankings.md`）。

## 道具

```
... weighin --org ivf                                   名簿の計量の表（体重・階級・出られるか・席）
... rankings --org ivf [--division middle] [--seeds 1,2,3] [--rounds 5] [--break 10] [--crown on|off] [--report docs/arena/ivf_rankings.md]
                                                         階級ごとの総当たり（両コーナー × 種、団体の決まりで最後まで。tvscout と同じ試合）で順位を決め直し、standings を書く
... title --org ivf --winner dmitri --loser marcus       試合の結果で王座とランキングを動かす
... video --tv on --org ivf --red-char joao --blue-char albert ...   計量を通して撮る（階級が違えば止まる。見出しに「ミドル級」「ヘビー級タイトルマッチ」、選手の比較に「階級・席」、台本の資料に計量と席）
```

`tvscout` も同じ計量を通す（撮影と同じ試合）。中継の札（`tools/tvshow/cards/*.json`）は `"org": "ivf"` で IVF の中継になる。

## 新人リーグ（2026-11-25、docs/plans/IVF_PROSPECTS_PLAN.md）

- 種から 240 人の新人（国の割合は BoxRec の現役プロの数を手がかりにした推定、名前・国は架空、違いは体格・教科書・教育の小さな揺らぎだけ）を作り、戦績の近い同士で 3R の興行を 6 回（597 試合）。負けが込むか試合で死ねば引退（148 人）。
- 階級ごとの上位 2 人（10 人）を正式な名簿（`roster/`、`org: "ivf"`）とランキングの末尾へ登録し、すぐ上の席へ 5R で挑戦させた（19 試合）。結果、ライト級アンドレ・ビショップ、ライトヘビー級シフォ・ファンワイク、クルーザー級プラサート・ラッタナクン（王座決定戦）、ヘビー級マウリシオ・ビジェガス（マーカスから奪取）が王者に。ミドル級はアルバートが防衛。
- 決まりは `games/MiniRing.Arena/Orgs/circuit/ivf.json`、新人・全試合の記録は `league/ivf/`（`bouts.jsonl` に 1 試合 1 行: コミット・版・種・両者のファイルとハッシュ・決まり・終わりのチェックサム）。プロフィールの戦績・経歴は記録から `circuit profiles` が書く（レギュラーはリーグ前の戦績 `baseline.json` に足す）。報告は `docs/arena/ivf_prospects.md`。

## 近道・残り

- IVF に出られる選手は今の名簿で 18 人（新人リーグの 10 人を足した）。全階級に王者がいる。
- 中継の試合の結果は、まだ自動で王座の記録へ入らない（`title` を手で回す）。
- 判定は 3 団体とも「与えたダメージの総量」。ラウンドごとの 10 点法の採点は入れていない（入れるなら団体の値で選べるようにする）。
- 武器・はめる物の選手を IVF に出すとき、はめる物はグローブに替わるが、教育はその選手の元のはめる物に合わせたまま（教科書がボクシングの選手だけなので差は小さい）。
