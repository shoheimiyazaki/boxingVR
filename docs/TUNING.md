# チューニングと実機確認

調整値は `games/MiniRing/FighterTuning.cs`（record。`new BoxingGame(tuning)` で差し替え）にまとめてあります。

- 体幹のゲインは加速度単位で持ち、実行時に質量と慣性を掛けて力積にします。
- 関節サーボの強さは Hz・減衰比・力上限で指定します。力上限は `TorqueScale`（質量倍率 × 縮尺）で縮小しています。
- Bepu の SpringSettings は換算質量に対して定義されます（Aigis anti-pattern A12）。そのため Unity 版の N/m の値は移植していません。

## ヘッドレスで確かめた範囲

テスト `FighterPhysicsTests` は、240Hz・地面のみの環境で次のことを確かめています。

- 3 秒立ち続けられる（直立度 0.9 以上）
- 2 秒で 0.5m 以上歩ける
- 180° 旋回できる
- ストレートが腕の長さの 15% 以内まで届き、構えの姿勢は 20% 以内に収まる
- 相手の胸を掴み、離せる
- ダウンしてから 5 秒以内に起き上がる
- CPU との 20 秒の試合が発散せず、ヒットが出る
- 左右それぞれの拳が体の正しい側に来る（右手系で右 = −X）

ヒット判定は「拳の近くで当たった・相手の前腕（ガード）ではない・衝突直前の拳の点速度のうち相手へ踏み込む成分」で行います。CPU は打つときだけ踏み込みます（構えたままでは頭に届かない間合いに立つため）。

GPU スナップショットでは、打ち合いのときに体がかなり前傾します。押し合いでホバーと直立の力が負けているためで、実機で気になる場合は `UprightKp` を上げてください。

## 実機（HMD）で最初に確認すること

1. **起動**
   - コンソール 1 行目の `[xr] runtime: Meta (...)` で、Meta のランタイムに固定されたか確かめる。
   - `xrGetSystem` で失敗する場合は、Quest が Link / Air Link でつながっていない（Meta Quest Link アプリでヘッドセットが「接続済み」になっているか見る）。
   - SteamVR（`--runtime steamvr`）は HMD 未接続だと xrCreateInstance 自体が失敗する（iTVision の知見）。
2. **向きと位置**
   - 起動直後に向いていた方向にリングが来るか。
   - 逆向きなら `XrSession.WorldFromXr` か `Recenter` の符号を見る。
3. **腕の写像**
   - 拳を前に突き出すと、人形が相手へ突き出すか。
   - 腕が届かない／伸び切るときは、A/X で再キャリブレーションする。
   - それでも合わなければ `PuppetMapping.ArmReachFromHeight` の係数を見直す。
   - 左右が逆なら `WorldFromXr` を疑う。
4. **手応え**
   - 遅い・重い → `HandKp` と `MaxHandForce` を上げる。
   - 震える → `HandKd` を上げる。
   - 腕がねじれる → `ArmServoHz` を上げる。
5. **パンチ**
   - ダメージが出ない → `PunchMath.SpeedThreshold` を下げる。
   - 毎回ダウンになる → `KnockdownDamage` を上げる、または `MaxHandForce` を下げる。
6. **掴み・投げ**
   - すぐ外れる → `GrabBreakForce` を上げる。
   - 投げが決まらない → `ThrowSpeed` を下げる、または `ThrowAssist` を上げる。
7. **性能**
   - フレームが落ちるときは `--scale 0.6` などに下げる。
   - 描画は目ごとに同期して送信する簡易方式（後述）なので、重ければ最初にここを改善する。

## 既知の制約・次の一手

- **VR の描画は簡易方式です。** 目ごとに「描画 → GPU コピー → 完了待ち」をしています。本格化するなら WindowedRenderer 側に XR 用のレンダーパスを作り、マルチビューやダブルバッファにします。
- デスクトップのミラーウィンドウ、効果音（Aigis.Audio は位置音響なし）、VR 内の文字表示は未実装です。
- 脚は見た目だけの正弦歩行で、体重は骨盤へのホバー力で支えています。踏み出して踏ん張る歩行は未実装です。
- 拳の向き（コントローラの回転）は使っていません。
- Quest 単体（スタンドアロン・Android）では動きません。PC で動かし、Link / Air Link / Virtual Desktop で映す構成です。
- SteamVR の同梱と PICO Connect の起動支援（iTVision の `Shared/*`）は必要になったら移植します。
