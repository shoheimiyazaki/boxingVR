# 実況の説明書（LLM 向け）

WVC の試合の動画に声の語り（実況・解説・心の声…）を付けるとき、**書き手の LLM が読む説明書**。語りを 4 つの層に分け、層の組み合わせで色々な型を作る。道具の使い方は [TV_BROADCAST.md](../TV_BROADCAST.md)、決まりの由来と記録は [TV_COMMENTARY_PDCA.md](../TV_COMMENTARY_PDCA.md)。

## 1. 層

| 層 | 決めること | ファイル |
|---|---|---|
| 0. 共通の決まり | どの型でも守ること（ラジオで分かる・言わない言葉・長さ・左右） | この README の §2 |
| 1. **型**（style） | 誰が声に出るか（席の数と役）、番組の組み立て、どの場面で誰が話すか、骨組みの下書きを使うか、点検のどの決まりを見るか | [styles/](styles/) |
| 2. **役**（role） | その席の仕事: 見てよい情報、話す時、文の型 | [roles/](roles/) |
| 3. **個性**（persona） | 人柄: 口ぐせ・語彙・熱の量・知識の得意・呼び方、声（OneCore の声と話し方） | [personas/](personas/) |

**優先順位**: 共通の決まり ＞ 型 ＞ 役 ＞ 個性。個性は役の仕事を変えない（熱血の実況でも主語は言う。皮肉屋の解説でも理由を言う）。

**組み合わせ**の書き方（札の `commentary`、またはユーザーの指示から作る）:

```json
"commentary": {
  "style": "tv-duo",
  "cast": [
    { "speaker": "announcer",   "role": "play-by-play", "persona": "tachibana" },
    { "speaker": "commentator", "role": "color",        "persona": "saeki" }
  ]
}
```

- `speaker`: 台本の中の話し手の id（声入れの配役のキー）。`announcer`・`commentator` は既定の声がある。ほかの id（`red_inner` など）は個性の声を `speakers` に書く。
- `role`・`persona`: `roles/<role>.md`・`personas/<persona>.md` の名前。
- 書いていなければ `tv-duo` ＋ 実況 `tachibana` ＋ 解説 `saeki`（今までの中継）。

用意してある型・役・個性:

| 型 | 席 | 一言 |
|---|---|---|
| [tv-duo](styles/tv-duo.md) | 実況 ＋ 解説 | テレビの格闘技中継（既定） |
| [solo-radio](styles/solo-radio.md) | 実況 1 人 | ラジオの一人実況。見えない人に全部を描く |
| [inner-voice](styles/inner-voice.md) | 赤の心の声 ＋ 青の心の声（片方だけでも） | 戦っている本人の頭の中。実況はいない |

| 役 | 一言 |
|---|---|
| [play-by-play](roles/play-by-play.md) | 実況: 見えることを即座に |
| [color](roles/color.md) | 解説: なぜ・この先 |
| [inner-voice](roles/inner-voice.md) | 本人の心の声: 自分の体と、見えている相手 |

| 個性 | 役 | 声 |
|---|---|---|
| [tachibana](personas/tachibana.md) | 実況 | Ichiro。熱いベテラン |
| [mizuki](personas/mizuki.md) | 実況 | Sayaka。落ち着いた正確な実況 |

## 2. 共通の決まり（どの型でも）

1. **ラジオで聞いても分かる**: 画面を見ていない人に、誰が・何を・どうなったかが伝わる。動き・体の状態の台詞には選手の名前（心の声は本人の声なので「俺」でよい。相手は名前か「あいつ」＋見た目の特徴）。
2. **言葉**: ゲームを知らない人が一言で分かる言葉。言わない: ダメージ＋数字・打撲・％・VGV・ボット・物理・セル・判定の内部の値。割合は「3割」「半分」。
3. **作中の世界**: 動画は WVC（Wonderful Voxing Council）の大会、競技は Voxing。ゲームの名前（VGV）は出さない。
4. **左右は本人から見た左右**（記録の「左上腕」は本人の左腕）。打つ手の「左」「右」も本人の手。
5. **1 台詞 28 字まで**（息継ぎ 1 回）。長い説明は分ける。
6. **事実は記録から**: `bN.digest.md`・`bN.events.json` に無いことを事実として言わない（推測は推測と分かる言い方で: 「〜でしょう」「〜かもしれない」）。記録に狙い（`technique`）が無い選手の作戦は、キャラクターファイルの流派・肩書きから「〜したい」「〜で行く」の意図として言う（起きたことにしない）。
   - 同じ部位が 2 度「飛んだ」（例: 27 秒と 80 秒に「右上腕が飛んだ」）は、最初に残った付け根が 2 度目に斬られたこと。下書きは「残りも飛んだ」と言う。新しく腕を失ったように言わない。
   - 名前は `hudName`（画面の名札と同じ呼び名。例: コンラート・ジン・ハンマー）。
7. **同じ台詞を 2 度書かない**。同じ型の文を 3 回続けない。
8. 試合の結果は変えない（勝敗・ダウンの数・決着の仕方は記録どおり）。

## 3. 情報の渡り方（誰が何を知っているか）

`bN.events.json` の出来事には `for`（実況 / 解説）と `who`（誰の出来事か）がある。役ごとに使ってよい情報:

| 役 | 使ってよい | 使わない |
|---|---|---|
| play-by-play | `for: 実況`（当たり・ダウン・カウント・立った・骨折と切断・ラウンド・リプレイ・決着） | 体の中の割合（解説に聞く） |
| color | すべて（`for: 解説` の体の中・狙い・疲れ・目・臓器を中心に） | — |
| inner-voice | 自分の `body`・`body_hurt`・`tired`・`eye`・`technique`（自分の狙い）、自分が打った・打たれた当たり、自分のダウン | **相手の体の中**（相手の臓器・割合）。相手については見えること（よろめく・腕がぶら下がる・息が上がる）だけ |

## 4. 書く手順

1. 資料を作る: `tvshow.ps1 -Stage digest`（`bN.digest.md`・`bN.draft.json`）。
2. 組み合わせを決め、型・役・個性のファイルを読む。
3. `bN.extras.json` を書く（形は §5）。型が骨組みを使うなら下書き（`bN.draft.json`）を読み、足りない所だけ足す。使わないなら `"useDraft": false` で全部書く。
4. 重ねて点検: `tvmerge`（入らなかった台詞が出る）→ `tvlint`（型ごとに見る決まりが変わる）。直してから `tvshow.ps1 -Stage dub`・`-Stage package`。
5. 動画を聞いて（書き起こしを読んで）確かめる: 画面なしで試合が追えるか。

## 5. 書く形（bN.extras.json）

```json
{
  "style": "inner-voice",
  "useDraft": false,
  "speakers": {
    "red_inner":  { "voice": ["Ichiro"], "rate": "-5%", "pitch": "-8%", "volume": "-6%", "excited": { "rate": "+15%", "pitch": "+0%", "volume": "+6%" } },
    "blue_inner": { "voice": ["Ichiro"], "rate": "+8%", "pitch": "+10%", "volume": "-6%" }
  },
  "drop": [],
  "lines": [
    { "at": 9.4, "speaker": "red_inner", "text": "よし、ひざに入った。", "excited": false }
  ]
}
```

- `style`: 型の名前（点検が見る決まりを選ぶ）。`speakers`: 個性の声（`announcer`・`commentator` の既定を変えるときも書く）。
- `useDraft`（既定 true）: 骨組みの下書きを使うか。`drop`: 下書きから消す台詞。
- `lines[].at`: 言ってほしい時刻 [s]。`tvmerge` が空きへ入れる。
  - 台詞は**話す長さの分だけ時間を占める**。見積もりは (字 × 0.16 秒 ＋ 区切り「。、！？…」× 0.48 秒) ÷ (1 ＋ 話し手の `rate`)、置き場所はその 1.15 倍で取る（実測で 1 台詞が 2〜3 割長いことがあるため）。例: 実況（+15%）の 20 字・区切り 2 つで約 4 秒、心の声（−12%）の 14 字・区切り 2 つで約 4.4 秒。次の台詞まで 0.15 秒。重ならないように置くので、長い台詞の直後の台詞は押し出される。
  - ずらしてよい範囲: `excited: true` の台詞は頼んだ時刻から後ろへ 1 秒まで（前へはずらさない）。問い（「〇〇さん、…？」）と直後の答えの組は前 2 秒〜後ろ 6 秒。ほかは前 1.5 秒〜後ろ 2.5 秒。範囲に入らない台詞は落ち、`tvmerge` が「入らなかった台詞」と表示する。
  - 込み合う場面（打ち合い・ダウン〜カウント・リプレイの入り）は 1 秒に 1 台詞も入らない。短い台詞（2〜8 字）を間を空けて置く。
- `lines[].excited`: 盛り上がる瞬間の声（速く・高く・大きく）。実況は打ち合い・ダウン・決着のコール。解説は決着・逆転だけ。心の声は打った・打たれた瞬間と、自分のダウンからの「立て」・勝った瞬間。考え・振り返り・作戦は false。
- 声は Windows の OneCore の日本語: Ichiro（男性）・Ayumi・Haruka・Sayaka（女性）。話し方は `rate`・`pitch`・`volume`（SSML の prosody。必ず符号つきの `+10%`・`-8%` の形。符号が無いと別の意味になる）。話し手の id は英数字と `_`・`-` だけ、大文字と小文字は区別する。
- 台詞の長さ: 区切り（。、……）1 つで約 0.5 秒の間が入り、遅い話し方（`rate` がマイナス）はさらに長い。心の声の目安は 4〜5 秒に 1 台詞。`tvmerge` が「入らなかった台詞」を出したら、大事な台詞（ダウン・切断・決着）が入るよう、周りの小さな台詞を削るか短くする。

## 6. 層を足す

- **型**: `styles/<名前>.md` に、席・番組の組み立て・場面ごとの話し手・骨組みの使い方・点検で見ない決まり（`TvLint.SkippedRules` にも足す）を書く。
- **役**: `roles/<名前>.md` に、仕事・見てよい情報（§3 の表にも足す）・話す時・文の型・悪い例を書く。
- **個性**: `personas/<名前>.md` に、経歴・人柄・口ぐせ・語彙・呼び方・声（`speakers` に書く値）・例文を書く。ほかの個性と口ぐせが重ならないように。
