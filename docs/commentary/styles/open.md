# 型: open（役だけ与えて、話す中身は自由）

テレビ中継の 2 席（実況 `announcer` 立花・解説 `commentator` 佐伯）。2026-11-17 から LLM の書き手の既定。

- 渡すもの: 役の名前（実況 = 試合を伝える、解説 = 試合を見て話す）と資料（`bN.events.json`・`bN.digest.md`・`bN.draft.json`）だけ。役（`roles/`）・個性（`personas/`）のファイル、話題の例、番組の組み立て、掛け合いの決まりは渡さない（誘導すると毎回同じ話題になって単調だった）。
- 守ること: 記録と違えない・作中の言葉（README §2 の 2・3）・1 台詞 60 字・実況の入りのコール（第Nラウンド・ダウン・決着・リプレイ）。
- 骨組み: `useDraft: false`（全部の台詞を書く）。
- 点検: 見ない決まり = 掛け合い・カウント中・呼びかけ（と、どの型でも見ない主語・型）。
- プロンプト: `tools/tvshow/prompts/tv-duo-open.md`。
