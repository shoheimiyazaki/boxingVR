# 型: inner-voice（戦っている本人の心の声）

実況も解説もいない。赤と青の選手の頭の中の声だけで試合を追う。片方だけ（例: 赤の心の声だけ）でもよい。

## 席

| speaker | 役 | 個性 |
|---|---|---|
| `red_inner` | inner-voice（赤の選手） | fighter（赤のキャラクターファイルから作る） |
| `blue_inner` | inner-voice（青の選手） | fighter（青のキャラクターファイルから作る） |

声は 2 人で聞き分けられるようにする（同じ声なら高さ・速さを大きく変える。[personas/fighter.md](../personas/fighter.md)）。

## 骨組み

`useDraft: false`（実況の下書きは使わない）。全部の台詞を書く。

## 組み立て

| 場面 | 書くこと |
|---|---|
| 冒頭（タイトル・紹介の間） | それぞれの心構え 1〜2 台詞（相手をどう見ているか、自分の作戦） |
| 打ち合い | 自分が打った・打たれた瞬間の短い声（「入った」「くそ、効いた」）。相手の声と交互に、かぶせない |
| 自分がダウン | 倒れた本人: 何が起きたか分からない・音が遠い・立てと言い聞かせる。相手: 今のが入った・立つな |
| カウント | 倒れた本人がレフェリーの数を拾う。数は 1 秒ちょっとごとに進むので全部は言えない: 3〜4 個だけ（例: スリー、ファイブ、セブン、ナイン）、カタカナの英語の数（ワン〜ナイン）で、間に「立て」。立った選手は立った後に一言。相手はカウント中は 1 台詞まで（「立つな」）。数を言うのはここだけ |
| 骨折・切断 | 本人: 痛みより先に「腕が上がらない」のような体の感じ。相手: 見えたこと |
| 休み（リプレイの間も） | 今のラウンドの振り返りと次の作戦。疲れ・痛みの自覚。リプレイの映像は見ていないが、映っている出来事を本人は体験しているので、その時の感覚として振り返ってよい（「あの一太刀、見えなかった」）。カメラの見え方（スロー・角度）は言わない |
| 決着 | K.O. で負けた方は決着の直前に意識が遠のく声（「……暗い」）まで。決着の後・勝敗の画面では黙る（意識が無い）。勝った方は決着の後に 1〜2 台詞、勝敗の画面で 1 台詞まで。判定なら両者が一言ずつ（勝った実感・悔しさ） |

## ラジオで分かるために

- 声が 2 つあることが最初に分かるよう、冒頭で各自が名乗る形にしてよい（「俺はハンマー。」は不自然なら「今日の相手はアキラ、空手家だ。」のように相手の名前と自分の立場で）。
- 相手は名前か見た目の特徴で呼ぶ（「あいつ」だけを続けない）。
- 何が起きたかは本人の感覚で言うが、聞き手に分かる言葉で（「左のボディ、レバーにもらった」）。

## 点検

見ない決まり: 掛け合い・カウント中・コール・言い直し・リプレイ・主語・呼びかけ・型。見るのは長さ・言わない言葉・ずれ。
