# 個性: fighter（選手本人の心の声）— 型紙

選手の心の声（role: inner-voice）の個性は、その選手の**キャラクターファイル**（`games/MiniRing/Characters/roster/<id>.json`）から作る。新しい人物を作らず、ファイルの値と試合の記録から読み取る。

## ファイルから読むもの

| 値 | 使い方 |
|---|---|
| `name`・`hudName` | 自分のことは「俺」「私」、相手からは `hudName` で呼ばれる |
| `origin`・`tagline` | 背景（「リヒテナウアー流の剣士」→ 剣の型の言葉を使う。母国の言葉を 1 試合 1〜2 回混ぜてよい: 「Verdammt…」） |
| `textbook`・`body` の武器 | 何で戦うか（刀・ロングソード・こんぼう・素手・グローブ）。技の言葉はその流派の普通の言葉 |
| 記録の `technique`（自分の狙い） | 考えていること（「ジャブで距離を測る」「蹴りで足を止める」） |

## 気質（ファイルに無いので、ここで決めて extras の先頭のメモに残す）

キャラクターの `tagline` と戦い方（記録の狙い・前に出るか下がるか）から、次の中から 1 つ選ぶ。2 人の気質は違うものにする。

| 気質 | 心の声の特徴 |
|---|---|
| 冷静 | 観察と計算。短い文。痛みは事実として言う（「右腕が折れた。左で行く」） |
| 激情 | 怒り・意地。言い切りと罵り（汚い言葉は使わない: 「くそっ」まで） |
| 誇り | 流派・名誉を口にする。負けそうでも型を崩さない（「剣士は下がらない」） |
| 臆病を隠す | 怖さと強がりが交互（「大丈夫だ、効いてない……効いてない」） |

## 声（`speakers.red_inner` / `speakers.blue_inner`）

使える男性の声は Ichiro だけなので、2 人を高さと速さで分ける。下の表は 1 人ずつの出発点で、**2 人の高さ（`pitch`）の差が 15 ポイント以上になるよう、高い方の気質の人をさらに上げる**（例: 冷静 −10% と 誇り −16% の組なら、冷静の人を +6% に）。この決まりは表の値より優先。心の声は実況より小さく（`volume` を下げる）。女性の選手は Haruka か Sayaka（男性と組むなら高さはそのままでよい）。遅い話し方（`rate` がマイナス）は 1 字 0.25〜0.3 秒かかるので台詞は 15 字まで。

| 気質 | 例 |
|---|---|
| 冷静 | `{ "voice": ["Ichiro"], "rate": "-8%", "pitch": "-10%", "volume": "-6%" }` |
| 激情 | `{ "voice": ["Ichiro"], "rate": "+10%", "pitch": "+8%", "volume": "-4%", "excited": { "rate": "+25%", "pitch": "+14%", "volume": "+6%" } }` |
| 誇り | `{ "voice": ["Ichiro"], "rate": "-12%", "pitch": "-16%", "volume": "-6%" }` |
| 臆病を隠す | `{ "voice": ["Ichiro"], "rate": "+6%", "pitch": "+14%", "volume": "-8%" }` |

## 例（コンラート、誇り、ロングソード）

- 「刀か。間合いは俺の方が長い。」
- 「……右腕が、無い。まだ左がある。」
- 「剣士は下がらない。前へ。」
