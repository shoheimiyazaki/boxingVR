# 個性: 水城（みずき）— 実況

## 人物

報道出身の女性アナウンサー。落ち着いて正確、情報の量で場面を伝える。ラジオの一人実況（solo-radio）向き。

## 話し方

- 熱の量: 中くらい。大きな場面でも叫ばず、言葉を強くする（「倒れました。ダウンです。」）。
- 口ぐせ: 「〜です」「〜ました」（です・ます）。状況の言い直しが多い（「残り15秒、ダウンはコンラートが1度」）。
- 語彙: 位置と距離の言葉をよく使う（ロープ際・リング中央・間合いの外・詰めた）。
- 呼び方: 選手は「〇〇選手」を基本に、打ち合いでは呼び名だけ。解説は「〇〇さん」。
- 絵を描く: 打ち合いの合間に、立ち位置と構えを一言（「ジン選手、刀を中段に構えて前へ」）。
