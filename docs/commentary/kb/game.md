# Voxing というスポーツ（競技の基本）

Voxing は、ボクシングを土台に、素手・グローブ・武器・蹴り・古武道まで持ち込める異種格闘技のスポーツ。主催は WVC（Wonderful Voxing Council）。実況・解説は「競技の名前は Voxing、団体は WVC」の前提で話す。

## 1. 体は小さなブロックでできている

選手の体は、皮膚・筋肉・骨・内臓（脳・心臓・肺・肝臓・腸）・目・髪・服といった**小さなブロック**の集まり。だから打撃は「点数」でなく、**実際に体を削る**。

- 外側は皮膚、その下が筋肉（赤）、中心に骨（白）、胴の奥に内臓。削れると下の色が見える。
- 削れたブロックは破片になって飛び、血も散る。傷のまわりの皮膚は赤く染まる。
- 体の大きさ（身長・腕と脚の長さ・筋肉の太さ）は選手ごとに違い、**見た目のとおりに強さが決まる**。大きく太い体は力が強く、筋肉が薄い体は打たれ弱い。
- 見えない強さの倍率は無い。「強そう」なら本当に強い、が基本。

## 2. 試合の形式

| 項目 | 内容 |
|---|---|
| ラウンド | 1ラウンド30秒。大会によるが、テレビ中継の標準は3ラウンド |
| ラウンド間の休み | 約20〜25秒。浅い傷は少し治る（大会の決まり）。折れた骨・失った手足は戻らない |
| 勝ち方 | K.O.、または最終ラウンド終了後の判定 |
| 判定 | 与えたダメージの多い方の判定勝ち |
| 記録の表示 | 画面の左右に、与えた量とクリーンヒット（ガード以外）の数 |

### ダウンとカウント

- 腰・上体・手がマットに着いたら、または脚で立てなくなったら**ダウン**。
- 中腰でまだ立っていても、意識が深く落ちたまま数秒たつとダウンになる。その間、相手は打ち続けてよい。
- ダウンしたらカウントが始まり、**10カウントで立てなければ K.O.**。倒れたまま動かなくても K.O.。
- 立ち直った選手は、構えを取り直して試合に戻る。

### レフェリーのいないルール

Voxing の大会には**レフェリーがいない**。止める人がいないので、倒れた相手への打撃も立っている相手と同じように当たり、同じように効く。倒れた相手に打ち下ろす攻めも普通に見られる。実況は「倒れた相手にも打撃が入ります」と事実として伝えればよく、反則とは言わない。

## 3. 体の壊れ方

| 壊れ方 | 起きること |
|---|---|
| 削れる・へこむ | 肉が減るほどその部位の力が落ちる。腕の筋肉が減れば腕の力が落ちる。グローブでも皮膚が潰れて赤くなる |
| 骨折 | 骨が曲がりに負けて折れる。折れた腕・脚はぶらぶらになり、折れた先は思うように動かない |
| 切断 | 骨が断たれて、そこから先が体から離れて落ちる。腕も脚も起こりうる（刃物・重い一撃） |
| 内臓 | 心臓・肺・肝臓・腸などが半分ほど壊れると命に関わる（死ぬ）。肝臓や腹への打撃で足が止まることも |
| 首 | 首の骨が折れると頭がぶら下がる。首が断たれて頭が離れたら、その場で決着（命を落とす） |
| 脊髄 | 背骨の中の神経が削られると、そこから先の筋肉に力が入らなくなる |

### 脚を失っても戦い続ける

脚の骨が折れたり切断されたりしても、**残った脚の長さの高さで立って戦い続ける**。すねを失えば膝立ち、付け根近くなら腰を落として座った形になる。動きは遅くなり、這うように進む。蹴りは使えなくなる。ここで体勢が低くなった分、相手は頭を狙って打ちやすくなる。

### 腕を失った場合

腕が折れたり切れたりした選手は、肩に近い筋肉の分しか力が出ない。落ちた手は握りが次第にほどける。切断されても試合は続き、逆に出血と欠けた体の弱りで勝負が傾くことが多い。

## 4. 意識とダウン

- 意識は「脳の働き」と「頭を揺らされた量」で決まる。
- **頭は首の上でねじられる。** 回転の中心から外れた点（あご・こめかみ）を速く振り抜かれると、頭が首の上で急に回り、意識が飛ぶ。これが K.O. の本質。速いほど、外した点ほど効く。
- 意識が下がるにつれ、体の張りが抜け、脚が言うことをきかなくなり、腰が落ちる。段階の切り替えではなく、滑らかにつながっている。
- 脳そのものが削られても意識は落ちる。
- 解説で使える見え方:「意識はあるのに足が言うことをきかない」（ボディ）、「頭を揺らされて意識が飛んでいる」（顔への一撃）、「足がもつれただけ」（軽いダウン）。

## 5. スタミナと疲れ

- 腕を振る・踏み込む・体のバネを使う、すべてに筋肉のエネルギーを使う。構えて立つだけ、足で回るだけなら減らない。**全力の連打だけが、蓄えをぐんぐん使う。**
- 蓄えが減ると、まず拳を運ぶ力が落ち、拳が遅れて重さも落ちる。
- 休めば戻る。打ち合っていないときは減らない。休む選手も足は使い続け、手数は少し残す。
- 試合を通して持久力も削られる。**ラウンドの休みでは戻らない**ので、後のラウンドほど疲れやすい。
- 筋肉の大きな選手は蓄えも大きい。

| 疲れの見た目の手がかり | 意味 |
|---|---|
| 息遣いが荒い・肩で息をする | 蓄えが減っている |
| ガードが下がる・手数が減る | 拳を運ぶ力が落ちた |
| 足が止まる・ふらつく | 体全体の疲れ、またはボディのダメージ |

## 6. 力の出どころ（体で打つ）

パンチの重さは「どれだけ体の質量を拳に乗せられたか」で決まる。腕だけで打つ（手打ち）と軽く、体の軸に沿って踏み込んで打つと重い。

- **体重移動**: 踏み込みながら打つと、拳は速く、体のぶん勢いが前へ移る。打った後、体は少し遅くなる。
- **体のバネ（溜め）**: 逆へ引く予備動作で、脚の沈みや胴のひねりにエネルギーを溜め、打ち出しで拳へ移す。溜めが大きいほど一撃が強い。ただし溜めは相手に読まれやすい。
- **関節の健全度**: 肩・肘・脚が傷んでいると、同じ動きでも手打ちになって軽くなる。
- 打つ位置で効き方が違う:

| 狙い | 効くこと |
|---|---|
| あご・こめかみ | 頭が回って意識が飛ぶ（K.O. の筋道） |
| 肝臓（右の脇腹） | 内臓に効いて足が止まる |
| みぞおち・ボディ | 息が詰まる、意識はあるのに足が動かない |
| 肩・肘 | 腕の力を削ぐ |
| 膝・脚 | 動きを止める、骨折の危険 |
| 首 | 重い一撃では骨に負担、折れれば致命的 |

- 刃物は面でなく**線・点**に力を集めるので、少ない力でも切れる。グローブの大きな面は広く押して、打撲で効かせる。柔らかい方が壊れ、強さが近ければ両方が壊れる。

## 8. 言葉づかいの注意

- 実況は見えること（誰の何がどこに入った・ダウン・カウント・ラウンド・時間）を短く、解説はなぜそうなったか・次の見どころを話す。
- 数字は「ラウンドと時間と、体の何割が失われたか」だけ。「3割」「半分」と言う。点数や細かい数値は言わない。
- 作中の世界の言葉で話す。試合の裏側（仕組み・プログラム的な言葉）には触れない。
