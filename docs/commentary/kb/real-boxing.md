# 実際のボクシングの知識（実況・解説の引き出し）

Voxing の土台はボクシング。実況・解説は、実際のボクシングの言葉を作中の試合に重ねて使ってよい。ここは一般的な知識を自分の言葉でまとめたもの。

## 1. 歴史（ごく短く）

- 拳で闘う競技は古代ギリシャの時代からある。近代のボクシングは18〜19世紀のイギリスで、素手の拳闘（ベアナックル）として広まった。
- 19世紀後半、グローブの使用、ラウンド制、10カウント、体重別の階級などの決まりが整った（クインズベリー侯爵ルールとして知られる）。
- 20世紀に入り、プロの世界王者、体重別の階級（ヘビー級からミニマム級まで）、各団体の王座が整備された。
- 日本でも大正〜昭和期に広まり、世界王者を多く輩出してきた。
- 素手の時代は拳が壊れやすかったため、顔より体を狙う、短い拳を使うなどの工夫があった。グローブになってから顔への連打が増えた。

## 2. 構え（スタンス）

| 構え | 特徴 |
|---|---|
| オーソドックス | 左足と左拳が前。右の拳が強い（右利きの標準） |
| サウスポー | 右足と右拳が前。オーソドックスの鏡 |

- 肘を締め、あごを引き、両拳を顔の前に置く。体をやや斜めにして的を小さくする。
- 足は肩幅より少し広く、前足の母指球に乗って軽く弾む。
- オーソドックス同士・サウスポー同士なら向かい合い、組み合わせが違うと前足がぶつかる位置関係になり、外側へ回る争いが起きる。

## 3. パンチの種類

| パンチ | 手 | 内容 |
|---|---|---|
| ジャブ | 前の手 | 最短距離でまっすぐ。距離を測り、相手の攻めを止め、つなぎに使う。威力は軽いが速い |
| ストレート（クロス） | 後ろの手 | 腰と肩を回してまっすぐ打つ強打。ジャブの後の「ワン・ツー」の「ツー」 |
| フック | どちらも | 肘を曲げ、横から弧を描いて打つ。あごやこめかみ、脇腹を狙う。頭を揺らしやすい |
| アッパーカット | どちらも | 下から突き上げる。あごやみぞおちを狙う。相手が前傾したとき、近い距離で |
| ボディブロー | どちらも | 腹・脇腹・みぞおちへ。肝臓（右の脇腹）が急所の代表 |
| オーバーハンド | 後ろの手 | 上から弧を描いて落とす。大振りの強打 |

### 体を狙う

- **肝臓（リバー）**: 右の脇腹の肋骨の下。効くと激痛で脚が止まり、立っていられなくなることがある。「レバーブロー」。
- **みぞおち（ソーラープレクサス）**: 胸の中央下。息が詰まる。
- ボディは効くのに時間がかかるが、効けば相手の足が止まり、頭が下がる。そこで顔を打つ。

## 4. 防御

| 技術 | 内容 |
|---|---|
| ブロック（ガード） | グローブと腕で受ける。高いガードは顔、肘を締めて脇腹を守る |
| パリー | 相手の拳を手のひらで払って外側へそらす |
| スリップ | 拳の来る線から頭を紙一重で外す。ストレートに対して |
| ダッキング | 腰を落として拳の下をくぐる。フックに対して |
| ウィービング | 腰から前へ折り、体を横に振って、フックの下をくぐる。ダッキングより大きく動く |
| スウェー | 上体を後ろにのけぞらせて拳を外す。足は動かさない |
| クリンチ | 相手に組み付いて、打たせない。疲れたときの休憩にも使う |
| ステップバック・サークリング | 足で距離を取る、横へ回る |

守りの技の見分けは、**どこへ体が動くか**。後ろ（スウェー）、横（スリップ）、下（ダッキング）、腰から前に折って下（ウィービング）。

## 5. フットワークと距離

- 距離は3つに分かれる。**長い距離**（ジャブが届く）、**中間距離**（ストレートが届く）、**近距離**（フック・アッパーが届く）。
- 足が良い選手は、相手の拳の届かない所に立ち、こちらだけ当てる。
- 前進する選手は、相手を下がらせ、ロープ際へ追い詰める。ロープを背負うと後ろへ逃げられず、サークリングも制限される。
- ピボット（軸足で回る）、ステップイン（ジャブとともに踏み込む）、サイドステップなどが基本。
- 疲れると足が止まる。足が止まるのは、攻めでも守りでも最初の疲れのサイン。

## 6. コンビネーションとカウンター

- **ワン・ツー**: ジャブ（1）→ストレート（2）。もっとも基本の連打。
- **ワン・ツー・フック**（左右左）、**ジャブ・ボディ・フック**など、上下に打ち分ける連打が効く。
- **フェイント**: 打つふりで相手の守りを動かし、空いた所へ打つ。
- **カウンター**: 相手が打ってくる瞬間に、守りながら返す。相手は攻めに全力を使っているので、いちばん効く。
  - クロスカウンターは、相手の拳の外側から自分の拳を交差させて当てる。
  - 返しの名手は、スリップやウィービングで外した直後に一撃を入れる。

## 7. 戦い方のタイプ

| タイプ | 特徴 | 弱点・相性 |
|---|---|---|
| アウトボクサー | ジャブと足で距離を保ち、安全に点を取る | 近距離に入られると弱い |
| スウォーマー（インファイター） | 前へ出続け、近距離で手数を出す。小柄で打たれ強い | 長い腕に入る前に打たれる |
| スラッガー（ハードパンチャー） | 一発の強打で倒す。重量級に多い | 足が遅い、スタミナが切れやすい |
| カウンターパンチャー | 相手の攻めを待ち、返す | 受け身で、手数が減りがち |
| ボクサーファイター | 距離を取り組み立てる、バランス型 | ― |
| 王者型（オールラウンダー） | 距離、手数、強打の全部をこなす | ― |

## 8. ルールと採点

- プロは通常3分×最大12ラウンド（ラウンドの間は1分休み）。アマチュアは3分×3ラウンド。
- 採点は**ラウンドごと**に10点法: 優勢な方に10点、劣勢に9点以下（ダウンがあれば1回につき1点引く）。
- 評価は、クリーンヒット、攻勢（手数と主導権）、ディフェンス、リング支配など。
- 判定は3人のジャッジ。全員一致・多数決・引き分け。
- 反則: ローブロー、後頭部への打撃、ホールドして打つ、相手が倒れたときの追撃など。**Voxing にはこのルールの一部（倒れた相手への打撃）が無い。**
- ノックダウンの後は、レフェリーが10まで数える。選手は自分で立ち、ファイティングポーズを取れなければ K.O.。立てても足元が危なければレフェリーが止める（TKO）。

## 9. ノックアウトの生理

- 頭を横から打たれると、頭が首の上で**回転**する。急に回転が始まると、脳が頭蓋の中で揺れ、脳幹の働きが一時的に落ちて意識が飛ぶ。
- 回転の中心（首の上）から外れた点、つまり**あごの先・こめかみ**を打たれると、てこの作用で回転が大きくなる。だから急所と言われる。
- 真正面から顔の真ん中を打たれても、頭が後ろへ下がるだけで回転しにくく、意識は飛びにくい。
- 打たれると分かっていた（身構えていた）ときは、首の筋肉が頭を固定して耐えやすい。**見えないパンチ**ほど効く、と言われる。
- **脚が効く**: 頭を揺らされると、意識はあるのに足が言うことをきかなくなる（いわゆる「ガクッとくる」）。バランスを司る器官が乱れる。
- ボディの一撃も、息が止まる・肝臓の痛みで動けなくなるという形で倒す。
- 倒れた後の回復には時間がかかる。立ち上がっても、そのまま連打されて再びダウンしやすい。

## 10. コンディショニング

- ロードワーク（走り込み）、縄跳び、シャドー、サンドバッグ、ミット打ち、スパーリング、体幹・脚の強化で、スタミナと打たれ強さを作る。
- **減量**: 階級の上限に合わせて体重を落とす。極端な減量は試合でのスタミナと打たれ強さを損なう。
- 試合ではラウンドが進むほど、手が下がる・足が止まる・息が荒くなる。その変化が見えたら、解説は「疲れが出てきた」と言ってよい。
- 後半のラウンドで勝負が動くのは、持久力の差が出るから。
