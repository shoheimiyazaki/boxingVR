## 1. 空手

- 沖縄で発達した、突き・蹴り・受けの武術。琉球の「手（ティー）」と中国武術の影響を受けて育った。首里・那覇・泊の三つの流れがあり、首里手（シュリテ）は直線的で素早い動きが特徴。
- 本土へ伝わって近代空手になり、流派がいくつにも分かれた。型（カタ）を繰り返して体に染み込ませる。
- **突き**: 腰の回転と踏み込みを一点に集める。「一撃必殺」の考え方。
- **手の形**（使い分けが空手らしい）:

| 手の形 | 内容 |
|---|---|
| 正拳（せいけん） | 握った拳の人さし指・中指の拳頭で打つ、基本の突き |
| 手刀（しゅとう） | 手の小指側の縁で打つ。首や鎖骨、受けにも使う |
| 貫手（ぬきて） | 指をそろえて伸ばし、指先で突く。目や喉などの急所 |
| 掌底（しょうてい） | 手のひらの付け根で打つ。顔や顎、拳を痛めにくい |

- **受け**: 上げ受け・下段払い・内受け・外受けなど。単に止めるのではなく、払って相手の姿勢を崩して反撃につなげる。
- **パリー（払い）**: 相手の拳の側面を払って軌道を外す。ボクシングのパリーと同じ考えだが、空手では腕の長さや角度の使い分けが多い。
- 試合では踏み込む前に腰を沈める（体のバネを溜める）のが、突きの合図になる。
- 弱点になりやすいのは、長いリーチの相手、蹴りや武器といった慣れない間合い。

## 2. テコンドー

- 朝鮮半島発祥の格闘技。足技が中心で、高い蹴り・跳び蹴り・回転する蹴りが特徴。
- 試合では軽やかに跳ねる、素早く足を出す。長い脚を生かして相手の拳の外側から蹴る。

| 蹴り | 内容 |
|---|---|
| 回し蹴り（ドルリョチャギ） | 膝を横に張り出して畳み、足の甲やすねで横から振り抜く。いちばんよく使う |
| 横蹴り（ヨプチャギ） | 体を横に向け、足の裏・刃で真っすぐ押し出す。距離を作る蹴り |
| 後ろ蹴り（ティットチャギ） | 背を向けて体を回し、後ろへ踵で突く。意表を突くが回転が大きく読まれることも |
| かかと落とし（ネリョチャギ） | 脚を高く上げ、真上から踵を振り下ろす。頭や肩を狙う |
| 前蹴り | 膝を上げ、足の裏で前へ押す |

- 蹴りは脚の大きな筋肉を使うので重いが、足は拳より遅く、軸足一本で立つので、**足を掴まれる・低く潜られる**と崩れやすい。
- 筋肉が薄く細身な選手が多く、打たれ強さに欠けることがある。

## 3. 琉球古武道（こぶどう）

沖縄の農具や生活の道具から発達した武器術の総称。

| 武器 | 内容 |
|---|---|
| 棒（ぼう）、六尺棒 | 長さ約6尺（約180cm）の棒。両手で持ち、両端で突く・打つ・払う。基本の武器 |
| トンファー | 握りの柄から短い棒が前腕に沿って伸びる、1組2本。突く・回して打つ・前腕に沿わせて受ける。もとは石臼の取っ手とも言われる |
| サイ・ヌンチャク等 | ほかの代表的な武器（Voxing の選手には現時点で使い手はいない） |

- 棒術の動きは大きな円を描いてつなぐ。突き（つき）・打ち下ろし・横打ち・足払い（あしばらい）・返し（棒を回して逆の端で打つ）。
- トンファーは、前腕の外側の棒が盾になり、そこから手首を返して打つ。
- 空手と古武道は同じ道場で学ぶことが多く、沖縄の選手どうしは稽古仲間や幼なじみのことがある（各選手のファイルを確認）。

## 4. 日本剣術・居合

- **剣術（けんじゅつ）**: 刀を使う武術。構え・間合い・斬り・突き・受け流しの体系。流派が数多くある。
- **居合（いあい）**: 鞘に納めた刀を、抜くと同時に斬る「抜き打ち」の技。座った姿勢や立った姿勢から、一瞬で勝負をつける。刀の抜き方、納め方、残心（斬った後の心の構え）が大切にされる。
- 日本刀は鍛えた鉄の片刃で、反りがある。両手で握る。
- **技の名前**:

| 技 | 内容 |
|---|---|
| 袈裟斬り | 肩から斜めに斬り下ろす |
| 逆袈裟 | 下から斜めに斬り上げる |
| 突き | 切っ先でまっすぐ突く |
| 胴（抜き胴） | すれ違いながら脇腹を払い斬る |
| 面 | 頭を打ち斬る |

- 剣道の竹刀とは違い、刃で斬る道具なので、間合いの見極め、踏み込み、受け流しが何より大事。
- 間合いが近すぎると刀は使いにくい。拳の距離になったらグローブの拳で戦う選手もいる。

## 5. ヨーロッパ歴史剣術（HEMA）と長剣

- **HEMA**（Historical European Martial Arts）: 中世・ルネサンス期のヨーロッパの武術を、残された教本から再現して学ぶ活動。
- **リヒテナウアー流**: 14世紀のドイツの剣術家ヨハネス・リヒテナウアーの流派。弟子たちが残した注釈書が基になっている。ニュルンベルクなど南ドイツの都市に、歴史剣術の道場がある。
- **長剣（ロングソード）**: 両手で持つ直刃の両刃の剣。長い刃は突きにも斬りにも使え、鍔や柄頭で打つこともできる。
- **構え（Vom Tag）**: 「屋根から」の意味で、剣を肩の上に構える基本の構え。
- **主な技**:

| 技 | 内容 |
|---|---|
| オーバーハウ（Oberhau） | 上から斜めに斬り下ろす |
| ツォルンハウ（Zornhau） | 「怒りの斬り」。強い斜めの斬りで、受けと攻めを兼ねる |
| ツヴェルヒハウ（Zwerchhau） | 横から水平に打つ、相手の斬りを受けて返す技 |
| ウンターハウ（Unterhau） | 下から斬り上げる |
| シュティヒ（Stich） | 突き |

- 剣の長さで間合いを支配し、近づかれたら組む・投げる・拳で殴る技もある（レスリングの原型）。

## 6. 剣と盾

- 古代から中世まで広く使われた組み合わせ。盾で相手の攻撃を受けて逸らし、空いた所へ剣を差し込む。
- 歴史再現（リエナクトメント）や歴史武術の団体が、盾術を復元して教えている。
- 守りが厚いので、自分から踏み込まず、相手の打ち終わりを待って返す戦い方が向く。盾が体を隠すので、相手は狙う所が少なくなる。
- 弱点は、盾が重くて動きが遅れること、盾を持つ手の自由が少ないこと。

## 7. そのほか（roster に出てくるもの）

- **フェンシング**: 細身の剣で突く競技。間合い（ランジの距離）の感覚が鋭く、遠くから突いて下がる動きに生きる。ガストンのトレーナーの背景。
- **カタール**: インドの短剣。握りが横木で、拳が刃になる。ラージプートは北西インドの戦士の家系。レスリング（インドの伝統的なクシュティ）の素地を持つ人もいる。
- **ベアナックル拳闘**: 素手で殴り合う古い拳闘。グローブがないので、拳の当て方に注意が要り、顔より体を打つことも多い。
- **棍棒・スティック**: アイルランドのシレイラ（棒）など、棒で戦う民族的な伝統がある。重い木の棒を振り回して強打で倒す。
- **路上の喧嘩殺法**: 体系はないが、近距離で頭から潜り込み、被弾を気にせず連打する荒々しい戦い方。

## 8. 他の流派がボクシングと違うところ（解説用）

- 武器術は、**間合いの長さ**が命。武器が長ければ、近づかれる前に当てられる。逆に近距離ではボクシングの拳が速い。
- 蹴りは遠くから届くが、軸足一本になるので、崩されやすい。
- 受けの考え方も違う。ボクシングは受けて止める・避ける。空手や古武道は払って崩し、そのまま反撃へつなぐ。
- 刃物は、当たれば深く入るので、守りの組み立てが変わる。「触れさせない」が基本になる。
