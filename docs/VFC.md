# VFC の試合の芯（ルールの値と六角形の檻）

2026-11-18、`docs/plans/VFC_PLAN.md` の段 A。体・物理・材料・ボットの判断は変えず、**ルールの値と場の形だけ**を足した（同日の指示書 F で、休みの再生と武器の支給を足した: 下の「再生」。こちらは `PhysicsVersion` 47）。既定の道（四角いリング・今のルール・`PhysicsVersion`）は 1 ビットも変わらない（檻は既定の道を変えない追加なので `PhysicsVersion` は上げない）。

## ルールの値（`MatchRules`）

| 値 | 既定（WVC） | `MatchRules.Vfc` | 意味 |
|---|---|---|---|
| `CountsDowns` | true | false | false なら「動かないままの K.O.」と「10 カウント K.O.」で決着しない。死・リングアウトは今のまま。倒れた状態（`DownTime` など）は体の状態として残り、レフェリーの一呼吸（`_resumeHold`）も起きない。10 カウントの HUD（`DownCountHud`）も出さない |
| `JudgesDecision` | true | false | false なら最終ラウンドの終わりは判定せず `"DRAW — BOTH SURVIVE"`（勝ち数は増やさない） |
| `RegenVoxelsPerSecond` | 150 | 0 | 予算で内側から治す WVC の再生（`Regenerate`）。VFC は使わず、下の前線の再生で治る |
| `RegrowthSpeed` / `RegrowthTickSeconds` | 0 / 0.25 | 0.0005 m/s / 0.25 s | 前線の再生（`BoxerBody.Regrow`）。0 ならしない。下の「再生」 |
| `StuckDoublingSeconds` | 0 | 3 | ラウンド中に両者が倒れて意識だけでは立てない間の再生の倍率 2^(t / これ)。0 ならラウンド中は再生しない |
| `ResupplyWeapons` | false | true | 休みの間に、失った武器を同じ種類で支給する |
| `BruiseHalfLifeSeconds` | 20 | 20 | 休みの間に皮膚のあざが半分に引く時間（VFC も休みに引くようにした） |
| `RoundSeconds` / `Rounds` / `BreakSeconds` | 30 / 5 / 10 | 30 / 5 / 25 | ユーザーの指定（2026-11-18） |

## 六角形の檻（`RingLayout.Shape = ArenaShape.HexCage`）

- `Size` は向かい合う辺と辺の距離（内接円の直径）。外接円の半径 R = Size / √3。辺（平らな面）が ±Z（2 人が向き合う方向）を向き、頂点は ±X 軸上。角は X 軸から Z 軸の向きへ測る（頂点 0°・60°…、面の法線 90°・150°…）。
- `RingLayout.Cage` = 1.3 m（面積 ≈ 1.46 m²、四角 1.2 m の 1.44 m² と同程度）・始めの間 0.44 m。`RingLayout.WeaponsCage` = 2.6 m（≈ 5.85 m²、四角 2.4 m の 5.76 m²）・1.0 m。
- `OuterHalf`（四角 = Half、檻 = R）に余白を足して `TableHalf`（+15 cm）・`PlinthHalf`（+8 cm）を出す（頂点が台座・天板からはみ出さない）。`LivingRoom.GroundAt` は檻のキャンバスを六角形で判定する。
- 当たり判定・見た目は `HexCage`（`Ring` が形で作り分ける 1 か所）。台・エプロン・キャンバスは長さ R・幅 2·(Size/2) の箱を 0°・60°・120° に回して 3 枚重ねる。壁は 6 辺に静的な箱 1 枚ずつ。
  - 高さ 0.5 m（`HexCage.WallHeight`）: UFC の金網は人 1.8 m に対し約 1.75 m だが、身長 60 cm の人形では拳・武器を隠しすぎないよう縮めた近道。
  - 厚み 0.06 m（`HexCage.WallThickness`）: 240 Hz で 1 歩に進む距離（拳 6 m/s で 2.5 cm、剣先 10 m/s で 4 cm）より厚い。内側の面が辺に付き、角の外側は t·tan30° だけ長くして隙間を埋める。
  - 見た目は 45° の細い棒の菱形格子（間隔 6 cm）・頂点の柱・上端と下端のパッド（黒）。キャンバスは明るい灰で中央に何も描かない。
- `IsOut` は今のまま（面より下へ落ちたら）。
- `RingLayout.EdgeDistance(point)`（縁から内側への距離）と `RingLayout.RestCorner(red, inset)`（休むコーナー）は形ごとの計算をここに置いた。檻の休むコーナーは赤 240°・青 60° の頂点から `CornerInset` だけ中心へ寄せた点。
- 記録・再生: `ReplayMatchSettings` は `RingLayout`・`MatchRules` をそのまま JSON で持つので、`Shape`・`CountsDowns`・`JudgesDecision` も入る。古い記録は既定値（四角・今のルール）で読める（テストあり）。

## 再生（2026-11-18、指示書 F。ユーザーの指定「両者ダウンしたまま何もしない時間が長く、番組として失敗」）

- **前線の再生**（`BoxerBody.Regrow`）: 壊れたボクセルのうち、生きているセルに接するものが抽選ごとに確率で元に戻る。1 回の抽選の確率 p = `RegrowthSpeed` × `RegrowthTickSeconds` / セルの大きさ（ボクセル 5 mm で 0.025）。p が 1 を超えるときは k = ceil(p) 回の pass に分け、各 pass を p / k にする（前線を飛ばさない）。候補は pass ごとに全部集めてから引く（順序に依らない）。乱数は試合の種から作った専用の流れ（`seed ^ 0x2e9e0`。ほかの乱数を動かさない）。死んだ体は再生しない。
- **値を測った結果**（`VfcRegrowthTests`）: 指示書の初めの値 1.2 mm/s では、前腕（人形で 9 cm、18 スライス）を肘から 3 割で切った切り株が休み 1 回（25 s、100 回の抽選）で元の長さまで戻った（+6.5 cm）。横のどの生きたセルからでも届くので、実際の前線は 1 列ぶんの確率から見積もった速さの約 2.2 倍で進む。0.5 mm/s にして測り直すと:
  - 胸への拳 4 発の削れ（208 セル）: 休み 1 回で 88% 戻る。
  - 前腕の切り株（失ったのは 6.5 cm）: 休み 1 回で +3.0 cm。戻りきらない。
- **欠損した先の部位の生え直し**（`Fighter.Reconnect`・`Rebud`）: 切り株の骨が元の遠い端（肘・膝・足首の関節を受ける所）まで戻ると、肉でぶら下がっていた破片のつなぎを外し、体から外れていた先の部位（肘から先・膝から先・足首から先。足はつま先と一緒）を芽から生え直させる。古い中身は同じ位置・向き・中身の破片として床に残り（握っていた武器・その先にぶら下がる部位もその破片へ付け替える）、部位の剛体は関節の側の 1 層（芽）だけを残して、親の関節の所へ作ったときの休みの形で置き直し、作ったときと同じ関節（`HumanoidRagdoll.AttachJointAt`、関節の所は生成の直後に読んだ値）と筋肉（肘・膝・足首のサーボ）を作り直す。芽の部位は骨が元の遠い端まで戻ると腕・脚がそろい、また駆動する（腕は拳を作ったときの所に付け直す。グローブ・はめる物は戻さない）。
- **いつ再生するか**（`BoxingGame.UpdateMatch`）: 休みの間は両者とも倍率 1。ラウンド中は、両者とも倒れていて（立っていない）、どちらも意識だけでは立てない（`Fighter.BodyLetsStand`: 脳しんとう 0・起き上がりの試みいっぱいでも、脚が支えられない・意識が戻らない・腰を立ち直りの高さまで上げられない）間だけ、倍率 2^(t / 3 s) で再生する。片方だけ倒れているなら再生しない（相手が攻める場面を消さない）。脚が支えられずに倒れた「起き上がらない」は、脚が戻れば外れる。
- **休みの武器の支給**（`BoxingGame.ResupplyWeapons`）: 試合の始めに武器を持っていた選手が、今その武器を握っていなければ（落とした・折れて捨てた・手を失った）、手が武器を保持できるとき（`Fighter.CanHoldWeapon`: 掴みの強さ × 前腕の筋肉の残りが、手と武器の軽い方の重さを支えられる。力の抜けていく手が武器を落とすのと同じ式）、同じ種類の新しい武器を試合の始めと同じ手順で持たせる。両手持ちは主の手が保持できれば支給し、添える手は使えれば添える。1 回の休みに 1 本まで。床の古い武器はそのまま残る。武器を失って拳で戦っていたボット（`DisarmedFallback`）は、また握れば武器の側へ戻る（LogicVersion 52）。
- **中継の記録**: `weapon_supplied`（実況: 誰に何が渡された）と `regrown`（解説: 失った部位が切り口から生え直し始めた）。下書き（`TvDraft`）・台本の道具は知らない種類を読み飛ばす。
- **団体のファイル**: `Orgs/vfc.json` の `match.regrowth`（`speed`・`tickSeconds`・`stuckDoublingSeconds`）と `match.resupplyWeapons` を `TvShowRules.Rules` が `MatchRules` へ通す（書かない団体は 0 / false。WVC は変わらない）。休みの看板の言葉は `text.intervalSign`。

## 近道・残った点（CLAUDE.md §8 へ足す候補）

- 金網の高さは人形の縮尺に合わせた見た目の値で、UFC の比ではない。壁は箱 1 枚（網目では当たらない）。
- 檻の壁は静的な箱なので、押し付け・追い詰めは物理から出るが、`BoxerBot` のロープ際の判断（`RopeBehind`・`StayInside`・`WeaponDefense` の `ring.Half` 判定）は四角のまま（檻の斜めの面を知らない）。段 C で `RingLayout.EdgeDistance` を使うよう直す余地がある。
- `ArenaLook.Dressing` の床の線（コーナーの赤・青・白の線）は四角いリングの図柄のまま。
