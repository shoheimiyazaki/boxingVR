ある試合の動画に、それを一緒に見ている 2 人（A と B）の声を付けます。日本語で。2 人が何者で、何を話すかは決めていません。

話し方: 仲の良い 2 人が試合を見ながら配信している。話す相手は主に配信を見ている視聴者で（「見てください」「皆さん」「今の分かりました？」）、2 人のやり取りはほどほどに混ざる程度。少しプロらしく、です・ます調を基本にしつつ、ときどき砕ける（「うわ、入った」）。相づちを求める「〜ですね」「〜ですよね」を重ねない。

話せる時間: 動画の 0 秒から {{length}} 秒まで（`at` = 話し始める秒）。

試合: **{{key}}**。作業場所はリポジトリの根。資料の置き場 OUT = `{{out}}`。2 人は動画を見ていますが、あなたは見られないので、動画に映るものは次の記録で知ってください（使うかどうか・どこを使うかは自由）:

- `OUT/{{key}}.events.json`: 動画の中で起きることと、その時刻（画面に出る表・リプレイ・勝敗も）
- `OUT/{{key}}.digest.md`: それを読みやすくまとめたもの

## 守ってほしいことはこれだけ

1. 動画で起きたこと（勝敗・倒れた・当たった）を記録と違えて言わない。
2. 動画の中の世界: 競技は Voxing、主催は WVC（Wonderful Voxing Council）。VGV・ボット・物理・セル・ダメージの数値・打撲・% は言わない。
3. 1 台詞は 60 字まで。声は読み上げで、次の台詞と重なると後ろが押し出される（1 台詞の時間 ≒ (字数 × 0.16 秒 ＋ 句読点ごと 0.48 秒) ÷ 1.15）。

## 書くもの: `OUT/{{key}}.extras.json`（既にあれば上書き）

```json
{ "style": "free", "useDraft": false, "lines": [ { "at": 0.3, "speaker": "a", "text": "…", "excited": false } ] }
```

動画に入る声は、ここに書いた 2 人の台詞だけです（ほかに実況・解説はいません。確かめのコマンドに出てくる draft.json は使われません）。

`speaker` は `a` か `b`。`excited: true` にすると声が高く速くなる。

## 確かめる

```bash
{{exe}} tvmerge --draft OUT/{{key}}.draft.json --extras OUT/{{key}}.extras.json --out OUT/{{key}}.script.json
{{exe}} tvlint --script OUT/{{key}}.script.json --events OUT/{{key}}.events.json
```

tvmerge が「入らなかった台詞」を出したら、時刻か長さを直す。tvlint が OK になったら終わり。最後に台詞の数（A・B）と点検の結果を 2 行で報告する。
